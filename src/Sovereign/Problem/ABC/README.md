## 一、立场声明（先读这一节；本目录**不含**任何"abc 证明"）

本目录**不**建立 abc 猜想的证明，也**不**复现或形式化望月新一的 IUTT。三条理由，逐条给依据：

1. **IUTT 本身的可接受性无共识。** 望月 2012 年声称证明 abc；主流数学界**仍视为未证明**；
   Scholze–Stix 提出反驳意见《Why abc is still a conjecture》。在一个"连证明成立与否都无定论"
   的理论上做形式化，等于把争议搬进本库——**本库不接受**这种输入。
2. **abc 是真开放问题。** 它蕴含 Fermat 大定理、Fermat–Catalan、Beal、修正 Szpiro、
   Roth、Tijdeman 等；本框架**没有新的算术输入**能把开放问题变已证。
3. **本框架既有的元理论裁决已经给出结论。** `docs/duodecimal/13-flt-analysis.md` 判定：
   FLT 型断言含 **Archimedes 序**成分，在离散基座上不可证（DC12 论文 L5「位数分离」即因此被反例击穿、项目废弃）。
   而 **abc ⟹ FLT**，所以 abc **更强地**含该成分 —— 同一断层，且更深。
   把 abc 硬塞进离散基座，会重犯 L5 那类错误。

## 四、L1 断层见证层（核心可证结果）

**定理（待建）**：存在两个互素三元组，它们的
**（i）模 12 同余类完全相同、（ii）`rad(abc)` 完全相同**，但 **(iii) 一个 `q > 1`、一个 `q < 1`**。

**见证**（已独立核算，见下）：

| 三元组 | `a+b=c` | 互素 | `rad(abc)` | 与 `rad` 比较 | mod 12 |
|---|---|---|---|---|---|
| `(3, 5, 8)` | 3+5=8 ✓ | ✓ | `rad(120) = 30` | `8 ≤ 30` ⇒ **q < 1** | `(3,5,8)` |
| `(3, 125, 128)` | 3+125=128 ✓ | ✓ | `rad(2⁷·3·5³) = 30` | `128 > 30` ⇒ **q > 1** | `(3,5,8)` |

- 两者 `rad` **都是 30**（`8 = 2³` 与 `128 = 2⁷` 只差 2 的幂，而 2 在两者里都只贡献一次）；
- 两者模 12 完全相同 ⇒ **任何固定模投影都无法判定质量是否跨过 1**；
- 参考值：`q(3,5,8) = 0.611385…`，`q(3,125,128) = 1.426565…`（后者与维基百科经典例一致，交叉校验了我们的 `rad` 算法）。

**这条定理的意义**：它不是"复现 abc"，而是**证明离散投影看不见 abc 的内容**——
与库里既有的 `crt-myopia`、`euclidean-myopia`、`¬-factorization-is-vortex` 同一族（信息截断定理）。
它唯一依赖的算术就是"素因子分解"和"大小比较"，**完全在离散基座内**。

### 4.1 已建成：两维度壁垒（`ABCL1.agda`，0 postulate）

用户指出望月把环的加法/乘法结构称为「**两个底层算术维度**」，且「压成一个维度 ⇒ 立即矛盾」。
已核实原文（见 [`docs/duodecimal/23-two-arithmetic-dimensions.md`](../../../docs/duodecimal/23-two-arithmetic-dimensions.md)，带页码），
并在本库把它定理化：

| 维度 | 能否穿过平展投影（C₁₂/R₁₂） | 定理 |
|---|---|---|
| 加法 | **穿得过** | `additive-dim-passes = crt12-roundtrip`（Z/12 ≅ Z/3 × Z/4 双射） |
| 乘法 | **穿不过** | `no-injective-hom`：`⟨α⟩` ≅ C₄ 到 R₁₂ 单位群 V₄ 不存在保单位单射同态 |

一句话：**加法维度可无损下沉，乘法维度不能** —— 「两个底层算术维度不能压成一个」的可证版本。
⚠️ 边界（2026-09-13 审计后收紧，见 `23-two-arithmetic-dimensions.md` §六）：
- 这**不是** abc 的证据，**不**对 IUTT 对错表态；后果也有别（望月得到**矛盾**，我们得到**投影丢结构**）。
- **不得**写成「IUTT 困难的可证版本」。原文 (Syp2) 表明「两维度之间不存在相容性/函子」是**望月自己的主张**、
  也是批评方同意的**前提**——即**争议不在这一点上**（争点是"没有相容性时 Cor 3.12 的推理是否成立"）。
  所以本模块是 IUTT **结构前提**的**离散玩具实例**，**与争议裁决无关**。

## 五、诚实边界与已知障碍

1. **不主张 IUTT 对或错**。本目录只记录文献状态（争议未决），不下数学判断。
2. **`q > 1` 有无穷多三元组**是**已知**事实（维基百科明确记载），但**本库尚未形式化**；
   本目录不含它的证明。目前已核算的只有上文两个**具体**见证。
3. **已知工程障碍（实测，必须记录）**：把 `rad` 写成可计算的 Agda 函数
   （`radFrom` 用 `prime?` 逐 k 判定）后，**类型检查器在 600 s 内没有完成** `rad (3*5*8) ≡ 30`
   的 `refl`（判定过程产生的证明项在归一化时爆炸）。这是**实现层**障碍，不是数学障碍。
   待选方案：(a) 把 `rad` 定义成**关系** `IsRadical n r` 并只对具体小数字证明实例；
   (b) 走分解式定义（先要确认库中素因子分解 API 的可用性）；
   (c) 一般性 `rad` 只作**非计算**陈述，性质以抽象引理给出。
   **决策前不硬写模块**——写出来也是慢到跑不动的代码。
4. `Problem/ABC` 与 `Problem/Fermat` 的关系必须写进模块头：abc ⟹ FLT，
   而 FLT 已被本框架裁定"离散不可证"，故 abc 的断层只会更深，不会更浅。
