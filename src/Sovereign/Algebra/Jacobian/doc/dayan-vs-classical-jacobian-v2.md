# 大衍框架 vs 经典雅可比猜想：两种数学范式的根本区别

> **核心论点**：大衍框架不是在解经典雅可比猜想，而是在离散基座上重建了它的困难结构，并给出了该结构下的完全解答。

---

## 一、工作域与数学基础的根本差异

| | 经典雅可比猜想 | 大衍框架 |
|---|---|---|
| 工作域 | 复数域 ℂ（特征0，阿基米德域） | 有限域 𝔽₃、𝔽₉ 及环面 T⁶（特征p，离散紧致） |
| 无穷远 | 存在射影无穷远（根可逃逸） | **无**——729个格点全部有界，无逃逸路径 |
| 空间性质 | 无限、非紧致 | 有限、紧致（鸽巢原理适用） |

**关键区别**：经典JC在复数域上，点可以无限远离原点，映射行为在无穷远处难以控制；大衍框架在有限域上，所有点都"可见"，全局行为可通过有限计算完全确定。

> "复数域 ℂ 只是有限域 𝔽ₚ 在'特征0极限'下的**解析投影**。在这个投影过程中，原生的 Frobenius 共轭（x ↦ x^p）的零导数效应被掩盖了，取而代之的是拓扑无穷远。"（引自项目注释）

## 二、多项式身份的差异

| | 经典雅可比猜想 | 大衍框架 |
|---|---|---|
| 多项式对象 | **形式多项式环** ℂ[x]（x³ ≠ x） | **多项式函数空间** 𝔽₃^𝔽₃（x³ = x，Fermat坍缩） |
| 数学地位 | 语法对象，可无限次求导 | 函数对象，受Fermat恒等式约束 |

**关键区别**：在经典JC中，x³ 与 x 是**不同的多项式**；在有限域函数空间中，它们是**相同的函数**。大衍框架原生包含Fermat坍缩，高阶多项式在函数上等同于低阶多项式。

**项目明确区分**：
> "形式多项式环 GF(3)[x] 中 x³ ≠ x，多项式函数空间 GF(3)^{GF(3)} 中 x³ = x（Fermat）。BCW规约在形式多项式环上工作，Fermat坍缩在函数空间上工作。"（`jac_Discrete.agda`）

## 三、雅可比对象的本质区别

| | 经典雅可比猜想 | 大衍框架 |
|---|---|---|
| 雅可比对象 | **形式导数** ∂f/∂x（逐点局部条件） | **函数表矩阵** M_F（全局条件）+ **差分算子** J_Δ（局部） |
| 作用域 | 逐点（无穷小邻域） | 全局（整个有限空间） |
| 数学性质 | 解析线性化 | 有限集线性代数 |

**三层雅可比的强度**（`jac_DiscreteJC.agda`）：
```
形式导数 det J (最弱，有Frobenius盲区)
  < 差分算子 det J_Δ (无盲区，但仍是局部条件)
    < 函数表矩阵 det(M_F) (最强，精确判定双射)
```

**经典JC**用雅可比行列式作为**局部线性非奇异的判据**，试图推出全局可逆。**大衍框架**用函数表矩阵作为**全局映射的完备编码**，通过鸽巢原理精确判定双射。

## 四、共轭性处理的本质差异

| | 经典雅可比猜想 | 大衍框架 |
|---|---|---|
| 共轭处理 | **排除**复共轭（反全纯，不在JC考察范围） | **原生包含** Galois共轭 σ: x ↦ x³（多项式，自动进入判定） |
| 共轭导数的命运 | 被排除在游戏之外 | σ'(x)=3x²=0（Frobenius盲区） |

**关键洞察**：GF(9) 的 Frobenius 共轭是**不可回避的**——任何多项式映射都必须面对它。复数域通过"只考虑全纯映射"这个限制，**把共轭性驱逐出了游戏**。

> "复数域通过投影（仅取全纯部分）掩盖了共轭的零导数效应，但代价是引入了无穷远逃逸。"（项目分析）

## 五、失效机制的本质差异

| | 经典雅可比猜想 | 大衍框架 |
|---|---|---|
| 失效机制 | **根逃逸至射影无穷远**（Alpöge 2026） | **根坍缩进Frobenius核**（3-to-1有限坍缩） |
| 反例维度 | n=3（三个不同点坍缩到同一点） | GF(3)²: 9→3坍缩；GF(9)²: 81→27坍缩 |
| 反例结构 | 第三个根在 c=0 时逃逸到∞ | Fermat坍缩使 y³=y，纯三次项消失 |

### Alpöge 反例核心（216字符）：
```
a = (1+xy)³z + y²(1+xy)(4+3xy)
b = y + 3x(1+xy)²z + 3xy²(4+3xy)
c = 2x - 3x²y - x³z
```
三个不同点坍缩到 (-1/4, 0, 0)，det J(F) = -2 处处成立。

### 大衍框架反例核心：
- GF(3)²：F(x,y) = (x, y+2·y³) = (x, 0)，J=I₂，det=1，但非双射
- GF(9)²：F(x,y) = (x, y+α·y³)，det J=1，det J_Δ=1+α≠0，但非双射（3-to-1）

### 关于差分算子的正确表述：

**差分算子（ΔF）虽然消除了"形式导数"的 Frobenius 盲区，使得 Δ(x³)=1，但它所代表的"逐点局部条件"依然不足以推导全局双射性。在 GF(9)² 上，即使 det(J_Δ)=1+α ≠ 0（非零）处处成立，映射依然因 Frobenius 核坍缩而失效。**

> 这表明：即使差分算子消除了"零导数"的代数缺陷，局部信息（无论以何种形式定义）在离散域上仍然存在固有的"全局盲区"。

> "Alpöge反例利用**射影无穷远**（几何逃逸），大衍框架反例利用**Frobenius核结构**（代数坍缩）。两者都指向同一个元结论：**'局部非奇异'与'全局可逆'之间，天然存在一道鸿沟。**"

## 六、判定结论的本质差异

| | 经典雅可比猜想 | 大衍框架 |
|---|---|---|
| 结论 | **假**（n≥3被Alpöge证伪） | **真**（全局矩阵精确判定双射） |
| 判定方式 | 逐点条件 det J(F) ≠ 0（不充分） | 全局条件 det(M_F) ≠ 0（充分必要） |
| 证明依赖 | 复杂几何构造（反例） | 鸽巢原理（构造性形式化） |

**大衍框架的核心定理**（0 postulate）：
> 在有限集 S（|S|=N）上，对任意映射 F: S → S：
> F 是双射 ⟺ F 的全局矩阵 M_F 在 GF(3) 上行列式非零。

**证明结构**：
```
det(M_F) ≠ 0
  ⟺ 列互异 ∧ 无全零行    （函数表矩阵结构）
  ⟺ F 单射 ∧ F 满射       （行列性质）
  ⟺ F 双射                （鸽巢原理）
```

## 九、大衍框架的四大使命

### 1. 拆穿"复数投影层"的伪装
- 复数域 ℂ 只是 𝔽ₚ 在"特征0极限"下的**解析投影**
- 原生 Frobenius 共轭（x ↦ x^p）的零导数效应被掩盖了，取而代之的是拓扑无穷远
- 大衍框架回到未被投影的**离散基座**，让原生代数共轭**重新可见**

### 2. 建立离散域上的"完备可逆性理论"
- **局部层**：形式导数 → 被证伪（Frobenius盲区）；差分算子 → 仍被证伪（GF(9)²反例）
- **全局层**：函数表矩阵 M_F → **被证明为完备判据**（鸽巢原理 + 行列式非零）
- **结论**：在离散有限环面上，只有全局信息才能决定双射性，局部信息永远不够

### 3. 用形式化验证（Agda）封装修辞陷阱
- 所有结论编码为可机器检查的证明（~10200行，0 postulate）
- 明确区分"形式多项式环"与"多项式函数空间"
- 双重保障：Agda形式化证明 + Python穷举验证

### 4. 为算术几何提供"可计算的镜像"
- 经典JC在 ℂ 上涉及"射影无穷远"，难以计算
- 大衍框架在 𝔽₃、𝔽₉、T⁶ 上构造精确离散镜像
- **Frobenius共轭取代了无穷远；鸽巢原理取代了拓扑紧性；全局矩阵取代了雅可比矩阵**
