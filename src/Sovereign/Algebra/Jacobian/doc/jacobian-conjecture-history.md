## 引言：多变量多项式映射的全局可逆性与世纪难题

雅可比猜想（Jacobian Conjecture）由德国数学家凯勒（Ott-Heinrich Keller）于1939年提出：

> 对于多项式映射 F: ℂⁿ → ℂⁿ，若其雅可比行列式 det J(F) 为非零常数，则 F 存在多项式全局逆映射。

**核心张力**：逆函数定理保证局部可逆，但局部绝不等于全局。复指数函数 e^z 处处导数 ≠0，全局并非单射。猜想追问：多项式的 "刚性" 是否足以将局部可逆性强制提升为全局双射？

- 1998年，斯梅尔（Smale）将其列入 "21世纪数学问题"
- 2026年7月，阿尔普格（Alpöge）在 Claude Fable 5 辅助下构造了 n=3 精确反例

## 严格数学表述与特征零域的必然性

### 雅可比条件

F(x₁,...,xₙ) = (F₁,...,Fₙ)，Fᵢ ∈ ℂ[x₁,...,xₙ]

- J(F)ᵢⱼ = ∂Fᵢ/∂xⱼ
- det J(F) 度量了局部体积缩放比
- 若 F 有多项式逆 G：det J(F) · det J(G) = 1 → 两者皆为非零常数

猜想断言这一必要条件也是充分的。

### 正特征域的退化

特征 p 域上猜想显然不成立：
- F(x) = x + x^p，导数 F'(x) = 1 + px^{p-1} ≡ 1（因为 p=0 mod p）
- 但 F 显然不可逆（多对一）

此即 **Frobenius 盲区**——本项目中 GF(3)² 和 GF(9)² 反例的数学本源。

阿贾马格博（Adjamagbo）曾尝试通过 "域扩张度数不被 p 整除" 的额外假设推广，但主流研究集中于特征零域。

## 结构性规约理论

### Bass-Connell-Wright (BCW) 规约 (1982)

**定理**：若猜想对所有形如 F = X + H 的三次齐次映射成立，则一般情况也成立。

其中 H 的每个分量都是零或三次齐次多项式，且 J(H) 是幂零矩阵。

→ 将任意高次问题转化为三次齐次 + 幂零矩阵问题

### Drużkowski 规约

进一步简化为 "立方线性类型"：Hᵢ = (Lᵢ)³（线性形式的立方）。

代价：变量维度 N 剧烈膨胀（低维高次 → 高维低次）。

### 度数上界

- 度数=1：线性代数，显然成立
- 度数=2：Stuart Wang 证明所有维度成立
- 有逆时逆的度 ≤ d^{n-1}（Gabber 边界）
- 二维 度数≤100：莫宗坚 1983 年证明成立

**张益唐插曲**：博士七年试图证明二维雅可比猜想，依赖莫宗坚引理，但引理有致命缺陷 → 学术生涯沉寂数十年。

## 实数域变体与拓扑破缺

### 强实雅可比猜想

若 det J(F) 在 ℝⁿ 上处处不为零（→ 恒正或恒负），则 F 是全局同胚。

### Pinchuk 反例 (1994)

ℝ² 上的多项式映射，det J(F) > 0 处处成立，但：
- 不是单射
- 拓扑度数 = 2
- 非满射（遗漏 (-1,0) 和 (1,0) 两点）

构造核心：利用 t = xy-1, h = t(xt+1) 等辅助多项式，使两条渐近曲线在无穷远处扭曲交汇。

### Braun-Fernandes 反例 (2023)

即使 det J(F) ≥ 1（有正下界），全局单射仍不成立。

根源：映射非固有（non-proper）——存在走向无穷远的路径，像却收敛于有限点。

| 猜想 | 领域 | 与 JC 的关系 | 2026 后状态 |
|------|------|-------------|-----------|
| Dixmier 猜想 | 非交换代数（Weyl 代数自同态） | 稳定等价：秩 n ↔ 维度 2n | n≥2 (即维度≥4) 被反驳 |
| Poisson 猜想 | 辛几何 | 完全等价 | n≥3 被反驳 |
| 消失猜想 | 偏微分算子（拉普拉斯） | 完全等价（赵文华 2007） | 被反驳 |
| 高斯矩猜想 | 量子场论、概率论 | 蕴含 JC | n≥3 被反驳 |

## 2026年7月：阿尔普格三维反例

### 反例 (216 字符)

```
a = (1+xy)³z + y²(1+xy)(4+3xy)
b = y + 3x(1+xy)²z + 3xy²(4+3xy)
c = 2x - 3x²y - x³z
```

验证：
- det J(F) = -2（处处成立）
- 三个不同输入坍缩到同一点 (-1/4, 0, 0)：
  - (0, 0, -1/4)
  - (1, -3/2, 13/2)
  - (-1, 3/2, 13/2)

### 陶哲轩的几何解析

从多项式乘法算子 F(L, Q) = L·Q 出发：
- Sym¹(ℂ²) × Sym²(ℂ²) → Sym³(ℂ²)，维度 2+3=5 → 4
- 三次多项式可分解为 3 个线性因子：C = L₁L₂L₃
- 拆解为 (线性)×(二次) 有 3 种方式 → 精确 3-to-1 坍缩
- 缩放对称性 F(λL, λ⁻¹Q) = L·Q 被结式 Res(L,Q)=1 约束消除

### 伽罗瓦分析

令 K = ℂ(a,b,c)，L = ℂ(x,y,z)。引入 t = y + 1/x：

```
b = 4t + 2/x - 3ct²
2a = ct³ - 2t² + bt
```

得到 t 的三次极小多项式：

```
P(T) = cT³ - 2T² + bT - 2a = 0
```

- [L : K] = 3
- 伽罗瓦闭包单值群 ≅ S₃
- 在坍缩点 a=b=c=0 处，c=0 → 三次退化二次 → 第二个根逃逸到射影无穷远

**扩张度数为 2 时自动正规 → 猜想成立。反例必须 ≥ 3 且非正规。**

### 苏联/俄罗斯数学渊源：维图什金（Vitushkin）的种子

陶哲轩等人在复盘中发现，反例的底层构造深受前苏联经典复分析与代数几何文献的影响：

- **维图什金（Anatoliy Vitushkin）的映射思想**：反例的"种子"可追溯到前苏联数学家维图什金等人在20世纪提出的有理映射经典例子——局部保距/单射但全局因对称性坍缩的非双射构造。其经典工作涉及**穿孔平面上的求和-乘积映射**：局部保持解析结构但在全局层面出现多对一重合。

- **前苏联多复变学派**：苏联数学学派在多复变函数、奇点理论、微分同胚以及多项式映射拓扑性质方面有数十年积累。Claude Fable 5 在探索高维多项式空间时，实质上是将这些老旧的数学构型进行了多维拓展与精妙组合——站在苏联巨人的肩膀上完成了现代化的参数空间搜索。

- **关键传承链**：Vitushkin (1970s~1980s) 的有理映射非单射构造 → 俄罗斯学派的局部-全局拓扑分析 → Pinchuk (1994) 实反例 → Alpöge/Fable 5 (2026) 复反例。这是一条清晰的代数-拓扑-计算融合的传承线。

### AI 研究合作者的意义

- **非暴力穷举**：Fable 5 并非盲目搜索 1300 项方程组，而是结合 Vitushkin 经典构型 + 陶哲轩的几何框架，进行定向剪枝与高维参数空间搜索
- **"寻找极难，验证极易"**：最终反例仅 216 字符，SymPy 瞬间验证，但发现过程依赖 AI 对庞大多项式空间的启发式探索
- **范式转变**：从 "寻找通用证明" 转向 "借助机器界定真理崩溃的精确边界"

### 为何 81 个数学家的搜索失败了

- 盲目搜索 = 近 1300 项非线性方程组完全抵消
- Fable 5 的启发式搜索在小时级收敛到最简反例
- "寻找极难，验证极易" —— SymPy 瞬间验证

## 与本项目的关联

| 概念 | 连续统 JC | 离散 Jacobian 项目 |
|------|----------|-------------------|
| 特征 | char 0 | char 3 |
| 盲区 | Pinchuk/无穷远逃逸 | Frobenius 盲区 (∂(x³)/∂x=0) |
| 核心反例 | 3-to-1 (c=0 退化) | GF(9)² 3-to-1 (α·y³ 项) |
| 映射类型 | 固定维度空间 | 有限集 (729 格点) |
| 判定条件 | 逐点 det J ≠ 0 | 全局 det(M_F) ≠ 0 |
| 结果 | JC 在 n≥3 被证伪 | 全局矩阵条件下 JC 平凡为真 |

**核心差异**：离散环面 T⁶ 有界封闭——不存在射影无穷远。这就是离散版本中全局矩阵能精确判定的几何根源。
