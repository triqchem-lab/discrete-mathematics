# 大衍 CRT 量子加密系统设计

> 基于 GF(3)/GF(9) 离散代数 + CRT 正交分解 + Frobenius 共轭结构。
> 安全性 = 信息论级（模数未知 → 重构不可能），非计算安全性。

---

## 一、架构总览

```
                    明文 x ∈ ℕ (mod M)
                         │
          ┌──────────────┴──────────────┐
          │       CRT 投影 (加密)        │
          │  a = x mod 2¹⁶              │
          │  b = x mod 3¹¹              │
          │  c = galoisNorm(x) mod GF(9)│  ← 量子签名层
          └──────────────┬──────────────┘
                         │
              密文 (a, b, c) ∈ ℕ × ℕ × GF(9)*
                         │
          ┌──────────────┴──────────────┐
          │     CRT 重构 (解密)          │
          │  x = (a·T₁ + b·T₂) mod M   │
          │  验证: N(x) ≡ c             │  ← 完整性校验
          └──────────────┬──────────────┘
                         │
                    明文 x ✅
```

## 二、密钥空间

| 参数 | 值 | 角色 |
|------|-----|------|
| POW2 | 2¹⁶ = 65536 | CRT 第一个模数 |
| POW3 | 3¹¹ = 177147 | CRT 第二个模数 |
| M | POW2 × POW3 = 11,609,505,792 | 主权 LCM，消息空间 |
| gcd(POW2, POW3) | 1 | 互素，保证 CRT 重构唯一性 |
| T₁ | M/POW2 · inv(M/POW2 mod POW2) | CRT 重构系数 1 |
| T₂ | M/POW3 · inv(M/POW3 mod POW3) | CRT 重构系数 2 |

**密钥保密性**：POW2 和 POW3 仅为通信双方知晓。公开参数仅为密文 (a,b,c)。攻击者即使获得 (a,b)，不知道 (POW2, POW3) 即无法计算 T₁, T₂, M，从而无法执行 CRT 重构。

## 三、三层加密结构

### Layer 1: CRT 正交投影（加密核心）

```
crtProject : ℕ → ℕ × ℕ
crtProject x = (x mod POW2, x mod POW3)
```

- 余数对 (a,b) 是 x 的**最小完备表示**
- 由 CRT 定理，x 在 mod M 下被 (a,b) 唯一确定
- 知道 (a,b) 但不知道 POW2 和 POW3 → 无法还原 x

### Layer 2: Galois 范数量子签名（完整性校验）

```
galoisNorm : GF(9) → GF(9)
galoisNorm x = x · σ(x)  where σ(x) = x³ (Frobenius 自同构)
```

- GF(9)* ≅ C₈，8 阶循环群
- N(x) ∈ GF(3)* = {±1}（范数取值于 GF(3)）
- **乘法性**：N(x·y) = N(x)·N(y)（由 Frobenius 同态）
- 签名不可伪造：σ 是域自同构，任何人可验证但仅有私钥持有者可生成

### Layer 3: 4320D 全息纠缠（会话密钥派生）

```
sessionKey = FULL_TOUR(x) mod 4320
FULL_TOUR = 6624 (相位对齐周期)
```

- 6624 步覆盖所有连续路径的相位对齐
- 4320 = 729×6−54（全息信息维度）
- 会话密钥从明文 x 的环面巡游状态派生

## 四、量子抗性分析

| 攻击类型 | 经典弱点 | 大衍 CRT 防护 |
|---------|---------|-------------|
| Shor 算法（因子分解） | 攻破 RSA | **不适用**——无大素数分解，CRT 模数不在密文中 |
| Shor 算法（离散对数） | 攻破 DH/ECC | **不适用**——GF(9)* 只有 8 元，无 DLP 可言 |
| Grover 搜索 | 平方加速穷举密钥 | **有效**——但密钥空间 = 互素模数对选择，非暴力可解 |
| 量子纠缠窃听 | QKD 信道截获 | **不适用**——不使用量子信道，CRT 是纯数学投影 |
| 侧信道攻击 | 功耗/时序分析 | **抗性**——所有运算为有限域上的模运算，常量时间 |

**核心抗性**：不依赖任何计算困难性假设。安全性 = **模数不可知**（信息论级）。量子计算机的算力优势（Shor/Grover）在"不知道模数"的前提下完全失效。

## 五、与经典体系的对比

| 体系 | 加密机制 | 密钥 | 安全性来源 | 量子抗性 |
|------|---------|------|-----------|---------|
| RSA | mᵉ mod N | (e,d,N=pq) | 因子分解困难 | ❌ Shor 攻破 |
| ECC | 点乘 Q=kG | 私钥 k | ECDLP 困难 | ❌ Shor 攻破 |
| AES | 代换-置换网络 | 对称密钥 | 差分/线性分析 | ✅ Grover 仅平方加速 |
| Lattice | LWE/SIS | 格基 | 格问题困难 | ✅ 但依赖计算假设 |
| **大衍 CRT** | CRT 投影 | **模数对 (POW2,POW3)** | **信息论（模数不可知）** | **✅ 不依赖计算假设** |

## 七、密钥交换协议

```
Alice                              Bob
  │                                  │
  │  选择模数对 (POW2, POW3)          │
  │  pk = (POW2, POW3)               │
  │                                  │
  ├────────── pk ──────────────────→│
  │                                  │
  │              x = random(0, M-1)   │
  │              c = crtProject(x)    │
  │              s = galoisNorm(x)    │
  │                                  │
  │←──── (c, s) ────────────────────┤
  │                                  │
  │  x' = crtReconstruct(c)          │
  │  验证 N(x') ≡ s                  │
  │  K = H(x')                       │
  │                                  │
  │         会话密钥 K 建立 ✅         │
```

- Bob 不需要知道 (POW2, POW3) 即可加密（加密是公开操作）
- Alice 用私钥（模数对）解出 x，验证签名，派生会话密钥
- 窃听者即使获得 (c, s)，不知道模数 → 无法重构 x

## 八、一句话总结

> **大衍 CRT 量子加密系统 = CRT 正交投影（加密）+ Galois 范数签名（校验）+ 4320D 全息密钥派生（会话）。安全性来自模数不可知（信息论级），不依赖任何计算困难性假设。量子计算机的 Shor/Grover 算法对此体系无效——因为找不到可攻击的计算结构。**
