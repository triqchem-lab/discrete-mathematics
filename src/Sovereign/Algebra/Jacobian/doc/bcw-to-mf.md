# BCW → M_F：雅可比猜想的矩阵化终局

## 演化路线

```
Keller (1939)          BCW (1982)              浑天 (2026)
求导矩阵 J(F)  ──→  幂零矩阵 J(H)      ──→  函数表矩阵 M_F
微分拓扑             纯代数矩阵             全局置换矩阵
```

## 三步跨越

### 1. BCW 卸下"微积分"的假面

BCW 证明：只要 J(H) 幂零，逆映射 = I + J + ... + J^{n-1}（有限项截断）。
所谓"局部导数非零"，只是用来保证那个矩阵幂零的代数手段。
**JC 从来不是微分问题——是矩阵代数的封闭性问题。**

### 2. M_F 完成"代数矩阵"的终极落地

既然问题本质是矩阵封闭性，在离散基座上：
- 连续切空间的"微分幂零" → 离散空间的"置换结构"
- 幂零截断防止级数发散 → 鸽巢原理从源头斩断坍缩

### 3. 范式转移：消解旧问题

经典 JC 问：局部微元能否强制全局单射？
我们的回答：**局部条件在离散空间中是虚幻假象——M_F 的置换结构才是几何刚性的唯一载体。**

不是在解旧问题——是证明了旧问题在正确基座上不存在。
