# 🏛️ 大衍离散雅可比框架与Alpöge反例的对比总结

## 一、Alpöge反例（连续域）

| 项目 | 内容 |
|------|------|
| **发现者** | Levent Alpöge，借助Anthropic的Claude Fable 5 (2026年7月) |
| **工作域** | ℂ³（复数域，特征0，非紧致） |
| **映射** | 7次多项式映射，显式给出（216字符） |
| **雅可比行列式** | 恒等于 -2（非零常数） |
| **失效机制** | **3-to-1坍缩**：三个不同点映射到同一点 (-1/4, 0, 0) |
| **几何根源** | 多项式乘法映射: Sym¹×Sym²→Sym³，因子分解的三种方式 |
| **代数根源** | 三次极小多项式 P(T)=cT³−2T²+bT−2a=0，单值群 S₃，根逃逸至射影无穷远 |
| **前苏联渊源** | 维图什金（Vitushkin）有理映射局部单射/全局非单射的经典构型 |
| **历史意义** | 宣告高维雅可比猜想（n≥3）在原形式下不成立 |
| **AI角色** | 非暴力穷举，结合经典构型进行定向剪枝与参数空间搜索 |

## 二、大衍离散雅可比框架（离散域）

| 项目 | 内容 |
|------|------|
| **工作域** | GF(3)、GF(9)、T⁶=GF(3)⁶（有限域，特征3，紧致离散） |
| **核心对象** | 函数表矩阵 M_F（全局线性化） |
| **判定条件** | det(M_F) ≠ 0 |
| **判定结论** | det(M_F) ≠ 0 ⇔ F 是双射（鸽巢原理，精确完备） |
| **逐点失效机制** | Frobenius盲区：∂(y³)/∂y = 3y² = 0（char 3） |
| **形式化验证** | 14模块，~10400行，0 postulate，Agda编译全绿 ✅ |
| **实验验证** | GF(9)²：59,049映射，93.3%非双射（逐点条件全部满足，全局矩阵精确检测） |

## 三、核心对比

| 维度 | Alpöge反例（连续） | 大衍框架（离散） |
|------|-------------------|------------------|
| **坍缩比例** | 3-to-1 | 3-to-1 |
| **盲区根源** | 无穷远逃逸（射影无穷远折叠） | Frobenius核坍缩（Fermat y³导数为0） |
| **判定工具** | 逐点雅可比行列式 det J(F) | 全局函数表矩阵 det(M_F) |
| **结论** | ❌ 局部条件不蕴含全局双射 | ✅ 全局条件精确判定双射 |
| **数学范式** | 连续、非紧致、半代数/解析几何 | 离散、紧致、有限组合/线性代数 |

## 四、关键洞察

> **Alpöge反例与大衍GF(9)²反例共享同样的结构（3-to-1折叠），却来自两个独立且不可约的数学机制：连续域的"无穷远逃逸"和离散域的"Frobenius核坍缩"。**
>
> **大衍框架通过全局矩阵（鸽巢原理），在离散域上彻底修复了"局部→全局"的断裂。这是Alpöge反例所无法触及的，因为连续域上没有可计算的"全局矩阵"。**
>
> **离散是本质，连续是投影。大衍框架回到离散基座，重建了雅可比猜想的困难结构，并给出了该结构下的精确解答。** 🜁
