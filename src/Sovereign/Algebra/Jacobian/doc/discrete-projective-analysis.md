> 基于大衍框架的射影几何模块（无无穷远、环面闭合、Frobenius 原生共轭），
> 系统解剖 Alpöge 反例的每个失效点，并对比离散环面上的行为。

## 一、Alpöge 反例的几何解剖

### 反例定义
```
F: ℂ³ → ℂ³
a = (1+xy)³z + y²(1+xy)(4+3xy)
b = y + 3x(1+xy)²z + 3xy²(4+3xy)
c = 2x - 3x²y - x³z

det J(F) = -2 (处处非零)
```

### 坍缩点分析

三个不同输入点：
```
P₁ = (0, 0, -1/4)
P₂ = (1, -3/2, 13/2)
P₃ = (-1, 3/2, 13/2)
```
全部映射到同一点：
```
F(P₁) = F(P₂) = F(P₃) = (-1/4, 0, 0)
```

### 引入 t = y + 1/x 后的三次方程
```
P(T) = cT³ - 2T² + bT - 2a = 0
```
在坍缩点 (-1/4, 0, 0)：
- a = -1/4, b = 0, c = 0
- P(T) = 0·T³ - 2T² + 0·T - 2(-1/4)
- P(T) = -2T² + 1/2 = 0
- T = ±1/2 (只有两个根！)

**第三个根在 c=0 退化时逃逸到了射影无穷远。**

## 二、离散射影几何的五个诊断维度

大衍框架的射影几何模块提供了五个维度来诊断 Alpöge 反例：

| 维度 | 经典 ℂ³ | 大衍 T⁶/GF(9)² | 诊断结果 |
|------|---------|---------------|---------|
| **空间闭合性** | 非闭合（需射影紧化） | 天然闭合（环面） | Alpöge 的逃逸通道不存在 |
| **无穷远存在性** | 存在（作为射影点） | 不存在（所有点可枚举） | c=0 退化无法逃逸 |
| **共轭可见性** | 被排除（反全纯） | 原生可见（Frobenius σ） | Frobenius 核替代无穷远 |
| **Fermat 坍缩** | 不存在（char 0） | 存在（y³ = y） | 三次项被吸收 |
| **全局矩阵** | 不存在（无限维） | 存在（9×9 / 729×729） | 精确判定双射 |

### 诊断 1：空间闭合性

```
ℂ³:  点可以无限远离原点 → 需要 ℂℙ³ 射影紧化 → 无穷远超平面存在
T⁶:  环面 (S¹)⁶ = 有限格点 × 周期边界 → 巡游回到起点 → 无需射影紧化
      729 格点全部可见、全部可枚举
```

**结论**：在 T⁶ 上，不存在 Alpöge 反例中 c=0 退化时根可以逃逸的去处。每个点都是格点，每个格点都有唯一的 Fin 729 索引。

### 诊断 2：无穷远的不存在性

在 ℂ³ 中，射影无穷远是一个合法的代数点。但在离散环面上：

```agda
-- jac_GeometricClosure.agda
finiteIndex : (p : GF3²) → Σ (Fin 9) (λ i → decode9 i ≡ p)
finiteIndex p = encode9 p , decode9-encode9 p

-- Fin 9 只有 0-8，不存在"第10个点"
-- Fin 729 只有 0-728，不存在"第730个点"
```

**结论**：Alpöge 反例中第三个根"逃逸到射影无穷远"——这个操作在离散环面上**类型系统直接禁止**。Fin 729 的索引 729 不存在于类型中。

### 诊断 3：共轭可见性——Frobenius 取代无穷远

经典 JC 把复共轭排除在外。大衍框架中，Frobenius 共轭是**原生可见的多项式映射**：

```
GF(9) = GF(3)[α]/(α²+1)
σ(α) = α³ = -α (Frobenius 自同构)
σ'(α) = 3α² = 0 (char 3, 导数盲区)
```

这个 σ 在 ℂ 中不存在——ℂ 上的 z↦z³ 不是域自同构（不是加法同态）。但在 GF(3) 上，σ 是**真正的域自同构**，且在函数空间中产生了 Fermat 坍缩。

**关键对应**：
```
ℂ³ 中的无穷远逃逸  ⟷  GF(9)² 中的 Frobenius 核坍缩
射影紧化的代数代价  ⟷  Frobenius 盲区的导数代价
```

### 诊断 4：Fermat 坍缩——三次项的消失

Alpöge 反例的核心是**三次方程在 c=0 时退化**。在 GF(3) 上：

```
在 GF(3) 函数空间中: y³ = y (Fermat)
在 GF(3) 形式环中:   y³ ≠ y (保持三次结构)

Alpöge 反例依赖于"三次 ≠ 恒等"的代数区分。
在 GF(3) 函数空间层面，三次项被 Fermat 坍缩吸收 → 方程退化在更早的阶段就发生了。
```

**形式化验证**（`jac_GeometricClosure.agda`）：
```agda
fermat-collapse : ∀ y → ((y ⊗ y) ⊗ y) ≡ y
fermat-collapse T₀ = refl
fermat-collapse T₁ = refl
fermat-collapse T₂ = refl
```

**结论**：Alpöge 反例的 "c=0 → 三次退化二次 → 根逃逸" 机制在 GF(3) 上被 Fermat 坍缩提前消解。三次项在函数层面等同于线性项。

### 诊断 5：全局矩阵——无逃逸的精确判定

在 ℂ³ 上，不存在可计算的"全局矩阵"——空间是无限的。在 T⁶ 上：

```agda
-- jac_NMatrix.agda
funcTable : (GF3² → GF3²) → Mat9    -- 9×9 函数表矩阵
funcTable F i j = toTrit (encode9 (F (decode9 j)) ≟ i)

-- 每列恰有一个 T₁, 在行 encode9(F(decode9 j))
-- det ≠ 0 ⟺ 列互异 + 无全零行 ⟺ F 双射 (0 postulate)
detNonzero↔bij : ∀ F → DetNonzero (funcTable F) ↔ (Inj2 F × Surj2 F)
```

**Alpöge 反例在离散环面上的表现**：
- 如果 Alpöge 的 F 定义在 T⁶ 上，`funcTable F` 是一个 729×729 矩阵
- 三个坍缩点会对应三个**相同的列**（因为它们映射到同一行）
- 函数表矩阵有两列完全相等 → det = 0
- 全局矩阵**直接检测到坍缩**，无需无穷远

## 三、为什么 Alpöge 的三次退化在环面上失效

### 完整的因果链

```
Alpöge 反例 (ℂ³):
  P(T) = cT³ - 2T² + bT - 2a = 0
  当 c=0: 三次→二次, 3个根→2个根, 第3个根→射影无穷远
  需要: (1) 射影无穷远存在 (2) 三次≠恒等

大衍环面 (GF(9)²):
  (1) 射影无穷远不存在 → 第3个根无处可去
  (2) Fermat 坍缩: y³=y → 三次项在函数层面被吸收
  (3) 全局矩阵 M_F 直接捕获坍缩 → 列相同 → det=0
```

### 离散环面上的 Alpöge 等价物

Alpöge 的 3-to-1 坍缩在 GF(9)² 上有精确的离散对应物：

```
F(x,y) = (x, y + α·y³)
→ det J_formal = 1 (Frobenius 盲区)
→ det J_Δ = 1+α ≠ 0 (差分仍不充分)
→ det M_F = 0 (全局矩阵正确检测)
→ 3-to-1 坍缩: 81点 → 27像
```

**区别**：GF(9)² 的坍缩机制是 Frobenius 核（α·y³），不是无穷远逃逸。两者都产生 3-to-1，但机制**独立且不可互约**。

## 四、离散射影几何的核心定理

> **在闭合的离散环面 T⁶ 上，不存在射影无穷远。全局函数表矩阵 M_F 捕获所有格点转移，其行列式非零与双射性等价（鸽巢原理）。**
>
> **Alpöge 反例在 ℂ³ 上成功，是因为：**
> 1. ℂ³ 几何不闭合 → 需要射影紧化 → 引入无穷远超平面
> 2. char 0 无 Frobenius 共轭 → 三次项保持独立 → c=0 退化时根逃逸
>
> **这两个条件在 T⁶ 上都不成立。环面的几何闭合性和 GF(3) 的原生 Frobenius 共轭共同保证了全局矩阵的完备性。**
>
> **经典 JC 的失败，不是多项式映射的失败，而是基础空间和代数基础的选择错误。**
