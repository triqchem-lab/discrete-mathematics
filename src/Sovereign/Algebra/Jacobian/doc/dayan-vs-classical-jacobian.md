# 大衍框架 vs 经典雅可比猜想：两种数学范式的根本区别

> 核心论点：大衍框架不是在解经典雅可比猜想，而是在离散基座上重建了它的困难结构，并给出了该结构下的完全解答。

---

## 一、工作域与数学基础

| 维度 | 经典雅可比猜想 | 大衍框架 |
|------|---------------|---------|
| 工作域 | ℂ (特征0, 阿基米德域) | GF(3), GF(9), T⁶ (特征p, 离散紧致) |
| 连续性 | 无限、连续 | 有限、离散 |
| 无穷远 | 存在 — 根可逃逸到射影无穷远 | 不存在 — 环面绝对封闭 |
| 多项式身份 | 形式多项式环 ℂ[x₁,...,xₙ], x³≠x | 函数空间 GF(3)^{GF(3)}, x³=x (Fermat 坍缩) |

**Fermat 坍缩**是大衍框架的基石：在 GF(3) 上，x³ ≡ x 作为函数恒等，但 ∂(x³)/∂x = 3x² = 0 — 这就是 Frobenius 盲区的代数本源。

## 二、雅可比对象

| 对象 | 经典 | 大衍 |
|------|------|------|
| **局部判据** | 形式导数 ∂Fᵢ/∂xⱼ (n×n 行列式) | 差分算子 ΔF = S∘F - F |
| **全局判据** | (不存在) | **函数表矩阵 M_F** (pⁿ×pⁿ, 鸽巢完备) |
| 失效机制 | 无穷远逃逸 (根逃入射影平面) | Frobenius 核坍缩 (3-to-1 有限) |
| 判定结论 | n≥3 被证伪 (Alpöge 2026) | **M_F 行列式 ≠ 0 ⟺ 双射 (0 postulate)** |

三层雅可比强度：

```
 形式导数 (最弱, Frobenius 盲区)
   < 差分算子 (无盲区, 但仍是局部条件)
     < 函数表矩阵 M_F (全局, 鸽巢完备)
```

## 三、失效机制的本质

### 经典：无穷远逃逸

Alpöge 三维反例中，三次方程在坍缩点 c=0 退化为二次方程，第三个根游离到射影无穷远：

```
P(T) = cT³ - 2T² + bT - 2a = 0
当 c=0: P(T) = -2T² + 1/2 = 0 → 只有 2 个根, 第 3 个根在无穷远
```

### 大衍：Fermat 坍缩 (有限, 可枚举)

GF(3) 上：∂(x³)/∂x = 3x² = 0。形式导数看不到 x³ 的贡献，但实际上 x³≡x —— 局部判据失效，全局判据（函数表矩阵）依然完备。

GF(9) 上：差分算子也失效——`det J_Δ = 1+α ≠ 0` 但 F 仍 3-to-1 坍缩。

**离散环面无无穷远 → 全局判据自然完备。**

## 五、大衍框架的四大使命

### 1. 拆穿"复数投影层"的伪装

ℂ 只是 GF(p) 在 "特征 0 极限" 下的解析投影。投影过程中：
- Frobenius 共轭 (x↦x^p) 的零导数效应被掩盖
- 被掩盖的效应在投影层表现为 "射影无穷远"

大衍回到原生离散层，让原生代数共轭重新可见。

### 2. 建立离散完备可逆性理论

| 层次 | 判据 | 状态 |
|------|------|------|
| 局部 | 形式导数 / 差分算子 | 被证伪 (GF(3)²/GF(9)² 反例) |
| **全局** | **函数表矩阵 M_F** | **0 postulate 完备 (鸽巢)** |
| 组合 | 穷举 + 形式化 | Python 59,049 / Agda 8884行 |

### 3. 用形式化验证封装修辞陷阱

8884 行 Agda (0 postulate) 严格区分：
- 形式多项式环 GF(3)[x] (x³ ≠ x)
- 多项式函数空间 GF(3)^{GF(3)} (x³ = x)

杜绝"重言式冒充定理"和 BCW 规约的 Fermat 坍缩歧义。

### 4. 为算术几何提供"可计算的镜像"

| 经典概念 | 大衍镜像 |
|---------|---------|
| 射影无穷远 | Frobenius 共轭 (x↦x³) |
| 拓扑紧性 | 鸽巢原理 (729 点) |
| 雅可比矩阵 J(F) | 函数表矩阵 M_F |

## 六、对"局部→全局"元问题的贡献

大衍框架的 **终极形式化注脚**：

> 在离散环面上，局部信息 (导数/差分) 永远不够——因其被 Fermat 坍缩掩盖。
> 只有全局信息 (函数表矩阵) 可以决定双射性——因其保有完整的组合结构。

**大衍不是在解雅可比猜想，而是在离散基座上重建了它的困难结构，并给出了该结构下的完全解答。**
