# 离散雅可比定理 — 反例提交与验证标准 (RFC-DJC-1)

> **版本**: 1.0 | **日期**: 2026-07-25 | **状态**: 现行标准
>
> 大衍离散雅可比定理声明：在闭合离散环面 T⁶ (GF(3)⁶, 729 格点) 上，
> 任意映射 F 的全局函数表矩阵满足 `det(M_F) ≠ 0 ⟺ F 是双射`（0 postulate, Agda 形式化）。
> 本标准规定对该定理提出反例时必须满足的条件与验证流程。

---

## §1. 适用范围

本标准适用于以下两类声明：

| 类型 | 描述 |
|------|------|
| **A 型反例** | 声称"存在映射 F 使得逐点雅可比条件成立但 F 非双射" |
| **B 型反例** | 声称"存在映射 F 使得全局矩阵条件成立但 F 非双射" |

**A 型反例**已被大衍框架本身的形式化反例覆盖（GF(3)² 和 GF(9)²），不需重复提交。
本标准主要规范 **B 型反例**。

## §2. 反例必须满足的三重条件

提交 B 型反例的映射 F 必须**同时满足**以下三个条件。任何一个条件不满足，反例不被受理。

### 条件 1：几何闭包

```
基础空间必须是闭合环面 Tⁿ = (S¹)ⁿ 或其离散剖分。
不接受以 ℂⁿ 或 ℝⁿ 等非紧致欧氏空间为基础空间的构造。
```

| 要求 | 规范 |
|------|------|
| 空间类型 | GF(p)ⁿ，p 为素数，n ≤ 6 或任意正整数 |
| 闭合性 | 无射影无穷远，所有点有唯一有限索引 |
| 编码 | 必须提供格点 ↔ Fin N 的双射编码 |

**不合格示例**: "在 ℂ³ 上定义 F(x,y,z)=...，证明在射影紧化 ℂℙ³ 上..."（ℂ³ 非闭合，拒绝）

**合格示例**: T⁶ = GF(3)⁶，`t6ToFin`/`finToT6` 双射，729 格点穷尽。

### 条件 2：代数共轭

```
基础域必须原生包含 Galois 共轭结构。不接受通过"排除复共轭"
或"仅考虑全纯映射"避开了 Frobenius 自同构的构造。
```

| 要求 | 规范 |
|------|------|
| 域特征 | p > 0（推荐 p=3） |
| Frobenius | σ(x) = x^p 必须作为域自同构可见 |
| 共轭导数 | σ'(x) = px^{p-1} ≡ 0 的效应必须被显式处理 |

**不合格示例**: char 0 域上仅使用全纯映射，排除复共轭。（Frobenius 不可见，拒绝）

### 条件 3：描述完备

```
必须提供全局函数表矩阵 M_F 的显式定义，并计算其行列式。
不接受仅提供"逐点雅可比行列式处处非零"的局部条件。
```

| 要求 | 规范 |
|------|------|
| 矩阵类型 | Mat(N×N, base-field)，N = |空间格点数| |
| 行列式 | 提供 M_F 的构造 + det(M_F) 的计算或结构证明 |
| 等价性 | 接受 `det ≠ 0 ⟺ 列互异 ∧ 无零行` 的结构论证 |

**不合格示例**: "对每个点 x，det J(F)(x) = 1 成立，但 F 非双射。"（仅局部条件，拒绝）

## §3. 提交格式

### 3.1 必需材料

```
提交目录/
├── mapping.agda        # F 的 Agda 定义
├── matrix.agda         # M_F 的构造 + 行列式或等价判定
├── nonbij.agda         # 非双射证明（碰撞见证或非满射见证）
└── README.md           # 摘要：空间、域、映射公式、错误点
```

### 3.2 Agda 模块头规范

```agda
-- | 反例提交: [标题]
-- 目标: B 型反例 - 声称 det(M_F) ≠ 0 但 F 非双射
-- 基础空间: GF(p)ⁿ, N = pⁿ 点
-- Frobenius: σ(x) = x^p 在域自同构中可见
-- 矩阵: M_F 为 N×N 函数表矩阵
-- 见证: 提供碰撞对 (p,q) 或遗漏点 r
```

### 3.3 反例摘要格式

| 字段 | 内容 |
|------|------|
| 提交者 | [姓名/机构] |
| 日期 | YYYY-MM-DD |
| 空间 | GF(p)ⁿ, p=?, n=?, N=? |
| 映射公式 | F: GF(p)ⁿ → GF(p)ⁿ 的显式表达式 |
| 矩阵构造 | M_F 的定义或等价判定方式 |
| 非双射见证 | 碰撞对 p≠q, F(p)=F(q) 或遗漏点 r |
| Agda 模块 | 文件名列表 |

## §4. 验证管线

提交者**不要求**自己完成 Agda 证明——但反例构造必须足够精确，使以下管线可执行：

```
步骤 1: 导入反例 → 加载 mapping.agda, matrix.agda, nonbij.agda
步骤 2: 检查三重条件 → 几何闭包 (Fin N 双射) + 代数共轭 (Frobenius 可见) + 描述完备 (M_F 定义)
步骤 3: 计算全局判定 → 应用 detNonzero↔bij 定理 (jac_NMatrix.agda)
步骤 4: 对比见证 → 若 F 非双射，M_F 必有两列相同 (碰撞) 或全零行 (遗漏)
步骤 5: 编译验证 → agda nonbij.agda → 0 错误 → 反例被确认
```

**反例被确认的条件**: 所有模块编译通过 (0 错误)，且 `nonbij.agda` 中的 `Fp≡Fq` 或 `¬Surj` 见证被 Agda 接受。

**反例被拒绝的条件**: 任何模块编译失败，或三重条件中任一不满足，或 `jac_NMatrix.detNonzero↔bij` 定理导出与见证的矛盾。

## §5. 不适用声明

以下情况**不构成对本定理的有效反例**：

| 情况 | 理由 |
|------|------|
| 基础空间为 ℂⁿ（非闭合） | 不满足几何闭包条件 §2.1 |
| char 0 域（排除 Frobenius 共轭） | 不满足代数共轭条件 §2.2 |
| 仅提供逐点雅可比条件 | 不满足描述完备条件 §2.3 |
| 在连续域上构造但声称"可以离散化" | 必须提供显式离散构造，不接受"原则上可化" |
| 依赖未定义实体的哲学论证 | 本标准接受 Agda 编译输出作为唯一判决依据 |

## §6. 判决权威性

> **Agda 类型检查器是本标准的唯一判决权威。**
>
> 审稿人不需要信任提交者——他们只需要信任 Agda 的类型检查器。
> 编译通过 = 反例有效。编译失败 = 反例无效。
>
> 对于是否满足三重条件的争议，同样由 Agda 代码中的类型声明裁定。
