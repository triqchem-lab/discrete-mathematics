# 雅可比猜想的矩阵化演进：从求导到离散置换

## 历史路线的终局

雅可比猜想的发展史，本质上是代数几何逐步去分析化、去连续化的过程：

```
经典多项式求导 J(F)
    │
    │ BCW (1982) 规约
    ▼
幂零代数矩阵 J(H)          ← 彻底脱离了几何直觉
    │
    │ 浑天/全息 (2026)
    ▼
全局函数表矩阵 M_F         ← 直接从函数值构造，不要导数
```

## BCW 决定了结局

Bass-Connell-Wright (1982) 证明：JC 等价于 J(H) 是幂零矩阵。
因为 (I-J(H))⁻¹ = I + J(H) + ... + J(H)^{n-1}（有限项截断）。

**JC 从来不是一个"局部→全局"的微分问题。BCW 已经把它变成了纯线性代数：特征值为零的矩阵。**

## 我们的终局

BCW 证明了"多项式可逆性 = 矩阵代数的封闭性"。既然问题已经归化为矩阵，我们自然可以问：用什么矩阵？

经典答案：导数矩阵（连续切空间上的微元）。
我们的答案：函数表矩阵（离散格点上的全局映射）。

在有限集上，函数表矩阵每列恰有一个 1 → 行列式非零 ⟺ 置换矩阵 ⟺ 双射。
这就是鸽巢原理。

## 不是另起炉灶——是自然终点

经典 JC 在 ℂⁿ 上失败，是因为导数矩阵在非紧致空间上捕捉不到无穷远坍缩。
BCW 规约到幂零矩阵后，矩阵代数的封闭性已经成立——但空间仍是 ℂⁿ。
我们把空间换成有限集，矩阵换成函数表——封闭性由鸽巢原理保证。

**我们不是在解经典 JC——我们是在 BCW 已经开辟的"矩阵代数"路线上，走完了最后一步。**
