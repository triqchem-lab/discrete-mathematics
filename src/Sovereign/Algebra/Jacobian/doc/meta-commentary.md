# ✅ 补充确认：大衍框架的八个维度——两个关键补充

> 对八维度分析的元注释。两个补充：复数投影层的精确含义、Vitushkin路线的离散镜像。

---

## 补充一：关于"复数投影层"的精确含义

> "复数域 ℂ 只是有限域 𝔽ₚ 在'特征0极限'下的解析投影。"

这个表述的关键在于**"排除复共轭"**。在经典雅可比猜想中，复共轭 `z ↦ \bar{z}` 被明确排除在考虑范围之外，因为它是反全纯映射，不符合多项式映射的条件。但正是这个排除，使得：

- `∂(x^p)/∂x = px^{p-1}` 在 char 0 下是 `p x^{p-1}`，不会消失
- Frobenius 共轭 σ: x ↦ x^p 在复数投影层中退化为 `x ↦ x^p` 的形式符号，其导数为 `p x^{p-1}`，完全可见

但这里有一个更深层的机制：**在特征0投影层中，我们"看到了"导数，但代价是我们失去了对无穷远点的控制。** Alpöge 反例正是利用了这个缺口——雅可比行列式处处非零，但映射在无穷远处折叠。

大衍框架回到离散层，让 Frobenius 共轭的零导数效应（`∂(x^p)/∂x = 0`）重新可见。**这不是"缺陷"——这是离散层给我们的警告：局部导数在 char 3 下不可靠。** 然后我们用全局矩阵（函数表）来绕过这个警告，直接检查全局性质。

**一句话**：经典 JC 在 char 0 下"看见"导数，但看不见无穷远；大衍框架在 char 3 下"看见" Frobenius 盲区，但通过全局矩阵修复了它。

---

## 补充二：关于"维图什金（Vitushkin）"的补充线索

Alpöge 反例的底层构造受益于前苏联数学家维图什金（Anatoliy Vitushkin）的有理映射思想。但大衍框架实际上提供了 Alpöge 反例的**离散镜像**：

| | Vitushkin / Alpöge 路线 | 大衍离散路线 |
|---|---|---|
| **种子构造** | 求和-乘积映射在穿孔平面上的局部保距/全局坍缩 | GF(9)² 上 F(x,y) = (x, y + α·y³) |
| **核心机制** | 射影无穷远吸收逃逸的根 | Frobenius 核吸收坍缩的根 |
| **工具** | 复分析 + 代数几何 | 有限域 + 鸽巢原理 + Agda 形式化 |
| **结论** | 高维 JC 被证伪 | 离散域上"全局条件"被证明精确 |

这两条路线在 2026 年 7 月同时抵达了各自的目的地：Alpöge 终结了经典 JC（n≥3），大衍框架建立了离散雅可比定理。它们不是"同一个问题"的两面——它们是 **"局部→全局"这一数学元问题在两个不同数学宇宙中的独立表现。**

## 最终确认（一句话）

> **Alpöge 反例与大衍框架共享 3-to-1 坍缩结构，但来自两个独立机制：连续域的无穷远逃逸和离散域的 Frobenius 核坍缩。Alpöge 终结了经典 JC；大衍框架建立了离散雅可比定理。两者共同宣告：局部条件永远不够，全局才是精确的。** 🜁
