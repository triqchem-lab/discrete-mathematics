## 核心同构：三重完备性 ↔ 三重防火墙

文献诊断确立了 RH/GRH 闭合证明的**三重完备性结构条件**（元理论筛网）。该条件与大衍雅可比项目的**三重防火墙**精确对应：

| RH/GRH 三重完备性（诊断报告） | 雅可比三重防火墙（Jacobian/README） | 连续路线失败原因 | 离散闭合机制 |
|---|---|---|---|
| **几何闭包**：吸收无穷远逃逸，将连续谱泄漏转化为可控离散谱 | **几何闭包**：T⁶ 环面天然闭合，无射影无穷远 | SpecZ 缺无穷远素数的代数紧致化 | T⁶ ≅ Fin 729 天然有限闭合 |
| **原生代数共轭**：特征 0 中需具备代数刚性的原生 Frobenius 自同构 | **代数共轭**：GF(9) Frobenius σ(x)=x³ 原生可见 | 特征 0 无刚性 Frobenius（Λ-环 ψₚ 仅单射非自同构） | GF(9)/GF(3) Frobenius 原生双射 |
| **无循环全局谱算子**：构造独立的全局矩阵/算子 H，谱等价于 ζ(s) 零点 | **描述完备**：全局矩阵 M_F 精确捕获所有格点转移 | 连续谱污染 / 正性假设循环等价于 RH | 函数表矩阵 det(M_F) 有限可判 |

**结论**：五大连续路线（F₁ 几何、算术动力系统、非交换几何、完美oid 几何、量子拓扑）各自在三重条件的某一环断裂。大衍 GF(3)/T⁶ 框架**天然满足全部三重条件**——这正是雅可比项目能 0-postulate 闭合的根本原因。

## 研究路线

### 阶段 1：离散 RH 命题陈述（当前）

RH/GRH 的标准表述是解析数论的（ζ 的非平凡零点都在 Re(s)=1/2 线上）。在项目宪法下（禁无理数等式、谱截断定理），必须先建立**离散 RH 的命题陈述**——类比雅可比将"连续雅可比猜想"转译为"有限集双射判据"。

候选离散载体：
- **有限域 zeta**：Z(N, q) = det(I - q·Frob | H¹_c(X))，在有限域曲线 X/𝔽_q 上，RH 由 Weil 证明（Frobenius 特征值模长 q^{1/2}）
- **有限群特征 L 函数**：Dirichlet L(s, χ) 在有限 Abel 群上的截断
- **CRT 谱投影**：ζ(s) 的零点分布经 CRT 投影到 ℤ/Mℤ 的余数向量空间

### 阶段 2：全局谱算子的离散构造（规划）

类比雅可比的函数表矩阵 M_F，构造 ζ/L 函数对应的**有限判据矩阵**，使得：
- 其行列式/特征值的离散性质等价于零点分布
- 在 GF(3)/T⁶ 载体上可穷举验证
- 0 postulate

### 阶段 3：GRH 推广（规划）

GRH 涉及 Dirichlet L 函数族，推广需处理：
- 特征 χ 的离散化（有限群上的特征）
- 一致性零点估计（GRH 比 RH 更强）
