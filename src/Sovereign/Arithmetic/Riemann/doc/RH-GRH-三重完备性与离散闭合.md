## 一、元理论筛网：三重完备性结构条件

文献诊断报告确立了一套不依赖单一学派的"元理论筛网"——任何声称闭合 RH/GRH 的证明必须同时满足三个结构条件：

### 条件一：几何闭包（Compactifying Mechanism）

> 代数数论中的非紧空间（复平面 ℂ、算术谱 Specℤ、阿代尔商空间 𝔸_ℚ/ℚ*）
> 在无穷远素数处缺乏自然的代数紧致化。完备框架必须能在几何上吸收无穷远逃逸，
> 将连续谱泄漏转化为可控的离散谱。

**连续路线的诊断**：
- F₁ 几何：局部满足（球面谱 S 给出亏格 0 紧致化描述），但无法导出高维迹公式
- 算术动力系统（Deninger）：**不满足**——无穷维叶状空间 X 缺乏拓扑紧致性
- 非交换几何（Connes）：高度满足——阿代尔商空间统一吸收有限/阿基米德素数
- 完美oid 几何：p-进局部完备，**全局断裂**——X_FF 与 Twistor P¹ 无法全局黏合
- 量子拓扑：**不满足**——xp 相空间非紧

### 条件二：原生代数共轭（Native Frobenius Automorphism Analog）

> 正特征域 𝔽_p 上的 Galois 动力学由代数 Frobenius σ(x)=x^p 驱动，
> 其与转置图的交点数直接保证特征值模长 q^{1/2}（即 Weil RH 成立）。
> 完备框架必须在特征 0 中显式构造出具备代数刚性的原生自同构。

**连续路线的诊断**：
- F₁ 几何（Borger）：概念性满足但代数刚性不足——Λ-环的 ψₚ 是单射同态**而非自同构**，缺逆映射 ψₚ⁻¹
- 算术动力系统：**结构不匹配**——以连续李代数生成元 D 替代离散 Galois 自同构
- 非交换几何：**不满足**——以 ℝ₊* 的模群作用（连续物理流）替代 Frobenius
- 完美oid 几何：**局部原生满足**——倾斜/解倾斜提供完美 p-进 Frobenius
- 量子拓扑（IUTT）：不同维度——Θ-link 破坏经典代数结构而非建立自同构

### 条件三：无循环全局谱算子（Non-circular Global Spectral Operator）

> Hilbert-Pólya 范式要求构造独立的、有限或紧致的全局算子 H，
> 其谱特征精确等价于 ζ(s)/L(s,χ) 的非平凡零点，且构造与自伴性证明
> **不得隐式预设 RH 本身**。

**连续路线的诊断**：
- F₁ 几何：**未闭合**——无显式希尔伯特空间
- 算术动力系统：形式化满足但算子未定义——D 的定义域与自伴性未确立
- 非交换几何：条件满足（吸收光谱），但**正性假设循环**——证明迹公式二次型的正性逻辑等价于 RH
- 完美oid 几何：**未建立全局算子**
- 量子拓扑：**不满足**——xp 谱为全实轴连续谱，截断破坏自伴延伸

## 二、大衍雅可比三重防火墙：天然的完备性满足

雅可比项目（`src/Sovereign/Algebra/Jacobian/`，19 模块 ~10480 行，0 postulate）建立了"三重防火墙"，阻断经典反例：

| 防火墙 | 内容 | 对应完备性条件 |
|--------|------|---------------|
| **几何闭包** | T⁶ 环面天然闭合，无射影无穷远 | 条件一：几何闭包 |
| **代数共轭** | GF(9) Frobenius σ(x)=x³ 原生可见 | 条件二：原生代数共轭 |
| **描述完备** | 全局矩阵 M_F 精确捕获所有格点转移 | 条件三：无循环全局谱算子 |

### 为什么大衍框架天然满足三重条件

**条件一（几何闭包）的离散满足**：
- T⁶ ≅ Fin 729 是有限闭合环面——不存在"无穷远逃逸"问题
- 离散连续界面规范 v7.0 §一：连续物理量是离散拓扑 Z₁₄₄×Z₄₆ 在 CRT 余数坐标系下的投影
- 连续路线的"无穷远素数紧致化"问题，在有限载体上根本不出现

**条件二（原生共轭）的离散满足**：
- GF(9) = GF(3)[α]/(α²+1) 的 Frobenius σ: α ↦ -α 是**原生双射自同构**（非单射同态）
- 与 Borger 的 Λ-环 ψₚ（仅单射）形成鲜明对比：大衍 Frobenius 有逆映射
- Gal(GF(9)/GF(3)) ≅ C₂，σ² = id，满足完整的双向对称相交理论

**条件三（无循环算子）的离散满足**：
- 函数表矩阵 M_F 是有限矩阵，det(M_F) 有限可判，**无连续谱污染**
- `detNonzero↔bij` 定理：det(M_F)≠0 ⟺ F 双射，证明不预设任何谱假设
- 与 Connes 的正性循环不同：M_F 的行列式是有限组合事实，可 0-postulate 闭合（`theorem-maximality` 从 postulate 变为 refl）

## 三、离散 RH/GRH 命题方向

### 核心张力

RH 的标准表述（ζ 的非平凡零点都在 Re(s)=1/2 线上）涉及：
- 无理数 t（零点 1/2+it 中的虚部）
- 连续解析延拓
- 无穷零点序列

项目宪法（界面规范 v7.0 §二.3）禁止将无理数写成等式（谱截断定理：±2√10 → ±16 mod 216）。因此 RH 必须经过**离散化转译**，类比雅可比将连续 JC 转译为 `det(M_F)≠0 ⟺ 双射`。

### 候选离散化路径

**路径 A：有限域 zeta（Weil 路径）**

Weil 在函数域上证明的 RH：有限域曲线 X/𝔽_q 的 zeta 函数
```
Z(X, q^{-s}) = P₁(q^{-s}) / P₀(q^{-s})P₂(q^{-s})···
```
其零点的 Frobenius 特征值模长为 q^{1/2}。这是已证的"离散 RH"。

大衍载体映射：GF(3) 上的曲线，Frobenius σ(x)=x³ 原生可用。

**路径 B：CRT 谱投影的零点判据**

ζ(s) 的零点分布经 CRT 投影到 ℤ/Mℤ 余数空间。
类比雅可比的 `det(M_F)`，构造 ζ 对应的**有限判据矩阵**，
使零点分布等价于矩阵的某种离散性质（行列式/特征值）。

**路径 C：特征和的离散闭合**

GRH 的核心推论之一是 Dirichlet 特征和的界：
```
|Σ_{n≤N} χ(n)| ≤ √N · log N   （GRH 下）
```
在有限群上，特征和是有限可判的，可能存在 0-postulate 的离散闭合。

### 研究原则

1. **不预设连续 RH**：离散 RH 的命题陈述和证明不得隐含假设连续版本成立（避免 Connes 式正性循环）
2. **0 postulate 优先**：与雅可比一致，能构造性闭合就不 postulating
3. **载体合规**：严格在 GF(3)/GF(9)/T⁶ 上操作，不引入 Float/无理数等式
4. **穷举优于解析**：论域有限就用 case 穷举 + 矩阵判据

## 四、五大连续路线失败机制 → 离散对应

四大失稳机制本质上是**连续统作为代数数论基座时的结构性缺陷**（详见 `docs/Riemann/RH-GRH-元数学定位与阴阳研判.md`）。连续统不是中性画布——它自带滑动、变形、泄漏，在局部微分几何中是恩赐，在全局算术问题中是诅咒。

| 连续失败机制 | 元数学本质 | 连续路线·错误码 | 大衍离散闭合 |
|---|---|---|---|
| 连续谱污染 | 连续统缺乏离散阻隔，离散性与非紧性是范畴冲突 | Connes `Circular positivity`; BK `Self-adjoint truncation` | T⁶ 有限闭合，无连续谱 |
| 刚性 Frobenius 缺失 | σ(x)=x^p 是刚体（导数为 0），连续流是软体（导数非 0） | Deninger `Missing Frobenius rigidity`; Borger `Motivic narrowness` | GF(9) σ 是导数为 0 的双射自同构 |
| 循环论证 | 阻止谱泄漏的正性条件 ⟺ RH，构成逻辑事件视界 | Connes `Circular positivity assumption` | det(M_F) 是组合事实，无循环 |
| 局部-全局割裂 | 阿基米德绝对值天然抵抗特征 p 倾斜 | FF `Local-to-global glue failure` | T⁶ 单一全局载体，无割裂 |

**审查范式**：三重完备性是一台类型检查器。凡未显式回答三条件的方案，可直接判定为底层类型失配。审查权已从社会学共识转移到构造性逻辑的编译检查。
