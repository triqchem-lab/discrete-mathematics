## 4. 诚实边界

1. **实验层是数值模拟, 非湿实验**: scholar-loop 的 FOM 来自环量子场声子模型的
   torch 模拟（冻结评分）; 物理常数真实（N14 NQR 3.17 MHz、石英声速 5720 m/s、
   α→β 居里温度 846.15K、Debye 温度 470K, 常数注释均带来源审计标记 P1-P5）。
2. **训练观测是模型训练步进中的动力学量**（测地线弧长/陈数近似/相变计数）,
   不是独立于训练的外部测量。
3. 与 Agda 侧口径一致: 这些锚定在形式化库中登记为 **B 类物理锚定
   （genuine bridge 合法公理）**, 不计入 "0 postulate" 宣称范围;
   教义类断言（不可拆解/禁约分）已升级为 **0-postulate 可证定理**
   （`PlatonicTorusProjection` / `HolographicPi`）。
4. 快照纪律: 引用实验数字时注明批次（早期 23/20 快照 vs v4.2 的 37+/34+）。
