### ⚠️ 设计缺口（A0）—— 排计划时暴露的，必须先裁决

我原以为「界内」是单侧上界 `k < L`。**不是**：

- `tShiftR (tL k) = tL (suc k)` ⟹ 左侧索引**增长**；
- `tShiftL (tR k) = tR (suc (suc k))` ⟹ 右侧索引**增长 2**；
- 因此「平移保持界内」（A8）在单侧上界下**不成立**：最边上的格平移后就越界。

两条候选：

| | (a) 固定双侧界 | (b) 按时间参数化的双侧界 |
|---|---|---|
| 形状 | `InOff o = (idx_L o < TL) × (idx_R o < TR)`，`TL = T+1`、`TR = len+T+1` | `InOff t o`，行 t 的偏移限制在 `[−t, len−1+t]` |
| A8 的证明 | 需要「平移 ±1/±2 后仍在固定界内」⟹ 对边界格**不成立**，只能对「远离边界」成立 ⟹ 子句族得避开边界 ⟹ **会漏掉真实运行**（头可能走到边界） | 归纳：t 行的偏移界 ⟹ t+1 行界自动扩张，平移恰好落在新界内 ✓ **闭合** |
| 代价 | 低但有洞 | `InOff` 带 `t` 参数，子句族生成也要带 `t`（本来就带） |

**建议 (b)**。若采纳，(a) 行的 A3/A8 形状随之改为 `InOff (t : ℕ) (o : TOff)`。

## 执行纪律（自定，逐条可查）

1. **一次一个原子任务**，写完立刻编译；失败只改该任务范围内的东西。
2. **不留跨任务半成品**：任一时刻工作区必须 `EXIT=0`。
3. 每完成一层，跑一次该层全部文件的编译并记录 `EXIT` 与行数。
4. 层 A 的 A0 裁决**必须**先于 A1——否则 A3/A8/C5 全部要返工。
5. 已知算术义务只有两处：A8（平移保持界内）与 B4（`combine` 往返由 stdlib 承担）。
6. 与 M1/M2/M3a/M3b 的接线处只读不写（那些文件已冻结在 `EXIT=0`）。

## 与「不要搞简化」的对照

本表刻意**不合并**任务：例如 A1/A2 只是两个 3 行定义，也各列一行；C1–C3 三族 oneHot 看起来同形，但各自的池维度不同（逐 `(t,o)` / 逐 `t` / 逐 `t` × 偏移），合并会把「维度搞错」这类错误藏进去。
