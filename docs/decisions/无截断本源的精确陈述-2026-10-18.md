## 一、先撤销：三个词被禁用的理由

| 被禁用的表述 | 为什么是连续统的 | 离散第一性下的替代 |
|---|---|---|
| `lim Ωⁿ` | 极限依赖序列 + 完备性 | 离散结构**没有极限**；只有并列的有限组合对象 |
| `∞-groupoid` | 可数层塔 + 无限相容性条件 | 塔本身是维度/层级概念；离散侧只有**这一张图**的结构 |
| 「截断到 n 阶 / τₙ」 | n 来自 `Sⁿ` 的维度（依赖 `ℝⁿ`）与迭代序结构 | **截断与否只看「生成方式丢没丢」，不看 n** |

**逻辑要点**：`Ω¹, Ω², Ω³, Ω⁴` 不是「阶梯的层」，而是**并列的、各自完整的离散对象**（不同的等价关系给出不同的商）。
把它们排成塔、再取极限——**这一步就是连续统投影**。

## 二、精确陈述（定义形，可检验）

> 依据：展示群八要素（`docs/duodecimal/11-type-theory-presentation.md`；`memory/definition-start-point-and-truncation-criterion.md` §一）

**定义 D1（本源级表述）**
一个表述 `O` 是**本源级**的，当且仅当 `O` 由**生成方式**给出，即同时给出八要素：

| 要素 | 判据（缺一即非本源级） |
|---|---|
| ① 载体 | 元素是什么（如 `DuodecPoint = Trit × AlphaPower`） |
| ② 生成元 | 由什么代数来源生成（GF(3) 加法 / GF(9)⟨α⟩ 乘法） |
| ③ 关系 | record **字段**（不是 HIT 构造子）：`δ³=id`、`φ⁴=id`、`δφ=φδ` |
| ④ 相位 | 每元素**不可约**携带的 C₄ 位置（**不可**约化为 {±1}） |
| ⑤ 时钟 | 迭代**过程**（`mixedOp^12` 走钟），**不是**「阶 = 12」静态事实 |
| ⑥ 归零 | 零冥族五字段（零 ≠ 空） |
| ⑦ 刚性 | Frobenius σ: x↦x³ 诱导 |
| ⑧ 核对 | `refl` 仅确认自洽，**不产生结构** |

**定义 D2（截断）**
表述 `O'` **相对** `O` 是**截断**的，当且仅当从 `O` 到 `O'` 有一个信息映射，且该映射**命中下列三层判据之一**：

| 层 | 判据 | 丢失物 |
|---|---|---|
| T1 数值群化 | 把相位/展示群降格为数值群刻画（`π₁=ℤ`、`θ∈ℝ/2πℤ`、`C₁₂/R₁₂/Doz` 当本源、CRT 当模算术） | 生成来源 + 关系体系 |
| T2 非忠实商 | 商把结构等同掉（`C₄→C₂`：1 = −1；范数 4→1） | **结构性相位**（相位不可约性元公理） |
| T3 维数塌缩 | 标量(l=0)/1D/2D 处理丢掉 3D+ 矢量相位 | 球谐矢量相位 |

**定义 D3（无截断本源 = 本项目的目标谓词）**

```
Untruncated(O)  ⟺  D1(O)  ∧  ¬(∃ O'. O ⟶ O' 命中 T1/T2/T3)
```

**即**：一个表述既是**本源级**（八要素齐），又**没有**任何一步把结构信息丢掉。

## 三、这个定义**与 n 无关**（关键论证）

| 常见误解 | 为什么错 | 正确判据 |
|---|---|---|
| 「πₙᵈ 的 n 越大越本源」 | 维度/迭代次数是连续统的序结构；离散侧 `Ω²` 与 `Ω⁴` 是**并列**对象 | 看八要素是否齐 + 三层判据是否命中 |
| 「π₁bt 因为 n=1 所以是截断」 | n=1 只是"取一层"，**不必然丢结构** | 看它**具体丢了什么要素** |
| 「π₁ᵈ 因保留幂等结构所以是中间层」 | "中间层"是塔隐喻 | 「保留/不保留」要落到具体要素上 |

**⇒ 判据替换**：不问「在第几阶」，只问**「八要素里哪一项被丢掉了」**。

## 七、追加更正（2026-10-18 晚）：「自同构二分」应改为「自反边判据」

§五 的 A2'' 写成了「Aut 足够大 ⇒ 群 / Aut 不足 ⇒ 幂等幺半群」。**该表述已被库内事实否证**：

| 事实 | 出处 | 后果 |
|---|---|---|
| `π₁ᵈ(Gskel two-chain) ≅ (ℕ,+)` | `Watershed.gskel-classify`（A 级，MonoidIso 八字段全闭） | `(ℕ,+)` **无逆** ⇒ Gskel 侧也不是群 ⇒ 「Aut 充分 ⇒ 群」不成立 |
| `Gcmp`/`Gskel two-chain` 顶点与交叉边相同，Aut 均为顶点对换 `ℤ/2` | `_PPI4.agda:41-46`（两图定义）+ 定义层比较 | **Aut 大小相等**，故不可能是 π₁ᵈ 差异的驱动量 |
| `Q-AStep`：AStep 两沿**恒同正长** | `probes/_PPI2.agda:276-280`（已证） | 正长闭走**永远**到不了 `nil` ⇒ 幂等（非群）的**机制** |
| `Gcmp` 用 `cmpEdge = (x⊑y) ⊎ (y⊑x)`（含 refl）⇒ **有 loop**；`Gskel` 用 `KEdge = IsChain2`（Strict）⇒ **无 loop** | `_PPI4.agda:42/46`；`_PMc2.agda:85-86/101` | **真正的驱动量 = 有无自反边** |

### 7.1 A2'''（自反边判据形，取代 A2''）

```
A2'''（自反边判据 / 取代 A2'' 的 Aut 大小版）
  (i)   G 非自反（irreflexive，如 Gskel）⇒ AStep 两沿恒同正长（Q 不变量）
        ⇒ 长度 1 的闭走不可能化成 nil ⇒ π₁ᵈ(G) 保留非幂等方向
        （实例：Gskel two-chain ≅ (ℕ,+)）
  (ii)  G 自反（有点 loop，如 Gcmp）⇒ loop 可 expand 成 (e, flip e) 形两步
        ⇒ 幂等性出现（实例：Gcmp two-chain = 2 元幂等幺半群，loop⊞loop=loop）
  (iii) 若在 AStep 上加 backtrack：**自反图必然塌缩**（loop → (e,flip e) → nil；
        oracle 回执 92578b63…，Gcmp two-chain 从 2 类 → 1 类），非自反图**不受影响**（待验证）
```

### 7.2 顺带解掉待裁决 `AStep-bt` 的 (C) 条件

先前的 (C) 候选条件「排除自反边」原来是**猜**的；现在有 **Q-AStep（已证）** 作依据：

- backtrack 需要「相邻逆对 `(e, flip e)`」；
- 自反图里**任何 loop 都能 expand 成 `(e, flip e)`** ⇒ backtrack 与 slide/expand **不独立** ⇒ 塌缩；
- 非自反图里 loop 不存在，`(e, flip e)` 仍需由两条不同的边构成 ⇒ backtrack 是**新增关系**，可能安全。

**⇒ (C) 的判据升级为：只在 `¬ Reflexive G` 上开 backtrack face。** 验证方式：在 `Gskel two-chain`（非自反）上重跑同一闸门，看类数是否仍为 `(ℕ,+)` 而非塌缩为 1 类。

### 7.3 诚实边界（本节新增）

- `Aut(ℝ) = {id}`、`Aut(ℂ)` 巨大、`Aut(ℚ)` 巨大 —— 都是**标准事实**，**本库未形式化**，引用时标「标准事实，未在库内证」。
- 「特征 0 ⇒ 自同构病态」**不成立**（ℝ 是反例）；正确概括是：**超越次数 > 0 或序不可定义的域才病态**；
  有限域由 Frobenius 生成、有限刚性。
- `A2'''` 的 (iii) 后半「非自反图不受影响」**未验证**，只是由 Q 不变量推出的**待检猜想**。
- 「自同构 → 结构（信息保留）」这一**方向性主张**库内**无证据**；`Watershed.no-pi1-iso` 只证了
  「两个具体 π₁ᵈ 不同构」，**没有**把 Aut 与群性连起来。不得当作已证。

## 八、决定性更新（2026-10-18 晚二）：`AStep-bt` 在**两类图**上都会塌缩 ⇒ (C) 的条件不成立

§7.2 曾把选项 (C) 的条件定为「只在 `¬ Reflexive G`（非自反图）上开 backtrack face」。**该条件已由机器证据否证。**

**oracle 回执 `700bf9fe…`（`domain = points = 65`，完整枚举，两图同脚本）**

| 图 | 自反性 | 仅 slide/expand | + backtrack |
|---|---|---|---|
| `Gcmp two-chain` | **自反**（`cmpEdge` 含 refl ⇒ 有 loop） | **2 类**，大小 `[1,62]` | **1 类**（塌） |
| `Gskel two-chain` | **非自反**（`KEdge = IsChain2` Strict ⇒ 无 loop） | **3 类**，大小 `[1,1,1]` | **1 类**（塌） |

两图在旧 face 上的结果**分别与库内两条 A 级定理吻合**（`Watershed.no-pi1-iso` 的 2 元幂等 / `gskel-classify` 的按长度 ≅ (ℕ,+)），故本闸门有交叉验证；加 backtrack 后**两者都塌成 1 类**。

### 8.1 根因：backtrack 必然摧毁 Q 不变量（与图是否自反无关）

已证：`Q-AStep`（`probes/_PPI2.agda:276-280`）——**AStep 两沿恒同正长**。
⇒ 在 slide/expand 下，**正长闭走永远到不了 `nil`**；这正是分水岭与 `(ℕ,+)` 分类赖以成立的**唯一不变量**。
而 `backtrack` 是**唯一**能把长度 2 减到 0 的规则（`(e, flip e) → ∅`），只要图是**对称**的（`Flip G`，`_PPI4.agda:49`），相邻逆对就存在 ⇒ **Q 不变量必被摧毁**。

**⇒ 结论（推翻 (C)）**：`AStep-bt` 不是「在某些图上安全、某些图上危险」，而是**在所有对称图上都使 π₁ᵈ 平凡**。
因此 (A)(C) 都与库内已证 A-理论冲突；**唯一自洽的选择是 (B) 拒绝 `AStep-bt`**。

### 8.2 若要修逆律，只能换表述而不是加消去生成元

- 加「消去生成元」在**任何**对称图上都会撞 `Q-AStep`（已证）⇒ 此路不通（这是**定理级**约束，不是风格偏好）。
- 可行方向（**未验证，仅列候选**）：
  (α) 逆律改述为「在某子范畴上存在逆」（载体收窄，同 `_PN16` 的 `RepWord` 做法）；
  (β) 保留 backtrack 但**不认同到 `nil`**——把它做成**记录**（带权/带标签的移动），而不是消去；
  (γ) 承认 `π₁ᵈ` 一般不是群，把「逆」换成弱形式（E–H 已有先例：只需幂等 + 单位）。
- 我倾向 **(γ)**：它与 `A1c2.add2-comm-generic-status` 的既有结论（`¬` 全域交换、仅单位类/气泡类交换）同源。

### 8.3 对「框架」讨论的校准（与 §二/§七 一致）

| 层 | 内容 | 证据档位 |
|---|---|---|
| **已证（内核回执）** | `Watershed.no-pi1-iso`、`Watershed.gskel-classify`、`Q-AStep` | proves |

**这正是「GF(3) 平凡 / GF(9) 由 Frobenius 生成 C₂」的精确形式**——我此前的结论方向对，但**没给库内锚点**，现在补上。
