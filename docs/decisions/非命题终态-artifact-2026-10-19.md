## 一、要解决的是什么问题

台账里有一批节点的**陈述不是类型**：

| 类别 | 例子 | 证据形态 |
|---|---|---|
| 文档修正 | `DYPE.fix.docs.readme-claims`（纠偏 README 5 处断言）| git diff / 文件内容 |
| 审计裁决 | `QUALITY.batch0-machine`（全库机器统计底料）| 实测数字 + 可复跑脚本 |
| 流程件 | `H.pgm.rewrite-criterion-impl`（判据落地要点）| 设计文本 |
| 口径改写 | `QUAD.T4.6624-rewording` | 文档 diff |

它们的**工作确实已完成**，但按「**只有内核回执算证完**」的口径，`proven` 永远拿不到
（没有 Agda 命题可编）。于是它们此前被统一停在 `needs_review` 并写「无回执可得，请人复核」——
**诚实，但语义错位**：报表里它们表现为「未完成」，把「已做完的文档工作」混进「数学债」。

**判据（裁决原文）**：*若一个节点的证据原则上不可能是内核回执（因为它的陈述不是类型），
它就不应该出现在「未完成」栏里。*

## 二、语义定义

```
state = 'artifact'          # 非命题终态
evidenceKind ∈ { git, oracle, doc, measure }   # 必填
evidence 或 note            # 至少一项（证据指针：commit / 回执 id / 文档路径 / 命令）
```

| 口径 | 规定 |
|---|---|
| 计入 `proven`？ | **否**（`proven` 只认内核回执 + A 级内容） |
| 计入「未完成」？ | **否**（工作已完成） |
| 计入进度分子？ | **是**（`done = proven + refuted + artifact`） |
| 计入 `unfinished`？ | 否（`unfinished = total − done − abandoned`） |
| 能否满足下游 `deps`？ | **不能**（依赖仍只认 `proven`——非命题节点不承载数学内容） |

### 为什么强制 `evidenceKind`

非命题节点的危险**不是「没证明」，而是「拿文档/实测冒充证明」**。
逼它写明「证据是哪种、指针在哪」，才能与 `proven`（内核回执）在**字段层**分清——
而不是靠读者记得「这条是文档件」。

### 为什么否决 `abandoned`

`abandoned` 的字面语义是**放弃**。把「已完成」写成「放弃」是语义损失（自欺），
且已命中 `abandonedWithoutReason` 判据族。**不使用。**

## 三、实现（插件侧）

`plugins/proof-dag.mjs`：

1. `STATES` 增 `artifact`；新增 `ARTIFACT_KINDS` 与 `checkArtifact()`（强制校验）。
2. **三条通道全部校验**：`add` / `update` / `import`（**批量通道不豁免**——与 receipt 纪律同构）。
3. `stats()`：`done` 计入 artifact；新增 `unfinished`。
4. `check` 新增两行：`非命题已完成（artifact）` 与 `未定局（未完成口径）`；
   并对 `needs_review` 中**无 module** 的节点给出可执行提示（「若陈述不是类型，应标 artifact」）。
5. 三条进度行加 artifact；「被截断的未完成节点」过滤加 artifact。
6. 工具描述与 schema（`enum: STATES` 自动含 artifact；新增 `evidenceKind` 属性）。
7. **修一个实测缺陷**：`import` 新建分支在**无回执**时把 `evidence` 覆盖成 `undefined`
   ⇒ artifact 的证据指针会静默丢失。改为保留条目自带的 `evidence`。

**负向控制**（判官必须能说「不」——否则闸门等于没装）：

- 缺 `evidenceKind` ⇒ **拒绝**
- `evidenceKind` 非法（如 `"proof"`）⇒ **拒绝**
- 有 kind 但无证据指针 ⇒ **拒绝**
- `import` 通道同上三条 ⇒ **拒绝且不落盘**
- 口径实算：`artifact=1 / proven=1`（**未混入**）/ `unfinished=2`（artifact 不计未完成）/
  `progress=50%`（计入完成）

## 六、诚实边界

- `artifact` **不是**「另一条拿分路径」：它**不计入 `proven` 数量**，也**不能**满足下游依赖；
  它只修正「未完成」栏的语义。
- 标 `artifact` 的节点**没有**数学内容被证明——这一点由字段（`evidenceKind`）显式承载，
  不靠读者记忆。
- 本文件记录的插件改动在**插件目录**，本仓库只保存依据与验证结果；
  两者若不一致，以 `plugins/proof-dag.mjs` 源码与 `doctor` 的哈希为准。
