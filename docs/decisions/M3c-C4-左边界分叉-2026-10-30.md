## 1. 事实（实测，不是推断）

`src/Sovereign/Algebra/Automata/TuringMachine.agda:59-61`：

```agda
leftLof s' w' []       a r = mkTC [] s' w' (a ∷ r)        -- 左带为空
leftLof s' w' (x ∷ xs) a r = mkTC xs s' x (w′ ∷ a ∷ r)    -- 左带非空
```

两支产出的格局**不同**：左空时 `scan′ = w′`、`right′ = a ∷ r`、头**不动**；左非空时
`scan′ = x`、`right′ = w′ ∷ a ∷ r`、头**左移一格**。对应 M3b 的两个平移原语
`tShiftLN`（恒等型）与 `tShiftL`（左移型），互不通用。

## 2. 为什么这不是局部事实

`left` 是「头左侧格子的完整列表」：

- 右移：`left′ = w′ ∷ left` ⟹ `|left|` 加一；
- 左移·非空：`left′ = xs`（`left = x ∷ xs`）⟹ `|left|` 减一；
- 左移·空：`left′ = []` ⟹ 仍为 0。

于是 `|left| = #右移 − #左移·非空`，即 **`left ≡ []` ⟺ `|left| = 0` ⟺ 头的绝对位置 = 0**。
这是一个**计数器**（上界 `t`），不是窗口内的局部符号/状态组合 —— 而路线 (B) 的窗口
只有相对偏移 `tH`/`tL k`/`tR k`，绝对位置在其中不可见。

### 反例：为什么「左侧全空」不能替代 `|left| = 0`

设头从位置 0 右移 3 格（写到位置 0、1、2）再左移 2 格 ⟹ 头在位置 1，`|left| = 1`。
若位置 0 上的符号恰好是空白，则「窗口内所有 `tL k` 皆空」为**真**，但真正的分支是
**左非空**（`left` 有 1 个元素）。两个分支对 `scan′` 的断言不同（`w′` vs `空白`）⟹
用「全空」判据会把合法运行判成 UNSAT。反之「至少一个非空」也不等价。

## 3. 三个候选与代价

| 方案 | 做法 | 代价 / 风险 |
|---|---|---|
| **(a) 状态原子带绝对位置** | 状态格改成 `St(t, q, p)`，`p : Fin (suc T)`（`|left| ≤ t ≤ T` 由 §2 的递推成立）。C4 的三支按 `(方向, p = 0?)` **局部可判**；`p′` 也随之确定（R ⟹ `suc p`；L·`p = 0` ⟹ `p`；L·`p = suc n` ⟹ `n`）。 | 状态原子数从 `(T+1)·Q` 涨到 `(T+1)·(T+1)·Q`（仍多项式）。C2/C5/C6 与 G4/G5 全部按新形状写；**不动 M2**、不需语言不变证明。 |
| (b) 改机器模型 | 左端标记 + `δ` 在 `|left| = 0` 时禁止左移（反弹），使左空支永不发生。 | 需「反弹不改变接受语言」的模拟引理（非平凡）；M2 已冻结 ⟹ 必须新增桥接层并证 `NPT-run` 与新 step 一致。 |
| (c) 单列「边界原子」`Edge(t)` | 用一族 `Edge(t)` 表示 `|left| = 0`，并编码其递推。 | 递推需要「`|left| = 1`」这一中间量，仍要位置计数器；等于把 (a) 拆成两族原子 + 多一族子句，工作量更大。 |

## 4. 建议

**(a)**。理由：它是唯一「不动冻结件、不加语言不变证明、且仍留多项式规模」的方案；
代价集中在原子形状与四族子句的写法上，而这些本来就要在 G3 里写。
