## 一、起点修正（三句话）

1. **`char F = p` 与 `|F| = p` 是两回事**：`GF(3^k)` 的特征**全是 3**，元素数却是 `3^k`。
2. **`GF(3)` 的代数内容确实贫乏**：`Aut_域(GF(3)) = {id}`，且其 **Frobenius `x↦x³` 恰是恒等**
   —— 库内已证：`σ(x) = x ↔ x ∈ GF(3)`（`docs/duodecimal/07-proof-status.md:56`）。
3. **丰富性从 `GF(9)` 开始**：`Aut_域(GF(9)) = ⟨σ⟩ ≅ ℤ/2`，`σ(x) = x³ ≠ id`
   （`Algebra/GF9.agda:96`；`docs/duodecimal/11:99-101`、`12:104-110`）。

## 三、`C₄` 的正确位置：`GF(9)*` 的 4 阶子群

```
GF(9)* ≅ C₈    （乘法群，8 阶循环：`GF9Star`, `_*s_`, `gen`, `gen-generates-all`）
  ⊃ ⟨α⟩ ≅ C₄   （4 阶子群 —— 库内载体 `AlphaPower = a0 | a1 | a2 | a3`）
```

- **`C₄` 不在 `GF(3)` 层**：`GF(3)* ≅ C₂`，只有 `{1, 2}` 两个元素。
- 锚点：`Algebra/GF9.agda`（`GF9Star`/`gen-generates-all`）；`GroupTheory/DuodecClock.agda:80`（`AlphaPower`）；
  `DuodecClockProperties.agda` 的 `alpha-order-exactly-4`（阶**恰为** 4，不是"能整除 4"）。
- **相位不可约性**：`C₄ → C₂` 的商**非忠实**（`a2 ↦ a0`），是结构性语义错配——见
  `GroupTheory/SignProjection.agda:98` **`sign-not-faithful`**（已证：非单射）与 §五 的壁垒定理。

## 四、零冥族的位置：在 `GF(9)` 层，不在 `GF(3)` 层

```
GF(9) 中 α² = −1 = 2   ⇒  1² + α² = 0²
```

- **`GF(3)` 层不存在 `i`**（`x² ∈ {0,1}`，`−1 = 2` 不是平方数）⇒ 零冥族**必须**在 `GF(9)` 层陈述。
- 库内：`GroupTheory/DCGroup.agda:120` **`ZeroOblivion`** 五字段；`docs/duodecimal/04-zero-oblivion.md`；
  `DayanCore.agda:46` 的关系字段含 `α² = −1`（写作 `⊕³ = T₀` / `α⁴ = a₀` 同族）。
- **语义要点**：零 ≠ 空——零是「多维相位同时回到单位元」（`DCGroup.agda:120/133`）。

## 七、展示群八要素 = `Presentation` record（精确字段，非我概括）

```
record Presentation (A : Set) : Set₁ where
  field
    step : A → A → A          -- ② 生成元/运算
    g : A                     --    驱动时钟的元素（时钟作用用 step y g）
    unit : A                  -- ⑥ 归零
    assoc | zeroˡ | zeroʳ     -- ③ 关系
    phase : A → A
    phase-order : ℕ
    phase-cycle : ∀ x → iterate phase phase-order x ≡ x       -- ④ 相位
    clock : ℕ
    clock-cycle : ∀ x → iterate (λ y → step y g) clock x ≡ x  -- ⑤ 时钟
    rigidity : A → A          -- ⑦ 刚性（硬约束：必须从 GF9 galoisConjugate 诱导）
    check : ∀ x → step x unit ≡ x                             -- ⑧ 核对
```
锚点：`src/Sovereign/Algebra/Presentation.agda`。**① 载体是类型参数 `A`，不是字段。**

**三条硬约束**（同文件明文，非本文件新立）：
1. **刚性不得定义在生成元层**，须从 GF9 诱导；
2. **核对是 refl 自洽确认、不产生结构**；
3. **八要素不扩充**（2026-09-27 裁决）；壁垒/保真度命题**不入本 record**
   （所以 `ABCL1` 的壁垒定理是**独立模块**，不是 `Presentation` 字段——这点容易混淆）。

## 九、诚实边界（汇总）

- **没有 `GF-Tower` 聚合模块**；塔是并列模块 + `21` 号文档的逐层记录。
- **`GF(27)/81/243` 的 `σ-mul` 未证**，只有"保加 + 阶 + 单射 + 生成元像"；引用「Frobenius 是域自同构」时须带此限定。
- `GF(729)` 的乘法/Frobenius **本会话未核**（只确认加法群实例存在）。`GF4`（特征 2）与 `GF2Degeneration` 也存在于库内，**不属于特征 3 塔**。
- 八要素的「刚性」是**约定必须从 GF9 诱导**（`Presentation.agda` 硬约束），不是类型系统强制——违反它不会编译失败，只会靠评审发现。
- 「形式化 = 发现」我给了三条**本会话**实例；不把框架层的宏大叙述（lim/∞-groupoid）混进来。
