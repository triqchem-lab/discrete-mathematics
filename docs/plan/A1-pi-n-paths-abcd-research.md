## 一、题目纠缠：人相遇揭示的语义归纳

（1）**闭合几何体穷举（本地）**：本框架「几何」一侧只有两种闭合形——**球面系**（S¹ᵈ 三边环/以便以圈长参数化、S²ᵈ 四顶形、S³ᵈ=4 顶四面体）与**环面系**（T⁶ = (Z/3)⁶ 离散环面）。**不含**高维一般同调流形、双曲曲面、Eⁿ 平面。这意味着 A1 定义域的试金石有限：**球面路径是「合场」，环面路径是「参考形」**。任何候选定义必须满足：S¹ᵈ(→Z)、S²ᵈ(→2)、S³ᵈ(→Z) 可算（Dvir/Serre 序列度）。

（2）**反信息截断（宪法级）**：候选定义不得把高阶同伦降格为「一组数值点」或「商群阶数」——**必须保留 ①群层载具 ②生成元 ③关系（复合/逆）④拼接上下文**。这正是路径 **C（sSet-Kan 单纯复形）被排除**的根因：presentation **超定**——Kan 填充条件 (④层封闭性) 把同伦群「预」成已定型，丢失了生成方式的会面过程。

（3）**维度压缩的施工辩护**：连续 πₙ 依赖 Sⁿ 全体同伦类——**离散化时必须保留同维的填充自由度**：Ω^(k+1) 的 step = **上一阶的闭走 + 上一阶的同伦生成元**（`_PPI5d:54-57`）。降维截断会丢掉 fill 模件（fill-tri/fill-tet），恰为路径 A 未解项。

（4）**壁垒定理（abc 对应）**：路径 D（Barcelo 图同态）证明「图同态同伦类」的**判据的计算复杂度**（A-同伦等价的判定）是**指数布列**——本框架映射为「基座**计算复杂度壁垒**」：**允许承认计算壁垒**，但**拒绝以此为借口放弃构造性定义**（裁决线=Agda 编译，不因难而不为零重新定义）。这与 abc 猜想的「最速捷径不存在」在方法论上同格。

（5）**加法群与乘法群**：πₙᵈ n≥2 阿贝尔性 = EH 耦合点——**加法群同伦复合**（Ω²X 的两个复合一致）与**乘法群同伦复合**（交换子 [α,β]）在 n≥2 重合。这正是路径 B 的**耦合优势**（EH 离散可走，`A1c-abelian-design.md`），也是路径 A 的副作用败（[Sⁿᵈ,X] 的群结构需额外构造）。

（6）**同伦多路径（探索性）**：四候选路径允许并行探索，**非互斥**——以下对比给出「主线/R2 比对基准/管哨双探」三元共存格局。

## 三、深度推论（闭合形 × 反截断 × 壁垒 × EH）

### 3.1 闭合几何体只有两种 = 候选定义的**劳油好锁**

本地「闭合形」= 球面系 + 环面系 ⇒ 任何候选定义**在 K¹ 级别就有判定**：S¹ᵈ → Ω¹ᵈ = C₃（非 (ℤ,+)，也与 A2 H1 假设的 backtrack 增广对应）。**试金石的形式化判据**（三条，本地可编译）：
- **C1 闭合判据**：π₁ᵈ(S¹ᵈ闭合形) ≅ C₃ 而非ℤ（walk/closed 实件已收 `_PPI5d`）；
- **C2 无「阶斜」判据**：定义对 Ωⁿ 迭代步数无不定性（`— _PPI5d:54-57` 模板）；
- **C3 阿贝尔对接判据**：n≥2 πₙᵈ 服务 EH（`A1c-abelian-design.md`）。

→ 路径 A/B 都能过 C1；路径 C 因超定 break C2；路径 D 立方网格**不与本地闭合形贴合**⇒ 需另建「闭合形→网格」桥（成本高、未给本地增益）。

### 3.2 反信息截断 = 路径 C 被排除的**结构性根因**

Kan 复形的 presentation 超定不是工程难度，是**结构性截断**：Kan 填充条件先验地固定了同伦类的**定型方式**（horn-filler 交换图闭合），丢失了「环路生成方式」的会面过程信息（生成元的记录链）。**本框架把「生成方式」当本体**（展示群 8 要素——载体/生成元/关系/相位/时钟/归零/刚性/核对 `=_PPI3.agda` Simplex 承载），截断即**本体论红线**触发（`08-terminology.md §7`）。这是路径 C 应判排除的**根因**，不是主编轮的口味。

### 3.3 维度压缩的施工辩护（路径 A vs B 差异根源）

R2 悬嵌（悬置）**单纯的复形数指数增长**——这是维度压缩的反向风险（超维），不是正向截断。路径 B 递推方法的**对抗风险**是 **Ω 闭包（等价闭包）的超定性**（Ω3Walk 等价闭包已把 symm3/trans3 内建，避免 JComboBox 振荡——实测 NF 振荡教训 `B1-garside-nf-results.md` canonical 升序排）。**处置**：Ωⁿ 迭代走 **canonical 数据型**（Ω2Walk cons2 链）→ **caption 闭装**（Ω3Walk 等价闭包）两条交替，四阶段交换模板已写（`A1b-omega4-design.md`）。

### 3.4 壁垒定理（abc 类比）的映射：**计算壁垒承认，构造性定义不弃**

Barcelo A-同伦的**判定复杂度**是**已知高指数**（图 A-同伦等价/类判定）。本地映射：
- **承认**：Aₙ(G,v) 同伦类判定的**计算成本**高（计算壁垒）；
- **拒绝**：因此接受「用 postulate 跳过」或「用数值点列举冒充」（**违反构造性裁决线**）；
- **可做**：把 Barcelo 思想**受限承载**——在**已然生成的**有限网格上（如 `T⁶ 格点`/`linPoset n`）**显式表出**图同态同伦链——这是「计算是工具不是裁决」的正途（先算后验证，Agda 唯一裁决）。
- **同 abc 方法论**：abc 猜想「最速捷径不存在」= 复杂度壁垒；框架立场=**复杂度壁垒不是「定义权壁垒」**（"太难所以我重新定义"=退化构造）。路径 D 若未来开立，必须先满足「显式有限网格 + 构造性复合」 precondition，否则启},

### 3.5 加法群 × 乘法群：路径 B 的 EH 承载（裁决性优势）

连续/离散 EH：Ω²X 有**两种复合**（水平/垂直）且一致 ⇒ πₙ (n≥2) 阿贝尔。本地对接：
```
耦合点 = π₂ᵈ 的水平复合（AStep 拼接）与垂直复合（fill-tri 填充）在 A1c 段判一致
```
本条的落地即 A1c-2 whisk-swap（whisker 交换）+ 拼接矩阵（`A1c-abelian-design.md`）。**路径 A 需另证这个（[Sⁿᵈ,X] 的群结构本身是**定理**而非辅赋）；路径 D 需把 EH 重述到立方网格。→ **EH 直接承载**是选 B 的**裁决性论据（第四，最重的一项）**。

### 3.6 同伦多路径探索：**互不排斥，正可分工**

本地架构对四路径的**装配分工**（正视留牌）：
- **主定义** = 路径 B（Ωⁿ 迭代，供 πₙᵈ 泛件/A1c/A2 全线）；
- **比对基准** = 路径 A（R2 标准边界复形，`Snd-face` `_PPI5:71-72`/`linChain`/`oFace` `_PPI5m`——供「闭环一致/收敛性对形成的检验」）；
- **排除+记录根因** = 路径 C（本报告 §3.2 固化结构性根因，M0 not 不重探）；
- **哨探/双探** = 路径 D（不硬开——预置条件不满足；如未来需要，从「有限网格显式表出」入手）；
- **与 A1a/A1d 关系**：路径 A 的 R2 就是 A1a 的球面载体，**不另建**——本报告只是把 A1a 的 R2 在「πₙ 定义域试金石」语境下重记（球面判据统一为 A1d 开工面）。
