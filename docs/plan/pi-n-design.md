## §0 问题定位（为什么 (b3) 是本体论待定而非工时）

π₁ᵈ 的成功路径：**闭 walk（组合数据）+ A-homotopy（等价闭包）+ 商型**——全程离散、全程构造性。
πₙ≥2 的阻塞：**「Sⁿ 的离散形」与「n 维同伦的离散形」双双未定义**。经典答案（ℝⁿ 凸包实现、
连续映射同伦类）触宪法红线（连续统病态：ε-δ/极限/不可数）⇒ 必须在离散基座内**重新设计**，
不是移植。八要素（载体/生成元/关系/相位/时钟/归零/刚性/核对）全缺 ⇒ 本设计逐要素补齐。

## §1 四问①：离散 Sⁿ 的定义——三方案对比

| 维度 | **方案 A：组合球面（边界球复形）** | **方案 B：单纯集球面（sSet）** | **方案 C：有限点集商形（面偏序）** |
|---|---|---|---|
| **载体** | ∂Δ^{n+1} 的面集合：顶点集 `Fin (n+2)`，单形 = 恰缺一顶点的 n 面之面闭包 | 分级集合 `X : ℕ → Set` + 面/退化算子（函子 Δᵒᵖ → Set） | 面偏序 `FacePoset = Σ (S : Fin (n+2) 的真子集) ⊆`（Alexandroff 有限空间，其序复形 = 方案 A） |
| **生成元** | 顶点 + 单形面（子集包含生成） | 非退化单形（本例仅 1 个 n 维腔） | 覆盖关系（加一顶点的单步扩展） |
| **关系** | 面单纯包含关系（`⊆` + 维数界） | 单纯恒等式（面算子 dᵢ、退化算子 sᵢ 的函子律） | `⊆` 传递/反对称 + 边界收缩关系（对应 ∂₂ 粘合） |
| **构造性** | ✅ 全有限组合数据（`Vec (Fin (n+2))` 子集 + `⊆` 判定可构造） | ⚠ 需函子机件 + 商（horn 填充 = Kan 条件需新增公理字段） | ✅ 全有限（偏序 = data/record 形，与 `FinitePoset` 现件同型） |
| **复用面** | `KVert/KEdge/KTri/FaceBoundary`（`_PPI`）直接推广 | 几乎零复用（sSet 栈全新） | `FinitePoset`/`K2Gluing`/`∂₂`（`_PPI:40-56`）+ McCord 序复形全链 |
| **n=1 参照** | S¹ᵈ = 四点圈/三点圈（组合圆）→ 映射类 = 闭 walk ✓ 与 `Loop` 同源 | S¹ = Δ[1]/∂Δ[1]（标准） | 面偏序的 1 阶形 = 圈的边偏序 ✓ |
| **风险** | 粘合结合性（a3 项）需证；维数泛化工程 | **超定风险**（Kan 公理 = presentation 外加关系，违最小性判据） | 需证「序复形 = 方案 A」（但这是 barycentric 细分标准事实，组合可证） |

**小结**：A 与 C 是同一组合对象的两个视图（复形 vs 其面偏序）；B 是现代 HoTT 标准形但机件成本
数倍且引入超定风险。**A+C 双视图（C 为呈现层、A 为计算层）**是最优组合。

## §2 四问②：离散 πₙ 的定义——三选项 + n=1 一致性

| 选项 | 定义 | n=1 退化检查 | 构造性 | 与 π₁ᵈ 机件一致性 |
|---|---|---|---|---|
| **选项 1：迭代 Ωⁿ 取 π₀** | πₙᵈ(X,x) := π₀(Ωⁿᵈ X)；Ωᵈ = 闭 walk 空间（`Loop` 形），π₀ = 按同伦商（`AHomotopy` 形） | Ω¹ᵈ = `Loop G x`，π₀ = `π₁ᵈ` ✓ **恰好现有件** | ✅ 商型可构造 | ⭐⭐⭐ **原生一致**（π₁ᵈ 就是 n=1 案） |
| **选项 2：映射同伦类** | πₙᵈ(X,x) := [Sⁿᵈ, X]_*（基点保持的组合映射 ÷ 组合同伦——柱体 Sⁿᵈ × Iᵈ） | [S¹ᵈ, X]_* ≅ 闭 walk 同伦类 = π₁ᵈ ✓（需 1 条对应定理） | ✅ 映射 = 有限函数；同伦 = 柱体映射 | ⭐⭐ 需 1 条桥（圈↔loop） |
| **选项 3：Kan 扩充/单纯集路径空间** | sSet 内 Kan 复形，horn 填充定义路径空间迭代 | 标准形 | ⚠ Kan 条件 = 新公理字段 | ⭐ 机件全异 |

**关键设计决定**：**选项 2 为主定义、选项 1 为导出刻画**——
- 主定义用映射类（与 Sⁿᵈ 选型直接咬合，八要素好填）；
- 证明 `Ωⁿᵈ` 刻画与之等价（n=1 案 = 圈↔loop 对应定理，作为**一致性核对件**）；
- n=2 起用**逐阶构造**：S²ᵈ 的映射 = 2 维腔填充（`K2Gluing` 的 `∂₂` 粘合恰是其数据形）。

**离散同伦（新件）**：`DHomotopy`——柱体 `Sⁿᵈ × Iᵈ`（Iᵈ = 两元素偏序 [0<1] 的组合区间）上的
组合映射族 + 端点取值律；参照 `AHomotopy` 的三律构造子形（refl'/symm'/trans'/gen）。**关系入定义**
（B2 正解②）：同伦生成元 = 柱体单步（对应 AStep 的 slide/expand 形）。

## §3 四问③：展示群八要素对齐表（方案 A+C 双视图 vs 方案 B）

| 要素 | **A+C 双视图（推荐）** | 方案 B（对照） |
|---|---|---|
| **载体** | 面偏序 `SFace n`（C 视图）≡ 面复形 ∂Δ^{n+1}（A 视图）——`Vec (Fin (n+2))` 真子集族 | 分级集合族 + 函子结构 |
| **生成元** | 顶点 + 单步覆盖（加一顶点）；n 维腔 = 全集补一点 | 非退化单形（1 个 n 腔） |
| **关系** | `⊆` 序 + **∂ 复合归零**（∂∂=∅，见「归零」）+ 柱体同伦生成元 | 单纯恒等式 + **Kan 公理**（⚠ 超定） |
| **相位** | 顶点置换群 `Σ_{n+2}` 的忠实作用（置换相位）；S¹ᵈ 案 = 旋转/反射二分——**如实注**：此处相位非 C₄ 形，是球面对称群的置换相位（不硬套框架相位语义） | 同左（退化算子带序相位） |
| **时钟** | 组合闭链的绕行周期：S¹ᵈ 圈长 = 顶点数（4 或 k+1）；n≥2 = 边界遍历的组合周期——**迭代过程**（映射柱体逐步） | 纤维化迭代（机件重） |
| **归零** | **∂²ᵈ = ∅**（边界算子两次 = 空复形）——组合归零律，构造性 refl 级可核 | 同调归零（∂²=0 是其定理） |
| **刚性** | 单纯形不可分解性 + `Σ_{n+2}` 作用忠实（无内核）；**如实注**：无 Frobenius 结构（球面非有限域扩张），刚性 = 置换忠实性 | 退化算子的不可约性 |
| **核对** | 有限 case refl 核对（G2s 型）：S¹ᵈ 映射类 ↔ 闭 walk（n=1 桥）；S²ᵈ 最小例（两个 2 腔粘合）逐案核 | 单纯集小例 |

## §4 四问④：推荐方案 + 实现路线 + 不采纳理由

### 推荐：**A+C 双视图球面 + 选项 2 主定义（映射同伦类）+ 选项 1 导出刻画**

**实现路线（估批数）**：
| 批 | 内容 | 估行 | 依赖 |
|---|---|---|---|
| πₙ-B1 | `SFace n` 面偏序 + 方案 A 复形 + **等价桥**（序复形 = ∂Δ^{n+1}，barycentric 细分组合证） | ~80-120 | 现件（FinitePoset/K2Gluing） |
| πₙ-B2 | `Iᵈ` 组合区间 + `DHomotopy`（柱体同伦，三律构造子形——AHomotopy 范式复制） | ~60-100 | B1 |
| πₙ-B3 | 基点映射类 `MapClass n X` + 商型 πₙᵈ + **n=1 一致性桥**（圈↔loop 对应，核对件） | ~80-120 | B2 + π₁ᵈ 件 |
| πₙ-B4 | Ωⁿᵈ 导出刻画定理（选项 1 ≅ 选项 2）+ S²ᵈ 最小例（∂₂ 粘合案） | ~60-100 | B3 |
| （选）πₙ-B5 | 八要素核对层（refl 实例全表 + G2s 型扩展） | ~40 | B4 |

**合计 ≈ 4-5 批 / 320-450 行**；无爆点预期（全有限组合数据 + 商型，无字面大数/无深归约）。

### 不采纳方案的理由（红线点名）
1. **ℝⁿ 凸包/经典几何实现**：触**连续统病态红线**（ε-δ/极限/不可数基）——宪法级排除；
   单纯逼近引理的经典证明同触（依赖 ℝⁿ 凸性）。
2. **方案 B（sSet/Kan）**：Kan 公理（horn 填充）是 **presentation 外加关系**——违
   presentation 最小性判据（结构公理之外的第三类字段=超定）；且机件栈与现有 π₁ᵈ 族零复用，
   成本数倍而 n=1 一致性反需额外桥。
3. **选项 3 单独作为定义**：同上（Kan 桥成本）；仅在 B4 阶段可作**对照刻画**引用，不入主线。
4. **连续映射同伦类直搬**：映射空间不可数 ⇒ 描述完备红线（M_F 缺失）；必须用**有限组合映射**。

### 边界（本设计不做的）
- ❌ 不实现任何代码（决策 5）；❌ 不动 π₁ᵈ 现件；❌ 不预设 πₙᵈ 的群结构（n≥2 的 πₙ 交换性
  是**后续定理**，本设计只定义集合层 π₀ 型）；
- ⚠ 未决点：Sⁿᵈ 圈长取 4 还是 k+1（核对件两形皆可，实现时定）；相位置换语义是否需与框架
  C₄ 相位打通（现判：不打通，如实注记——球面对称群 ≠ 框架相位群）。
