```
rank-nullity（条件于四个参数）：

    ① bV : Basis V
    ② bK : Basis (V ∩ ker T)
    ③ bI : Basis (im T)
    ④ σ  : Section V T   ← 契约：σ y 只依赖 y 的值，不依赖 y 的哪个原像
  则  Basis.dim bV ≡ Basis.dim bK + Basis.dim bI
```

## 一、语言纪律（v2 新增，最高优先级）

**本项目是 char 3，不是 char 0。** 每次写引理前先自问：

| char 0 的默认假设 | char 3 的真实情况 | 影响 |
|---|---|---|
| `x² ≥ 0`、二次型有特征值 | **`x² ∈ {0,1}`**，`x_j²` 是**非零指示子** | `F = Σ x_j²` 是**零坐标升格算子**，不是二次型 ✗ |
| 关联矩阵 `rank = #V − #comp` | **不成立** ✗（实测 14 情形全败）| 秩要按 char p 算（含 `p`-torsion）|
| 同一矩阵在 `ℚ` 与 `GF(p)` 上秩相同 | **不同** ✗，差 = `p`-torsion | `a_n = ker_ℚ + 3-torsion` ✓ |
| 表示论/特征值分解 | Freshman's dream **`(a+b)³ = a³+b³`** ⇒ **`F³ = 0`** | 幂零结构是 char 3 的**第一性** ✓ |
| `n ≤ 4` 的验证可外推 | **torsion 在 n=5 才出现** ⇒ 前 4 例是**巧合一致** | 不能用 `n ≤ 4` 验证猜闭式 ✗ |

**铁律** ✓：任何「在 `n ≤ 4` 成立」的断言，**必须标为未验证** ✓，因为 `n=5` 处 torsion 首次非零 ✓。

## 三、v1 → v2 的设计修正

### 修正 1：`section` 是独立第四参数（不能自动导出）

**v1 的错误想法** ✗：`ImOf V T y = Σ z, (V z × Fiber T y z)` 自带原像 ⇒ `section = proj₁` 自动 ✓

**实际** ✗：退化
```
section (T p) ⟨p, Vp, refl⟩ = p
⇒ p = (p − section(T p)) + section(T p) = 0 + p    ← 恒等
```
⇒ 「核部分」恒为 0 ✗

**v2** ✓：`section` 作为参数，且带**契约**（类型上无法强制，必须显式声明）：
```agda
Section : ∀ {n m} (V : CoeffN n → Set) (T : CoeffN n → CoeffN m) → Set
Section V T = (y : CoeffN m) → ImOf V T y → Σ (CoeffN n) (λ z → V z × Fiber T y z)
-- 契约（文档级假设）：σ 只依赖 y 的值，不依赖 y 携带的原像
```

### 修正 2：`ImOf` 用数据表示 **不需要 funext** ✓

```
ImOf V T y = Σ (CoeffN n) (λ z → V z × Fiber T y z)
分量：函数 + 两个命题 ⇒ Σ 整体相等不需要分量级 funext ✓
```
（v1 的风险标注过度谨慎 ✗）

### 修正 3：`dim` 良定义的路线上限

`V-from-Fin-inj` ✓ 已证（点态前提 ⇒ `Fin` 相等 ✓）。
**但完整 `dim-welldefined` 需要 `Σ`-层级双射** ✗ ⇒ 需要 `funext` ✗。
⇒ **v2 决定**：**不追求** `dim-welldefined` ✗，改用 **`3^-inj`** 把基数等式化为维数等式 ✓。

