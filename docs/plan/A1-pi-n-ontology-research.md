## 一、数学对象

### 1.1 问题陈述
离散基座上，高阶同伦群 πₙ（n≥2）的**数学定义**是什么？

| 维度 | π₁ᵈ（已定义） | πₙ≥2（未定） |
|---|---|---|
| 定义域 | 闭走 Loop G x | **未定** |
| 等价关系 | AHomotopy | **未定** |
| 群结构 | 幺半群（分水岭刻画） | **未定**（阿贝尔性待证） |
| n=1 锚点 | — | 必须与 π₁ᵈ 一致 |

### 1.2 候选定义路径
- **路径 A**：组合球面 Sⁿᵈ——πₙᵈ(X,x) := [Sⁿᵈ, X]*
- **路径 B**：Ωⁿ 迭代——πₙᵈ(X,x) := π₀ᵈ(Ωⁿ X)（选项 2 基点映射同伦类）
- **路径 C**：sSet Kan 复形——**已被项目排除**（presentation 超定/K(G,n) 非有限偏序集红线）
- **路径 D**：Barcelo A-同伦（图同态 on cubical grids）

### 1.3 当前设计选择：**路径 B（Ωⁿ 迭代）主定义 + 路径 A（Sⁿᵈ）对照面**
理由：① n=1 一致性锚点（数学约束）；② 组合性（零连续统）；③ 构造性（0-postulate）。

## 四、严格设计

### 4.1 Sⁿᵈ 定义（路径 A 侧）
```
Sⁿᵈ : (n : ℕ) → SimplicialComplex     —— 固定圈长有限形（圈长参数化保留）
S⁰ᵈ = 两点离散；S¹ᵈ = 三角形（3 顶 3 边）；Sⁿᵈ = S¹ᵈ × Sⁿ⁻¹ᵈ（圈长参数不固定）
```

### 4.2 主定义（路径 B）
```
πₙᵈ(X, x) := π₀ᵈ(Ωⁿ X)                —— n=1 锚（强制）：π₁ᵈ ≡ π₀ᵈ(Ω X) ✓ 已证
```

### 4.3 圈长参数化与 C₄ 边界
- 圈长**参数化保留**（不固定）——不同圈长=不同离散球面；
- 相位 C₄ **不打通**（相位不可约性红线）；
- 两者与 πₙᵈ 群结构的关系=开放问题（见五）。

## 五、诚实边界

| 类 | 项 |
|---|---|
| **已证** | n=1 锚（B1）；Ωⁿ 迭代 B1-B5 全链；π₂ᵈ+rec/elim；TruncAbove 骨架；Gskel 全证实例 |
| **需新工具** | Sⁿᵈ 一般递归构造（n≥2 组合球面）；πₙᵈ 阿贝尔性证明（Barcelo 2025 路线）；Ω⁴+ 机件（实测零命中——立界确认） |
| **依赖未定** | 圈长参数化↔群结构关系；C₄ 不打通的精确形式化；与 Gao-Yang「离散=经典同构」主张的调和（本项目 π₁ᵈ 是**幺半群**可不成群——分水岭定理——与 Gao-Yang 主张的张力=本体论核心问题） |

**核心张力（A1 的本体论要点）**：Gao-Yang 的离散同伦=经典同构（经 McCord/M3 邻域）；本项目分水岭定理证明 π₁ᵈ **不必成群**（幂等幺半群案）——两套离散同伦的**对象不同**：前者=经典拷贝（需 |K(X)| 实现），后者=组合本源（有限图直接承载）。A1 的论证义务=明确「本项目 πₙᵈ 的本体论独立性与对应面」（对应定理=桥，非定义）。
