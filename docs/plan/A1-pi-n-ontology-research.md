## 一、数学对象

### 1.1 问题陈述
离散基座上，高阶同伦群 πₙ（n≥2）的**数学定义**是什么？

| 维度 | π₁ᵈ（已定义） | πₙ≥2（未定） |
|---|---|---|
| 定义域 | 闭走 Loop G x | **未定** |
| 等价关系 | AHomotopy | **未定** |
| 群结构 | 幺半群（分水岭刻画） | **未定** |
| n=1 锚点 | — | 必须与 π₁ᵈ 一致 |

### 1.2 候选定义路径
- **路径 A**：组合球面 Sⁿᵈ——πₙᵈ(X,x) := [Sⁿᵈ, X]*
- **路径 B**：Ωⁿ 迭代——πₙᵈ(X,x) := π₀ᵈ(Ωⁿ X)（选项 2 基点映射同伦类）
- **路径 C**：sSet Kan 复形——**已被项目排除**（presentation 超定/K(G,n) 非有限偏序集红线）
- **路径 D**：Barcelo A-同伦——**图同态在立方网格上的映射**替代连续球面映射（该理论的核心特征）

### 1.3 当前设计选择：路径 B 主定义 + 路径 A 对接面
理由：① n=1 一致性锚点（数学约束）；② 组合性（零连续统）；③ 构造性（0-postulate）。

## 二、经典路径

### 2.1 连续 πₙ
πₙ(X,x) := [Sⁿ,X]*，n≥2 阿贝尔。πₙ(Sⁿ) 的计算是代数拓扑最重要的开放问题之一。

### 2.2 Barcelo A-同伦理论
- 核心：图同态 on cubical grids；A-同伦群=**双分级序列**（对单纯复形赋予双分级群序列）；
- 第一个迭代=**Q-analysis**（Ron Atkin，1972）——单纯复形组合"洞"；
- Babson-Barcelo-de Longueville-Laubenbacher (2006) 猜想；**2025 证明 + 离散强 Hurewicz 定理**。

### 2.3 Gao-Yang 有限偏序集
- **离散同伦群与经典同构**（经 McCord/M3 邻域）——经典拷贝，非独立不变量；
- 离散 Hurewicz 映射（Thm 5.4）；
- **任何有限单纯复形同胚于有限偏序集序列的逆极限**（C 理论扩展）。

### 2.4 离散球面的组合定义
- **Evako 定义**：重心细分为 d-球面 ⟺ 本身为 d-球面；
- **PL 同胚定义**：与 d-单形边界 PL 同胚；
- **临界胞腔判据**：组合 d-流形有恰两个临界单纯形的离散 Morse 函数 ⟺ 组合 d-球面。

### 2.5 离散 Hurewicz 定理（2025）
关联第一个非平凡 A-群与约化离散同调；自然映射 πₙ(X,x) → H̃ₙ(X,x)；可用于计算图的先前未知高阶同伦群。

## 四、严格设计

### 4.1 Sⁿᵈ 定义（路径 A 侧）
```
Sⁿᵈ : (n : ℕ) → SimplicialComplex（固定圈长有限形，圈长参数化保留）
S⁰ᵈ = 两点离散；S¹ᵈ = 圈形（_PPI5 六面实例承载）；Sⁿᵈ = S¹ᵈ × Sⁿ⁻¹ᵈ
```

### 4.2 主定义（路径 B）
```
πₙᵈ(X, x) := π₀ᵈ(Ωⁿ X)      —— n=1 锚（强制）：π₁ᵈ ≡ π₀ᵈ(Ω X) ✓ 已证
```

### 4.3 圈长参数化与 C₄ 边界
- 圈长**参数化保留**——不同圈长=不同离散球面；
- 相位 C₄ **不打通**（相位不可约红线）。
