## 三、替代陈述：分层传导（A2' 判据）

### 3.1 非形式表述

> **逆元的缺失不是全域的，也不是可以「整体消解」的；它是逐层、逐 face 的。**
> 反射 `ρ¹` 是 **Ω¹ 层**的自同构：
> · 在 `π₁ᵈ(X)` **是群**的图上，`ρ¹` 与恒等**同商**（冗余）；
> · 在 `π₁ᵈ(X)` **是幂等幺半群**的图上，`ρ¹` **不改变**幂等结构（故分水岭保持）。
> 因此「补 backtrack 生成元」只影响**含该 face 的层**；不含的层，其定理原样成立。

### 3.2 形式陈述（A2'，**判据形，未形式化**）

```
A2'（内逆存在性判据 / 分层传导）
  记号：X 为有限对称图；πₙᵈ(X) 如主定义；face F ⊆ {slide, expand, backtrack(AStep-back/bt)}。
  定义  Inv : (n : ℕ) → (F : Face) → (X : DiGraph) → Set
        Inv n F X  :=  「πₙᵈ_F(X) 的每个类在 ⊞ᵈ 下有双侧逆」

  要件（三条，缺一不可）：
    (a) 分层：Inv n F X 只依赖于 (n, F, X)，不依赖表征（representative）。
    (b) 传导：Inv (suc n) F X → Inv n F X         ← **待证/或入定义**（见 §五 风险 R-a）
    (c) ρ¹ 的层作用：
          Inv 1 F X     →  ρ¹ 在 π₁ᵈ_F(X) 上与恒等同商（冗余）
          ¬ Inv 1 F X   →  ρ¹ 保持幂等结构（不改类集，只改代表）

  推论（分水岭的**分层版**，替代「整体消解」）：
    ¬ Inv 1 {slide,expand} (Gcmp two-chain)        ← 已有：inv-law-false（_PPI2:301）
    Inv 1 {slide,expand,backtrack} (Gcmp two-chain) ← **待施工**（A2 逆律骨架 ~20–40 行，_PPI2:232 锚）
    ⇒ 两个 face 各自成立、互不推翻；「消解」无从谈起。
```

## 五、风险与诚实边界

- **R-a（传导 (b) 未定）**：`Inv (suc n) → Inv n` **未证、也未定是否为真**。可能它不是定理而是
  需要**入定义**的相容条件（若如此，`Inv` 就不只是判据，而是分层结构的一部分）。
  **不得在未定之前把 (b) 当已知使用。**
- **R-b（`ρ¹ selfloop = selfloop` 的来源）**：本会话**未能独立复核**该等式；它来自人类裁决与
  `_PPI2:229-236`/`:301` 的立界原文（v2 §1.2/§7.1 引）。引用时须带此出处，不得当作我验证过的事实。
- **R-c（`¬Inv 1 {slide,expand} Gcmp`）**：有 A 级节点 `Watershed.no-pi1-iso` 支撑，但它是**该图**
  的结论，不是「∀X 幂等」的一般定理。
- **R-d（face 参数的形式化）**：A2' 用 `Face` 作参数，但本库**尚无** `Face` 类型；
  落地时需决定是「`Face` 作为 `data`（三构造子）」还是「生成集作为 `AStep` 的并」——**未定**。
- 本文档**不产生 Agda 义务**；它是把口头更正变成可陈述判据的研究文本。
