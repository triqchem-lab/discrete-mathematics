# 第 B2 章：Church-Turing 三模型等价

## 一、数学对象

**三模型**：TM（`Algebra/Automata/TuringMachine`）｜μ-递归（`_PCT1` PrimRec 五生成元）｜λ-可定义（**本地零命中**）。

**论题 vs 定理区分**（本地已执行——人类决策②）：

| 类 | 陈述 | 可证性 |
|---|---|---|
| **论题** | 「直觉可计算 = 上述形式系统之并」 | ❌ 不可证（哲学主张） |
| **定理 1** | μ-递归 ⟹ TM（单方向——本地已建前件） | ✅ 可证 |
| **定理 2** | TM ⟹ μ-递归（逆向） | ✅ 可证（本地未建） |
| **定理 3** | λ-可定义 ⟺ μ-递归 | ✅ 可证（本地未建） |

## 二、经典路径

- **Turing 1936**：图灵机定义 + 万能机（λ-可定义性附录首次对表）；
- **Church 1936**：λ-可定义性；Church 论题=有效可计算性=λ-可定义；
- **Kleene 范式定理**（1936）：每部分递归函数等价于某范式形 φ_θ^e(x) = U(μ y T(e,x,y))——**逆向模拟的关键**（TM 高斯化 → 范式形）；
- **Kleene-Rosser 悖论**（1935）：λ 语义自指——后续 Kleene 用数值 λ 确立「λ-可定义=部分递归」。

# 第 B3 章：Myhill-Nerode 一般形

## 一、数学对象

**经典定理**：对任意语言 L，以下等价：
1. L 正则（被 DFA 识别）；
2. ~_L（右不变等价 u~_L v ⟺ ∀w, uw ∈ L ↔ vw ∈ L）有**有限指数**；
3. Myhill 等价（有限指数右不变等价细分）存在。

**最小 DFA 唯一性**：状态数 =~_L 指数；且任意 DFA 状态数 ≥ 类数。

## 二、经典路径

- **Myhill 1957**：等价关系 ↔ 正则性（含有限指数）；
- **Nerode 1958**：右商 u⁻¹L **有限个 ⟺ 正则**——**核心定理**。

## 三、本地对接（代码实测锚）

| 本地件 | 锚 | 状态 |
|---|---|---|
| (ab)ᵏ* 3 类全形 + mn-forward/mn-back | `_PMN1:136/classify:154/mn-*` | ✅ 实例级 |
| ~_L 逐点形定义（免 funext） | `_PMN1:113-114`（`u~L v = ∀w → accepts (rcat u w) ≡ ...`） | ✅ 逐点形 |
| 分南三对（sep-0-1/0-2/1-2 全 refl） | `_PMN1:162-175` | ✅ 可分性 |

| SetQuotient 商面 rec/elim | `_PPI5j` 范式 | ✅ 商面机 |

## 四、严格设计（一般形三件）

### 4.1 DFA → ~_M 构造（定理 1→2 方向）
**给定 M: DFA Q Σ**——定义 ~_M（u ≈ v ⟺ starS u ≡ starS v）：
- **右不变性**：~M ~L 直接证明（同 `_PMN1` same-state-quot，但基于任意 DFA 而非 abDFA）；
- **有限指数 ∣Q∣**：状态标签映射 Σ* → Q（starS）是满射到 Q——**纤维化等价**；Tard**类 ≤ ∣Q∣**（pigeonhole 状态纤维化——无需 funext）；
- **簇分**：~M 是由 Q 状态「打标签」定义的等价——是否有 funext？**逐点形定义即可**（同 (ab)* 实例）。

### 4.2 ~_L → 最小 DFA（定理 2→1 方向）
**给定有限指数 ~L**——构造 DFA_MN：
- **状态**：Σ*/~L（商——要用 `SetQuotient`，或商面机件）；
- **转移**：δ([u], a) := [u·a]（良定义性=右不变性——核心证明，应为**两步**：①两点等价→前缀追加后仍等价②转移固定 extend-choice）；
- **接受**：[u] ∈ F ⟺ u ∈ L（良定义性=右不变性+任意 w）；
- **初态** [ε]；
- **关键证明路径**：良定义性和接受定义，*not* funext——全用**类定义逐点形展开**。

### 4.3 双向互逆（iso）
- **⇒**：给定 DFA→dim DFA_MN（M）有≤类构的状态数（最小性）——需证明类两两可分（**分离对**的泛化性——`_PMN1` 的 sep 三对一般化）；
- **⇐**：两自动机互相同构 → 自动机 counting（`sep-pair` 对的泛化到 any-pair）。

### 4.4 QuotientBasic 充分性评估
- `cls`（逐点形）**够用**（_PMN1 实例证明过）；
- **一般形、需要 SetQuotient 的 rec/elim**（_PPI5j 商面范式）——`QuotientBasic` 若无商面机件→补力；**本地评估**：`QuotientBasic` 手工完成逐点形面，**一般 DFA 构造也应是逐点形**（商面=辅助而非必需）——**逐点形式化设计首选**。

## 五、诚实边界

| 类 | 项 |
|---|---|
| **可证** | 4.1-4.3 三件（DFA→有限指数构造+最小化+双向 iso）——纯组合 |
| **需新工具** | DFA 最小性定理（|Q| 最小=类两两可分——合并定理：状态数>类数 ⟹ 存在两状态同类可合并）；归到 DFA 可判定（FrameworkFor language）|
| **不可证** | 无（纯组合定理） |

# 第 C1 章：Trakhtenbrot 完整证明

## 一、数学对象

**Trakhtenbrot 定理（1950）**：有限模型有效性（或可满足性）**不可判定**——
```
∀ 算法 A（判定「φ 有限可满足」），存在 TM M 使得 A 不停机。
```
**精确陈述（形式化目标）**：
```
Decidable EXISTS-FINITE-MODEL ⊥
```
**半可判定面**：枚举公式+枚举有限模型——事件等成立关系；**互补面**=反单调（需要归约）。

## 二、经典路径

- **Trakhtenbrot 1950**：TM 归约构造——
  给定 TM M，构造 FO 公式 φ_M 使得 φ_M 在**有限模型**中可满足 ⟺ M **不停机**（或反之）；
- **编码**：有限模型的域 = TM 的时间-空间格（跨步+格子）；公式约束编码：
  初始格局 / 转移关系 / 停机状态。
- **后续**：经典结果（Lovasz 1970s 等）+ 盐度澄清（Coq 形式化尝试在 Incompleteness 类库里）。

## 三、本地对接（代码实测锚）

| 本地件 | 锚 | 状态 |
|---|---|---|
| 紧致性失效（双条件 ℕ 模型） | `_PFT2`（回执 921e5b25） | ✅ **独立经典结果（注记：非 Trakhtenbrot 逻辑前件）** |
| FMT 语言限制：双变元/无等式原子/Fin 2 变元 | `FiniteModelTheory:13-14` | ⚠ **需扩展**（归约需更多表达力） |

| TM 前件 | `_PCT1` (μ-递归侧在) | ◐ **机器级桥立界——C1 真实前置=CT 机器级批** |

**语言扩展清单**（归约构造必要条件）：

| 功能 | 当前 | 需扩展到 |
|---|---|---|
| 等式原子 | ❌ 无 | **加 (x ≡ y) 原子** |
| 变元集 | Fin 2 | **Fin k 通用** |
| 关系元数 | R₁（一元）+ S₂（二元） | **三元/四元**（状态×时间×格子格点位） |
| 函数符号 | ❌ 无 | **后继/加/乘**（或用关系模拟——Barwise-…） |

## 四、严格设计

### 4.1 归约构造设计（TM → φ_M）
**给定 TM M**（Q δ q₀ F 确定性单带三 tape），设计 φ_M：
1. **谓词化编码**：
   - **Q(x, t)**：时间 t 时状态为 x（或状态谓词区分 q ∈ Q 系列）；
   - **T(x, t, c)**：位置 x、时间 t、格点内容 c；
   - **Step(x, t, x', t+1)**：转移（四元关系 = k 变元语言扩展）；
2. **初始格局**：q₀ + 空带公式（常量/有限可行模型）；
3. **转移约束**：∀x,t (Q(x,t) ∧ T(x,t,c) ∧ T(x',t+1,c')) → 对应 δ(q,c) 转移——用通用公式处理 **deterministic** 转移；
4. **停机状态**：h 满足 h ∈ F；**停机判定=有限模型存在**；
5. **有限性确保**：域 = 时间 t 的初始大小（或循环）；停机 iff 有限。

### 4.2 Trakhtenbrot 精确陈述形式化
```
FinSat = λ φ → ∃ model limit → model有限 ∧ eval(model, φ) ≡ true
Dec FinSat → 无
```
半可判定面：枚举模型计数 → 有限可满足在**多数的情况下可半判定**（若模型可枚举）；**不可判定=两侧均不行**（正反归约均有）。

### 4.3 前置链完整性评估
- **CT 机器级桥**（`_PCT1` 立界）——**C1 真实前置=此件**（建立良基模拟+TM 全形化）；
- **FMT 语言扩展**（等式原子/通用变元/多元关系）——**语言扩展批 ~100-150 行**；
- **✗ 紧致性失效**：独立经典结果，**不等价**于 Trakhtenbrot 前置（本报告注记澄清）。
