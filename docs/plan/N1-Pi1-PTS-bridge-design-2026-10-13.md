- **代价**：~200-300 行（bt 三律 + 折叠 + 顶点翻转兼容性 verification 面）。

## 五、施工修正（2026-10-13 夜 —— `_PN4` 机器证据，**推翻本文档 §二/§四 两处判据**）

> 权威在台账与回执；本节是投影。证据：`src/_PN4.agda` 回执 `e27e6dd23aaed53c9ff58ec381b3ff80c94d9b5d1afefa5ab9bd16756e787790`（exit 0 / 0 postulate / 0 hole）。

### 5.1 修正①：`bt` 生成元的正确本形（§二 甲1 的定义形需换）
| | 形式 | 后果 |
|---|---|---|
| §二 原拟（经 `_PN3` 落成） | 闭走特化：`p`/`e`/`b` 端点皆为回路顶点 ⇒ 要求 `e : edge G u u`（**自环**） | 该面**无自环时为空**；且**长度是不变量** |
| **修正（机器验证）** | **`p·e·ē·b ~ p·b`**，其中 `p : x→u`（前缀终于回路顶点）、`e : edge G u v`（**任意出边**）、`b : Walk G u w`（**任意延续**） | Agda 里**零障碍**声明（索引由实参类型唯一解出）；`_PN4:97` `data AHbt` |
- **机器反例**：`no-PN3-backtrack-G2f`（`_PN4:318`）：`¬ AHomotopy-bt (e01·e10) nil`（闭走面）——而 `p ++w rev p` 定义层即 `e01·e10` ⇒ **在闭走面上 `bt-collapse-general` 是假命题**（不是「难证」）。
- 同一条命题在**新面**上**一行给出**：`check-G2f-backtrack`（`_PN4:394`）= `gen-b (nil fzero) e01 (nil fzero)`。
- 附带纠正：`_PN3` 报的「墙② 索引解析墙」**实为端点记账写错**（其 `b : Walk G w w` 读法在类型上不成立——`cons (flip e) b` 要求 `b` 起于 `flip e` 的终点 `u`）。

### 5.2 修正②：**边界方向相反**（§四 B3 的限定条件作废）
| 图 | 结论 | 证据 |
|---|---|---|
| **无自环**二顶点图 `G2f`（fzero⇄fsuc） | **任一闭走 ~ nil ⇒ π₁ = 0**，正对经典侧 `π₁(|N₁G|) = 0` | `bt-trivial-G2f`（`_PN4:282`）**证成** |
| **含自环**图 `G2s` | **被机器证伪**：奇偶模型 `par` + `par-hom` ⇒ `true ≡ false` | `no-bt-trivial-G2s`（`_PN4:369`）/ `no-bt-G2s-loop`（`:364`） |
- 机理：bt 面杀的是**回溯对 `e·ē`**，**不杀自环**（自环 `s` 满足 `s·s ~ ε` ⇒ 商为 `C₂ ≠ 1`）。
- ⇒ 本文档 §四 B3 的「**只能限于带自环的图**」**方向是反的**（该来源是 `_PN3.bt-face-needs-selfloop`，而它是 5.1 旧读法的产物）。**正确边界：无自环图才是 π₁=0 的实例。**
