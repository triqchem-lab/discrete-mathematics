## 四、严格设计（三处关键决定）

### 4.1 `step` 必须**联合**（否则 ⑤ 不满足）

| 候选 `step` | clock | ⑤ 满足？ |
|---|---|---|
| 逐点 `GF9` 加法 | 3 ✗ | ✗ |
| 逐点 `GF9` 乘法（含 `α`）| 8 ✗ | ✗ |
| 逐点 `⟨α⟩` 乘（C₄）| 4 ✗ | ✗ |
| **逐点 `mixedOp`（加 ⊕ α-乘）** | **lcm(3,4) = 12** ✓ | ✓ |

⇒ **必须**用 `mixedOp` 的逐点版本 ✓（`DuodecClock.mixedOp` ✓ 现成可用）

### 4.2 相位分量必须是 `⟨α⟩`（C₄），**不是** `GF9*`（C₈）

`GF9* ≅ C₈` ✗ —— 若相位取整个 `GF9*`，`clock = lcm(3,8) = 24` ✗ ⇒ **⑤ 不满足** ✗

⇒ 相位**只能**取 `⟨α⟩ ⊂ GF9*`（阶 4）✓ —— 这正是 `phase-order = 4` ✓

⚠ 这也是「相位不可约性」的要求：C₄ → C₂ 或 C₄ → C₈ 都不是合法同余 ✓

### 4.3 刚性必须从 `galoisConjugate` 诱导

`GF9.galoisConjugate (a , b) = (a , negate b)` ✓（`GF9.agda:103`）
⇒ `rigidity f = λ x → galoisConjugate (f x)` ✓

⚠ 不得在函数层另立刚性来源（`Presentation.agda` 的硬约束）✓
