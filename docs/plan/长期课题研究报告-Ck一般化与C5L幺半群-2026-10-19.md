### 1.2 技术障碍（真卡点 ✗）

本库 C₅ 的证明**依赖具体边构造子**（10 条逐条命名 ✓ `E5`）✗——理由：参数化边 `cw5 i : E5 i (next5 i)` 中 `next5 i` 是**函数应用**，Agda 无法反演索引 ✗：

- 官方记录：**Agda issue #5501「Flat pattern matching and expressions on indices」** ✓（[github.com/agda/agda/issues/5501](https://github.com/agda/agda/issues/5501)）
- 经典讨论：**Agda mailing list 2014**「I'm not sure if there should be a case for the constructor … because I get stuck」✓（[lists.chalmers.se](https://lists.chalmers.se/pipermail/agda/2014/007241.html)）
- 本库先例：`_PN4:310`「先把顶点索引拆到具体构造子」✓（同一现象 ✓）

### 1.3 三条候选路径

| 路径 | 设计 | 风险 | 成本 |
|---|---|---|---|
| **(A) Fin n + 证明携带边** ✓ 推荐 | 顶点 `Fin n` ✓；边 `Σ (Fin n) (λ y → y ≡ suc x)` ✓（索引不再是函数应用 ✗ ⇒ 模式匹配可行 ✓）；单调性用 `suc` 注入 + 算术 ✓ 而非构造子枚举 ✓ | 边相等需 UIP/`≡-irrelevant` ✗（中等 ✓）| 探针 1–2 轮 ✓；全量 ~300 行 ✗ |
| (B) 关系式图（无边构造子） | 顶点 `Fin n` ✓；走 = `List (Fin n)` + 相邻性证明 ✓；证明全走算术 ✓ | 走的结构更复杂 ✗（`Walk` 需重定义 ✗）| ~400 行 ✗ |
| (C) 逐 k 具体实例 + 脚本生成 | 对 k = 5,6,7,… 各生成 10/12/14 条具体边 ✓（同 `_PEH46`–`_PEH52` 的生成法 ✓）| 无技术风险 ✓ 但**不一般** ✗（工作量线性 ✗）| 每 k ~1 轮（生成 ✓）|

**推荐序**：先做 **(A) 的 k=6 探针** ✓（验证 Fin 路径是否真避开索引墙 ✗）——
- 通过 ⇒ 一般化 ✓（一劳永逸 ✓）
- 失败 ⇒ 退回 (C) ✓（至少拿到 k=6,7 的具体实例 ✓）

## 二、课题 2：C5L 精确幺半群刻画

### 2.1 库内已有**现成模板** ✅✅

⇒ C5L 的刻画**不是新课题** ✗，是同一模板的**第二个实例** ✓（工程 ✓）。

### 2.2 ★★ 数学内容（**oracle 已判定** ✓ 修正原假设 ✗）

**oracle 回执 `96cc33a0…`（domain = points = 153 ✓ 完整覆盖 ✓）**：
```
C5L 闭走 ≤6 边 = 153 条 ⇒ 类数 = 3：
  [0] wind=0   （nil 类 ✓ 含全部零绕数闭走 ✓）
  [1] wind=+5  （cw 绕行一圈 ✓）
  [2] wind=−5  （ccw 绕行一圈 ✓）
[nil] 与 [(0,0)] ⇒ 同一类 ✓（自环平凡 ✓）
```

⇒ **π₁ᴬ(C5L) ≅ ℤ** ✓✓ —— **自环填充不增加幂等元** ✗✓（与 C₅ 相同 ✓ 与文献 π₁ᴬ(C_n)=ℤ 一致 ✓）

**修正原假设** ✗→✓：本报告初稿假设「自环幂等类 ε（`(x,x)` ✓ `ε·ε=ε` ✓ 且 `ε ≁ nil` ✗）」——
**该假设为假** ✗：`(0,0) ←tri-slide← (0,1,0) →bt→ nil` ✓（三角弦 = 自环 ✓ + 回溯消去 ✓）
⇒ `(0,0) ~ nil` ✓（**自环在标准 A-同伦下平凡** ✓）。

**幂等结构的真正归属** ✓：`ε ≠ nil` 只出现在**排除 bt 的 π₁ᵈ（slide/expand 商）** ✓——
即本库**故意设计的「中间层」** ✓（`docs/decisions/本源-投影分层` ✓：AStep 两沿恒正长 ⇒ 无回溯消去 ⇒ nil 类永不可及 ✓）——
⇒ 本课题的答案：**C5L 在标准 A-同伦下的精确幺半群 = ℤ** ✓（幂等幺半群是 π₁ᵈ 的对象 ✓ 不是 C5L 的 ✓）。
