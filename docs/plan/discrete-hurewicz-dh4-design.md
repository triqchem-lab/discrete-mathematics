## 一、两版对照定理设计（Thm 5.4：ℤ commutator 形 vs 本地模 3 形）

### 1.1 两版现状（代码实测锚）
| 面 | 文献 ℤ 版 | 本地 GF(3) 版（_PDH1） |
|---|---|---|
| 映射 | h_D : π₁ᴰ(X,x₀) → H₁^Cube(X)（**ℤ 系数**立方链，Def 5.1 p.24） | h₁ : π₁ᵈ(Gskel two-chain) → ℕ（npos 计数）+ **h₁₃ = trit3 ∘ h₁**（3-周期投影） |
| 满性 | Thm 5.4（p.26）：h_D 满 | h₁-surj / h₁₃-surj（已证，`_PDH1:§2`） |
| 核 | **Ker h_D = [π₁ᴰ, π₁ᴰ]（交换子）** | ker-h₁-walk（npos≡0 ⟹ [w]≡[nil]）+ 核特征双向（div3 分解 + trit3-3m）——**模 3 边链投影形，非 commutator 形** |
| 同态 | Prop 5.3（p.26） | h₁-hom（elimProp2 三案）✓ |

### 1.2 关键结构性事实（设计洞察——决定对照形）
**本地实例的 π₁ᵈ(Gskel two-chain) ≅ (ℕ,+) 是交换的**（gskel-classify `703f9cb2`）——其交换子群平凡！而 h₁₃ 的核非平凡（3 的倍数类）。**故「模 3 约化 commutator」不是本地核的正确描述**——两版核陈述**本质不同源**：
- 文献版核 = commutator（阿贝尔化动机：h_D 经 π₁^ab 分解——Thm 5.5 交换图 p.26-27）；
- 本地版核 = **3·子幺半群类**（计数模 3 投影的纤维）。

### 1.3 对照定理的正确陈述（推荐三件套）
**CT-1（阿贝尔化分解——文献侧已知形）**：h_D ≡ (经典 h ∘ θ) 分解经 π₁^ab（Thm 5.5）；本地对应件：h₁ ≡ rounds（π₁ᵈ ≅ (ℕ,+) 的同构分量）——**已在库**（gskel-classify 的 to 分量）。
**CT-2（系数约化桥——两世界的真正桥）**：`h₁₃ ≡ red₃ ∘ (π₁^ab ⊗ mod3) ∘ ab` 形——即本地 GF(3) 版 = 「阿贝尔化后系数 mod 3 约化」版。所需桥件：
  (a) **阿贝尔化函子** ab : π₁ᴰ → π₁ᴰ^ab（自由交换化——本地：π₁ᵈ 到 FAb 计数对的下降，**npos/nneg 计数对恰是 ab 数据**（_PPI4i walk4-classify 全证））；
  (b) **系数约化** red₃ : ℤ → Trit / H₁^ℤ → H₁^FAb（**本地缺 ℤ 系数同调面**——实测：Problem/Hodge/FreeAb* 族为 FAb/GF(3) 形，无 Int 链复形）；
  (c) **对照定理本体**：`red₃ ∘ h_D = h₁₃ ∘ θ⁻¹`（交换方块——在 two-chain/Gskel 实例上可全证；一般 X 立界）。
**CT-3（mod 3 版 Thm 5.4 的诚实改写）**：「Ker h₁₃ = 3·π₁ᵈ 类」（已证于 two-chain）——**定名为模 3 纤维定理**，不冒充 commutator 形。

## 二、n≥2 路线世界定案

### 2.1 三方案对比
| 案 | 内容 | 估 | 优点 | 缺点 |
|---|---|---|---|---|
| A 文献形移植 | Zⁿ 锯齿 digraph 映射类（Def 3.1 p.4-5）全建 | 300-500 行 | 忠实文献（πₙᴰ≅πₙ(\|K(X)\|) Thm 3.3 可对表） | 新机件重（Zⁿ 域/有限半径映射/拼接）；与本地 Ωⁿ 资产脱节 |
| B Ωⁿ 重述 | 纯 Ωⁿ 迭代路线（πₙᵈ := π₀(Ωⁿᵈ)）+ Hₙ 面 | 200-350 行 | **高复用**（_PPI5f/g/h/i + PT 线全资产）；n=1 四验已证 | 与文献形的对齐需定理桥（非定义重合） |
| C 混合 | **B 主线 + A 锯齿对照件**（对齐定理族续） | 250-400 行 | 兼顾忠实与复用 | 对齐定理族是持续投入 |

### 2.2 定案：**C 案（B 主线 + A 对照）**——与 dim-1 的 C 案衔接
**理由**：①对齐定理族已有首件（`_PPI5i` k2-zero→class-triv 构造向 + 一致形 refl——两路线在 π₂ 面已实证同一）；②DH-3 的 saw-cycle 已建 Z¹ 锯齿对照件（Z¹ ≅ Gskel 型图桥）；③Ωⁿ 资产（Ω3Walk/bubble-complete/TriFill/对齐）全在库——A 案全移植是重复建设；④n≥2 的**真难点在 Hₙ 面**（离散 Hₙ 与 πₙᵈ 的连接——Gao-Yang Thm 的全 n 版是他们的深定理），路线选择不解决这个深度问题，但 C 案把投入集中在对齐定理而非机件重建。

### 2.3 n≥2 实施目标（诚实定位）
- **目标不是**「证 Gao-Yang 全 n 定理」（深件——诚实界）；
- **目标是**：Ωⁿ 路线的 n=2 离散 Hurewicz 形（π₂ᵈ → H₂^FAb 的构造性映射 + S²ᵈ 全证实例）+ 对齐定理续（π₂ 面两路线同一性闭合）；
- n≥3 阶梯化（Ωⁿ 迭代形递推）——按需开批。
