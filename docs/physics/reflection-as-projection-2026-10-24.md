## 一、理论依据来自哪里

### 1.1 `docs/duodecimal/41-strength-vs-transparency.md`

**判据不是「学科」，是「结构」**（该文第 4–6 行的自我纠正）：

| 类别 | 判据 | 例 |
|---|---|---|
| **本源**（透明） | 显式构造 + 穷举验证 + 有限步骤 | `GF(3)` 算术、`GF(9)` 的 Frobenius `x ↦ x³` |
| **投影**（遮挡） | 需要反证法 / 选择公理 / 无穷逼近 | `ℂ` 的域自同构、`D₁₂` 的反射、`ℤ` 的良序 |

**关键句**：「`rho` 的投影性来自它是 `DC ⋊_ρ C₂` 的**半直积反射**，不是来自『它是群论』。」

### 1.2 `09-complex-numbers.md` + `10-norm-collapse.md`

**复数的「原生共轭」为什么是投影：**

- **`ℂ` 的共轭**是 `ℂ` 的**域自同构**，但证明它存在需要选择/反证 ⇒ **投影**
- **`GF(9)` 的共轭**是 Frobenius `x ↦ x³`，**显式、可穷举（9 个元素）** ⇒ **本源**

**⇒ 同一个「共轭」概念，在 `ℂ` 上是投影，在 `GF(9)` 上是本源。**
**⇒ 这不是「域论 vs 群论」，是「显式可验 vs 需要无穷/选择」。**

### 1.3 `11-type-theory-presentation.md`（代数刚性）

**刚性** 指：结构由**生成元 + 关系**唯一确定，没有连续变形自由度。

- Frobenius 诱导的刚性（`σ_DC(t, αᵏ) = (t, α⁻ᵏ)`）是**显式**的 ⇒ 本源
- `D₁₂` 的半直积反射 ρ 是 `λ ∘ μ`，**不是**纯 Frobenius ⇒ 遮挡（投影）

**⇒ 「反射是投影」在库里的原意**：反射（半直积意义下）是**导出结构**，
它的存在依赖比 Frobenius 更弱的前提。

## 二、应用到光学反射/折射

### 2.1 判据怎么用

把 1.1 的判据套到「光学反射定律 θr = θi」，问：

> **它需要被当作公设，还是能从更本源的结构导出？**

**答案：能导出。** 从 Huygens 原理（波前每点是次级源）出发，
相位匹配条件自动给出反射定律与 Snell 定律。

**⇒ 按 41 号文的判据，光学反射/折射是投影。**

### 2.2 形式化的内容（`HuygensProjection.agda`，247 行，0 postulate）

| 部分 | 定理 | 内容 |
|---|---|---|
| **§1–§4** | `A-zero`, `A-one`…`A-seven`, `projection-is-delta` | **Huygens 求和** `A(k) = Σ_{j=0}^{7} ω^{jk}`（`ω = gen = 1+α`，GF(9)，阶 8）满足 `A(0)=2`、`A(1..7)=0` ⇒ **delta 投影** |
| **§7** | `fresnel-core` | **代数核** `(a+b)² = (a−b)² + 4ab`（ℤ，ring solver） |
| **§8** | `fresnel-energy` | **物理 R+T=1** 的通分形式 `n₁(n₁+n₂)² = n₁(n₁−n₂)² + n₂(2n₁)²` |
| **§10** | `CompProj` record | **互补正交投影对**的代数骨架（幂等 idem₁/idem₂ + 完备 complete + 正交 orth₁₂/orth₂₁） |
| **§11** | `sp-projection` | **s/p 偏振分解**在 `Trit × Trit` 上的实例（六个字段全部证完） |

**⇒ 反射定律没有被当作公设 —— 它是 `A(k)` 在 `k=0` 处的唯一非零分量。**

### 2.3 为什么用 GF(9) 而不是 ℂ

这正是 1.2 的判据：

- **用 `ℂ`**：需要连续相位 `e^{iθ}`、无穷求和、极限 ⇒ **投影**（且违宪：禁 `Data.Complex`）
- **用 `GF(9)`**：`ω` 是**有限的 8 次单位根**，求和是**8 项**，全部 `refl` ⇒ **本源**

**⇒ 同一物理结论，在 GF(9) 上可穷举验证，在 ℂ 上不是。**
