## 1. 连续统的危机

### 1.1 经典数学的连续统假设

自 Newton-Leibniz 以来，数学建立在连续统 ℝ 之上：

- **分析学**: 极限、导数、积分 — 全部依赖 ε-δ 语言
- **物理学**: 微分方程描述自然律 (Newton, Maxwell, Einstein, Schrödinger)
- **优化**: Weierstrass 定理、KKT 条件 — 需要紧性和完备性
- **生物学**: Lotka-Volterra 方程、复制动力学 — 需要 ODE 存在唯一性

### 1.2 连续统在类型论中的 TypeError

在构造性类型论 (Agda/Coq/Lean) 中，连续统的核心操作不可计算：

| 连续操作 | 为什么是 TypeError | 离散替代 |
|---------|-------------------|---------|
| lim_{n→∞} a_n | 无穷过程，非有限计算 | 有限格点上的代数恒等式 |
| ∂f/∂x | 极限商，不可判定 | GF(3) 差分 f(x+1)⊕f(x) |
| ∫f dx | 不可数求和 | GF(3) 有限求和 Σ |
| 紧性 | 开覆盖不可判定 | 有限集自动"紧" |
| Brouwer 不动点 | 非构造性存在 | 鸽巢原理 (构造性) |
| Weierstrass 极值 | 需要完备性 | 有限集穷举 |

### 1.3 不可判定性的根源

连续统 ℝ 的不可判定性来自：
- **不可数性**: Cantor 对角论证，ℝ 不可枚举
- **Archimedes 序**: 需要无穷比较
- **完备性**: Cauchy 列的极限不在有限计算内
- **选择公理**: 非构造性存在证明

## 2. GF(3) 离散革命

### 2.1 为什么是 GF(3)？

GF(3) = {0, 1, 2} (mod 3) 是最小的奇特征有限域：

- **特征 3**: x + x + x = 0 (三重归零，对应三态循环)
- **奇特征**: 有非平凡乘法逆元 (2⁻¹ = 2)，支持除法
- **最小非平凡**: GF(2) 太退化 (1+1=0)，GF(3) 保留足够结构
- **三态逻辑**: T₀(基态)/T₁(单位态)/T₂(双倍态) — 比布尔逻辑多一个自由度

### 3.1 穷举法 vs 存在性定理

经典数学的许多存在性定理是非构造性的：
- Brouwer 不动点: 存在但不可计算
- Weierstrass 极值: 存在但不可达
