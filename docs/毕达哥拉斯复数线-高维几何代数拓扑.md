## 0. 术语考据（诚实边界）

- 数学史上**不存在**定名为"毕达哥拉斯复数学派"的学派。
- 真实存在的是**毕达哥拉斯学派**（约公元前 530 年, 克罗顿）: "万物皆数"、
  勾股数、乐律整数比、√2 不可公度危机（Hippasus）。
- "复数"本身是 16 世纪（Cardano/Bombelli）才登场, 与古希腊无关。
- "毕达哥拉斯复数线"在本项目中的**工作定义**: 指以二次型为主干、
  连接毕达哥拉斯数论与高维几何代数拓扑（符号差/手术理论/K 理论）的数学脉络,
  复数侧由陈类（Chern–Weil）承载。此名称仅用于本项目内部索引。

## 1. 数学主线: 毕达哥拉斯 → 二次型 → 高维拓扑

| 环节 | 内容 | 备注 |
|---|---|---|
| 毕达哥拉斯三元组 | x²+y²=z² — 数学史上第一个二次型方程 | 本原三元组由 (m+ni)² ∈ Z[i] 生成: (m²−n², 2mn, m²+n²) |
| 二次型 | x²+y²（二元正定, Z[i] 范数）; x²−xy+y²（60° 格, Z[ω] 范数） | 判别式 −4 / −3 两族, 正是本项目 Eisenstein 的故乡 |
| 符号差定理 (Hirzebruch) | 4k 维流形的符号差 = L 亏格（Pontryagin 数的多项式） | 符号差 = 相交形式二次型的 p−q |
| 手术理论 (Kervaire–Milnor) | 高维流形分类障碍 = Z 或 Z/2 上二次型 + Arf 不变量 | 二次型决定高维拓扑形状 |
| Milnor 猜想 (Voevodsky, 2002) | Milnor K 群 mod 2 ≅ 模 2 Galois 上同调 ≅ Witt 环分级 | K 理论 = 二次型世界 = motivic 上同调 |

## 2. 复数侧: 陈类 / Hodge / 复配边

- 陈类出生在复几何（复流形上全纯向量丛, Chern–Weil 理论）。
- 高维几何代数拓扑 = 实数侧（二次型/Pontryagin/符号差）+ 复数侧（陈类/Hodge/复配边）合流。
