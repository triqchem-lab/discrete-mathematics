## 总裁定

1. **三锚点的实证内容基本对应**（C1-C3、D1-D2、B3 精确吻合），但**名称与锚点漂移普遍**：「规则 40」「encodeT6」「jac_Complexity/jac_BSD」「144-case 同态」四处需勘名。
2. **两处越界必须修正**：E2「3×3/4×4 小分量」是 jac_CRTDet 已书面修正的误读；B2「Z/12 本体、GF(3)/GF(9) 截面」违本体论红线。
3. **一处数字不实**：E4「34 个 Jacobian 模块」（现计 15/9）。
4. **拱顶石与桥接定理是注释级强、类型级弱**：一般 N 的 CRT 行列式分解（E1）与桥接等价链（F2/F3）尚未形式化；其中 F3 的 dimH₀=0 腿与库内具象值矛盾，疑陈述错误。
5. **认识论主张（H2）越层**，与「Agda 通过 ≠ 数学通过」裁决冲突，须按三层裁决改写。
6. **0-postulate 只能链级声称**（H1）；库级有 27 模块 postulate + 3 hole，如实列出。
