### 2.1 离散 Galois 代数拓扑

**边界矩阵化**：T⁶ ≅ (GF(9))³ 的拓扑结构映射为有限复形。链复形 C_{k+1} → C_k → C_{k-1} 中的 ∂_k 严格表现为 GF(3)/GF(9) 上的系数矩阵。

**同调秩计算**：H_k = ker ∂_k / im ∂_{k+1} 的维数通过 GF(9) 上的线性代数消元法 0-postulate 计算：
```
dim H_k = nullity(M_∂_k) − rank(M_∂_{k+1})
```

**示性数与鸽巢双射**：χ(X) 完全由全局函数表矩阵 M_F 的行列式与迹编码。离散宇宙中的拓扑连通性就是映射的单射⇔满射等价性（鸽巢原理）。

### 2.2 离散 Frobenius-Galois 群代数

**群结构的离散代数化**：G = Aut(T⁶/GF(9)) ⊂ GL_n(GF(9))。连续李群 G(ℂ) 降维替换为有限环面上的代数自同构群。

**Frobenius 驱动力**：exp(tX) → σ(z)=z³。群元素的代数作用不依赖微分方程的积分流，由有限域自同构幂次直接驱动。
