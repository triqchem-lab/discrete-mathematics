## 一、验收铁律

每个问题的每个定理必须满足全部三条:

1. **编译通过**: `agda` 返回 0 error (warning 可接受)
2. **证明项存在**: 每个定理的证明体是 `refl` / `≡-Reasoning` / `cong` / `⊥-elim`
   — 不能是空、不能是注释
3. **0 postulate**: 不允许 `postulate` 关键字出现在代码中 (注释中说明 "0 postulate" 不算违规)

**禁止的伪证明模式**:
- ❌ `n : ℕ; n = 28` 然后声称"#E=28已证" (这只是赋值)
- ❌ `-- 定理成立 ✓` (注释不是证明)
- ❌ 声称"由 XXX 模块代数扩张"但不导入也不引用 (口头引用)
- ❌ `complete_step` 用 `kind: "manual"` 签收 (必须用 `kind: "verification"`)
