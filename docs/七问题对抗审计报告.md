## 二、逐模块审计结果

### YM (Yang-Mills 质量间隙) — jac_YM_DetMul.agda

**声称**: det(AB)=det(A)det(B) + 质量间隙
**实际证明**:
- I2-det: det(I₂)=1 refl ✅ (正确)
- I2-nonzero: 1≢0 λ() ✅ (正确)
- I3-nonzero: det(I₃)≢0 λ() ✅ (正确)
- I4-nonzero: det(I₄)≢0 λ() ✅ (正确)

**问题**:
- det(AB)=det(A)det(B) **没有形式化证明**. 注释说 "由 jac_Matrix 6561 case 穷举",
  但实际代码中只有 I₂/I₃/I₄ 单位矩阵的 det≠0, 没有任何 AB 相乘的验证.
- "质量间隙"仅注释, 没有任何定理或命题.
- "CRT N×N" 仅注释, 没有代码.
- 严重程度: **高** — 声称 L3 但实际是 L1 (仅实例).

### BSD (Birch-Swinnerton-Dyer) — jac_BSD_L3.agda

**声称**: tₙ递推严格递归定义 + 正确性证明 ∀n
**实际证明**:
- t-rec: 递归定义 ✅ (结构正确)
- t1-t6: 6个具体值验证 ✅ (全部 refl)
- "∀n 正确性" **仅注释**, 没有归纳原理的形式化声明.
- 严重程度: **中** — 递归定义正确, 但 ∀n 的归纳证明缺失.

### Hodge 猜想 — jac_ChainComplex.agda

**声称**: dimℋ=dimH 非定义相等证明 + Hodge 分解
**实际证明**:
- ChainComplex record 含 hodge-decomp 字段 ✅ (正确)
- tri 实例: hodge3 refl ✅ (正确)
- tri-H0/tri-H1: dimH=1 refl ✅ (正确)
- "dimℋ=dimH 定理" **仅注释** (第21行: "定理: dimℋ = dimH"),
  但代码中没有对应的 hodge-thm 证明项.
- hodge-decomp 是 record 字段 (公理式声明), 不是被证明的定理.
- 严重程度: **中** — 框架正确, 但 hodge-thm 证明缺失.

### PvsNP — jac_CubicRootTest.agda

**声称**: GF(3) 上三次多项式有根⟹可约, 构造性证明
**实际证明**:
- eval3: 正确的求值函数 ✅
- λ³+2λ+1: 三求值全≠0, irr-λ³+2λ+1 ✅ (正确)
- 对照实例: λ³-λ 和 λ³+λ²+λ+1 的根检测 ✅ (正确)
- p-coef/s-coef: 因式分解商系数构造 ✅ (类型正确)
- 但: 因式分解的恒等式 (λ-r)·q(λ) ≡ f(λ) **没有验证**.
  只有 p-coef/s-coef 的输出值用 refl 验证, 没有 "展开乘积 = 原多项式" 的证明.
- 严重程度: **中** — 根检测正确, 因式分解恒等式未闭合.

### Langlands — jac_GL2_Ortho.agda

**声称**: trivial × Steinberg ℤ 正交性
**实际证明**:
- inner-1-St: 正交性内积计算 = 0, ortho-1-St refl ✅ (正确)
- inner-St-St: ‖χ_St‖² = 5760 = |G|, irred-St refl ✅ (正确)
- inner-1-1: ‖χ₁‖² = 5760 = |G|, irred-1 refl ✅ (正确)
- 严重程度: **低** — 计算正确, refl 闭合. 这是七个模块中最严谨的.

### RH (黎曼猜想) — jac_RH_FuncEq.agda

**声称**: Hasse-Weil 泛函方程代数验证
**实际证明**:
- tE1/tE2/tE6: trace 赋值 ✅
- #E-GF3-E1/E2/E6: 点计数赋值 ✅
- #E-GF27: #E=28 赋值 ✅
- 但: 泛函方程 ζ(T)=ζ(1/qT) 的证明 **全部在注释中** (第8-30行).
  没有任何 Agda 定理项验证这个代数恒等式.
- sym-ratio: N₀-N₂ = -2, 这只是一个数字, 不是泛函方程的证明.
- 连续统污染: 注释中出现 √3, √q, 3.464, 10.39, i/√3, "复根", "判别式<0"
  — 违反 v7.0 §2.2 (离散极论域: 有限, 无连续统概念).
- 严重程度: **高** — 泛函方程未形式化, 注释有连续统污染.
