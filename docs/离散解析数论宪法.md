# 离散解析数论 · 雅可比框架宪法

> **地位**: 核心疆域分支宪法
> **原则**: 数论是离散的，ζ 零点不是分析对象，而是 Frobenius 特征值的模长刚性投影
> **日期**: 2026-07-27

---

## 核心原则

> 数论是离散的，素数分布是 GF(9) 上全息矩阵特征多项式的不可约性谱。ζ 函数的零点不是分析对象，而是 Frobenius 特征值的模长刚性投影。

不是"用离散方法研究解析数论"，而是"经典解析数论的超越函数和连续谱只是离散全息矩阵谱在特征 0 下的粗糙近似"。
