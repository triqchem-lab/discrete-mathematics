# 离散代数拓扑 · 雅可比框架宪法

> **地位**: 核心疆域分支宪法
> **原则**: 离散是本质，连续是 CRT 谱投影的实验显现
> **日期**: 2026-07-27

---

## 核心原则

> 空间是构造的，不是赋予的。同调群维数由有限域矩阵的秩唯一确定。
> 不是"用离散近似连续拓扑"，而是"连续代数拓扑的奇异同调和基本群只是离散刚性在实数域下的粗糙投影"。

## 经典 vs 我们的代数拓扑

| 维度 | 经典代数拓扑 | 离散代数拓扑 (本项目) |
|:---|:---|:---|
| **基域** | ℝ / ℂ，连续谱污染 | GF(3) / GF(9)，绝对离散 |
| **单纯形** | 连续 Δⁿ，链群无限维 | T⁶ 格点复形，有限点集 `Fin n → Trit` |
| **边界算子** | ∂ₖ : Cₖ(ℝ) → Cₖ₋₁(ℝ)，无限维 | 3×3 GF(3) 矩阵，严格可算 |
| **同调** | Hₖ(X;ℝ)，无限维可能，不可计算 | dim H = nullity − rank，ran-nullity refl |
| **欧拉示性数** | 连续同调的交替和 | h⁰ ∸ h¹ = 0 (refl)，类型检查器归约 |
| **基本群/同伦** | 连续软路径，πₖ(Sⁿ) 同伦膨胀 | 群论闭包，有限置换 + σ(x)=x³ 代数锁 |
| **Hodge 理论** | Δ = ∂∂\*+∂\*∂，依赖正定内积与椭圆算子 | 正合列不分裂，数值 rank-nullity 替代存在性证明 |
| **验证方式** | ε-δ 极限，非构造性存在定理 | 0 postulate 穷举/递归/矩阵乘法 refl |
