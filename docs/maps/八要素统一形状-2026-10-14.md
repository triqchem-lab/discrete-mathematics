## 三、三段式结构规范

```
<件>.agda
├── ① 生成元族      data Gen : Set where …        （带来源标记注释）
├── ② 载体          类型别名 = 乘积  ／  record … field carrier : Set
└── ③④⑤⑥⑧ 关系族   record Presentation : Set₁ where field …（相位/时钟/归零/核对都在此）
    ⑦ 刚性        引用 Sovereign.Algebra.GF9.galoisConjugate（不写在 record 内）
```

**关键**：八要素**不**收进单个扁平 record。正源明确「生成元用 `data`、载体用 record/别名、关系用 record 字段」——
强塞成 8 个同层字段会让类型异质（载体是 `Set`、关系是一串律、核对是定理），反而不可通用。

**命名约定**（推荐，非强制）：record 内的载体字段一律叫 `carrier`；相位算子叫 `phase`/`rotate*`；时钟叫 `clock`；单位元叫 `e`/`zero*`；核对定理以 `check*`/`*-roundtrip` 命名。

```agda
module Shape where

open import Data.Nat using (ℕ)
open import Data.Fin using (Fin)
open import Data.Product using (_×_; _,_)
open import Data.Unit using (⊤; tt)
open import Relation.Binary.PropositionalEquality using (_≡_; refl)

-- ① 生成元族（data，带代数来源标记）
data Gen : Set where
  g3 : Gen   -- 来源：F₃ 加法（损益循环）
  g4 : Gen   -- 来源：⟨α⟩ 相位乘法（90° 旋转）

-- ② 载体（类型别名 = 乘积类型）
Point : Set
Point = Fin 3 × Fin 4

-- ③④⑤⑥⑧ 关系族（record 字段）
record Presentation : Set₁ where
  field
    carrier : Set                                              -- ①
    _·_     : carrier → carrier → carrier                      -- ② 生成元（运算）
    e       : carrier                                          -- ⑥ 归零
    assoc   : ∀ (x y z : carrier) → (x · y) · z ≡ x · (y · z)  -- ③ 关系
    zeroʳ   : ∀ (x : carrier) → x · e ≡ x                       -- ③ 关系
    phase   : carrier → carrier                                -- ④ 相位
    clock   : ℕ                                                -- ⑤ 时钟
    check   : ∀ (x : carrier) → x · e ≡ x                      -- ⑧ 核对（refl 层）

-- ⑦ 刚性：不在本 record 内。从 GF9 诱导：
--     Sovereign.Algebra.GF9.galoisConjugate : GF9 → GF9
--     诱导 σ(t, α^k) = (t, α^{-k})
```

### 8.1 ★ 零冥族 = 两层归零的联合（人类裁定 2026-10-14）

> **人类原话**：「这个他们的基础是**零冥族** —— **特征 3 的归零**，和**相位 C₄ 旋转群的归零**。」

代码逐字对应（`GroupTheory/DCGroup.agda` 的 `record ZeroOblivion`，`DuodecClock` 同款）：

```
零冥族 ZeroOblivion
 ├─ 单位元          addZeroR / addZeroL   （mixedOp x e ≡ x；交换律下的归零元）
 ├─ 特征 3 的归零    tritCycle : ∀ t → (t ⊕ t) ⊕ t ≡ T₀     ← 加法分量，周期 3
 ├─ C₄ 旋转群归零    mulAlphaCycle : … a1 a1 ≡ a0            ← 乘法分量，周期 4
 └─ 联合归零        jointCycle : ∀ p → mixedOp¹² p ≡ p       ← lcm(3,4) = 12
```

⇒ **零冥族不是单一归零，而是「分量级归零 × 联合级归零」的三层结构** ✓
⇒ 这与 g4 的结论**互为结构对应物**（见 8.4）。

### 8.2 P1 / P2 裁定（g1+g2 联合检验）

| 命题 | 裁定 | 依据（代码事实） |
|---|---|---|
| **P1 相位-时钟同源** | ❌ **不成立** | `mixedOp (x,a) (y,b) = (x ⊕ y , mulAlpha a b)` —— 分量级联合；`phase` 周期 4、`clock` 周期 12 = lcm(3,4)。`DuodecClock` 头部红线：「加乘联合，非纯加法直积」「勿写成 C₃×C₄ 直积或 C₁₂ 循环群」 |

**⚠ 一处对既有分析的校正**：某分析稿曾推论「12 不是 GF9 的群论不变量 ⇒ `phase` 不可能取值于 GF9\*」。**前半对、后半错** —— `phase = mulAlpha` 恰恰取值于 GF9\*（⟨α⟩ 是 `GF9* ≅ C₈` 的 4 阶子群，见 `PhaseSubgroup.alpha-order-exactly-4`）。矛盾的根源是把「12 阶**元素**不存在于 C₈」与「相位取值于 GF9\* 不可能」混为一谈：**12 是联合周期，不是任何单个群元素的阶**。

### 8.4 12 不可由单分量给出（g4）

**命题修正**：原拟「不存在一元 `f` 使 `clock-cycle` 等价于 `f^12`」**不成立** —— 一元 `f` 确实存在（`f = λ p → mixedOp p (T₁,a1)`）。真正的判定点在**最小性**：

```
① 加法分量（Trit）周期 = 3   ② 相位分量（AlphaPower）周期 = 4
③ 联合（mixedOp）周期 = 12 = lcm(3,4)
④ 只推进一个分量的作用，周期必 ∈ {3,4}   ⑤ 3 ≢ 12 且 4 ≢ 12
⇒ 12 不可能由单分量作用给出
```

**决定性反例**：`twelve-is-multiple-of-4 : 12 ≡ 4 * 3` —— 相位分量在 k=4 就归零、而 4 ∣ 12 ⇒ 若 `clock-cycle` 只要求「12 步归零」，**只推相位的 `phase` 也满足** ⇒ 联合语义被抹掉 ⇒ `clock` 必须取**最小**周期。

形式化落地：`GroupTheory/DuodecClockProperties.agda`（`three-not-twelve` / `four-not-twelve` / `single-component-periods-exclude-12` / `twelve-is-multiple-of-4`），提交 `1d6e587`。

### 8.5 形态决定：一元 / 二元是**两层视图**，共存（不必推翻 L3）

| 层次 | 形态 | 对应 |
|---|---|---|
| **分量级** | 一元作用 | 正源「生成元用 `data`」—— `Trit` / `AlphaPower` 皆为 `data`，其上 δ/φ 是**一元**作用 |
| **联合级** | 二元运算 | `mixedOp` —— 分量级的**联合** |

⇒ **一元化可行**（把「二元 + 生成元」打包成单个一元作用，如 `DayanCore §4` 的 `iterate (δ ∘ φ) 12 c ≡ c`），**但一元作用必须同时推进两分量**，不可退化为单分量迭代。

⇒ 正源「生成元用一元作用」与 DC 的「二元联合」**不矛盾**，是同一结构的**两层视图**。
⇒ **结论：`Presentation` 不需要改形态** —— 其二元 `step` 是对的，缺的只是把这条层次关系讲清（即本节）。
