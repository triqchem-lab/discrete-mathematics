## 三、三段式结构规范

```
<件>.agda
├── ① 生成元族      data Gen : Set where …        （带来源标记注释）
├── ② 载体          类型别名 = 乘积  ／  record … field carrier : Set
└── ③④⑤⑥⑧ 关系族   record Presentation : Set₁ where field …（相位/时钟/归零/核对都在此）
    ⑦ 刚性        引用 Sovereign.Algebra.GF9.galoisConjugate（不写在 record 内）
```

**关键**：八要素**不**收进单个扁平 record。正源明确「生成元用 `data`、载体用 record/别名、关系用 record 字段」——
强塞成 8 个同层字段会让类型异质（载体是 `Set`、关系是一串律、核对是定理），反而不可通用。

**命名约定**（推荐，非强制）：record 内的载体字段一律叫 `carrier`；相位算子叫 `phase`/`rotate*`；时钟叫 `clock`；单位元叫 `e`/`zero*`；核对定理以 `check*`/`*-roundtrip` 命名。

## 四、可编译样板（Agda 2.9 实测 EXIT=0）

```agda
module Shape where

open import Data.Nat using (ℕ)
open import Data.Fin using (Fin)
open import Data.Product using (_×_; _,_)
open import Data.Unit using (⊤; tt)
open import Relation.Binary.PropositionalEquality using (_≡_; refl)

-- ① 生成元族（data，带代数来源标记）
data Gen : Set where
  g3 : Gen   -- 来源：F₃ 加法（损益循环）
  g4 : Gen   -- 来源：⟨α⟩ 相位乘法（90° 旋转）

-- ② 载体（类型别名 = 乘积类型）
Point : Set
Point = Fin 3 × Fin 4

-- ③④⑤⑥⑧ 关系族（record 字段）
record Presentation : Set₁ where
  field
    carrier : Set                                              -- ①
    _·_     : carrier → carrier → carrier                      -- ② 生成元（运算）
    e       : carrier                                          -- ⑥ 归零
    assoc   : ∀ (x y z : carrier) → (x · y) · z ≡ x · (y · z)  -- ③ 关系
    zeroʳ   : ∀ (x : carrier) → x · e ≡ x                       -- ③ 关系
    phase   : carrier → carrier                                -- ④ 相位
    clock   : ℕ                                                -- ⑤ 时钟
    check   : ∀ (x : carrier) → x · e ≡ x                      -- ⑧ 核对（refl 层）

-- ⑦ 刚性：不在本 record 内。从 GF9 诱导：
--     Sovereign.Algebra.GF9.galoisConjugate : GF9 → GF9
--     诱导 σ(t, α^k) = (t, α^{-k})
```

## 五、机检规则（门禁若建，据此 grep）

| 要素 | 机检信号 | 强度 |
|---|---|---|
| ① 载体 | `field` 行含 `carrier\s*:` **或** 顶层 `X : Set` + `X = … × …` | 强 |
| ② 生成元 | 顶层 `^data\s+\w+` **且** 其构造子旁有「来源」标记注释 | 中 |
| ③ 关系 | record 内同时含 `assoc`/`identity`/`inverse` 类字段 | 中 |
| ④ 相位 | record 内字段名含 `phase`/`rot`，**或** 有 `N` 阶循环定理（`-order-N`） | 中 |
| ⑤ 时钟 | record 内字段名含 `clock`/`cycle`，**或** `^n p ≡ p` 形式定理 | 中 |
| ⑥ 归零 | record 内字段名含 `zero`/`e\s*:`，**或** 零冥族定理 | 中 |
| ⑦ 刚性 | **引用** `galoisConjugate`（或等价 Galois 作用） | 强 |
| ⑧ 核对 | `refl` 证明 / `*-roundtrip` / `check*` | 弱（正源：不产生结构） |

⚠ **机检是候选器不是判官**（M8 §5）：`Techniques/Pgm1-2` 这类工具件会被词面命中，须以**白名单排除**；反之 `DCGroup` 的核对以 `alpha-order-4` 形式存在，会被漏报。
