## 第一层：有限性、鸽巢原理、构造性基础

### 1.1 Dedekind 有限性（1888）

**出处**：Richard Dedekind, *Was sind und was sollen die Zahlen?*, Braunschweig: Vieweg, 1888, Definition 64.

**核心主张**：集合 \(S\) 是 **Dedekind 有限**的，当且仅当每个单射 \(S \to S\) 都是满射。等价地，\(S\) 不能与任何真子集建立双射。这是历史上第一个不依赖自然数定义的"有限"概念。

**与框架的关系**：`injSurj : Inj ρ → Surj ρ` 是 Dedekind 有限性在 `Fin n` 上的构造性实例。在构造性类型论中，"有限"被重新定义为**型有限**（`Finite A = ∃ n, A ≃ Fin n`），Dedekind 定义变成一条需要证明的定理。

**形式化切入点**：

```agda

-- 待建：推广到任意有限类型

DedekindFinite A = (f : A → A) → Injective f → Surjective f

Finite→DedekindFinite : ∀ {A} → Finite A → DedekindFinite A
Finite→DedekindFinite (n , A≃Fin) f inj = 
  -- 通过等价传输，把 f 搬到 Fin n 上，调用 injSurj，再搬回来
```

**依赖**：已有 `Fin n` 版本（`FiniteDynamics.agda`）
**工作量**：60–100 行

### 1.2 Dirichlet 抽屉原理 / 鸽巢原理（1834）

**出处**：Peter Gustav Lejeune Dirichlet, 1834，以 **Schubfachprinzip**（抽屉原理）之名提出。

**核心主张**：若 \(n+1\) 个物体放入 \(n\) 个盒子，则至少一个盒子含两个物体。

**与框架的关系**：`pigeonhole-fin` 直接包装了 `Data.Fin.Properties.pigeonhole`，是 `injSurj` 证明的核心支点。鸽巢原理的构造性证明**不走搜索路线**，而是对 \(n\) 的组合归纳直接证明。

### 1.3 Tarski-Kuratowski 有限性定义（1920–1924）

**出处**：Alfred Tarski, *Sur les ensembles finis*, Fund. Math. 6 (1924), 45–95；Kazimierz Kuratowski, 1920。

**核心主张**：\(S\) 有限 \(\iff\) \(S\) 的每个非空子集族（在包含关系下）都有极小元（Tarski）。Tarski 定义集合 \(\mathbf{x}\) 为有限，当且仅当真子集关系 \(\mathbf{PS}\) 在 \(\mathbf{x}\) 的幂集上的限制是良基的。与 Dedekind 定义在经典逻辑下等价，但在构造性逻辑下**互不推导**。

**与框架的关系**：这形成了"有限性定义动物园"。框架锁定在**型有限**（`Fin n`）上，需要证明型有限蕴含 Dedekind 有限。形式化"有限性定义之间的蕴含关系"是一个独立的理论任务。

**形式化切入点**：

```agda
-- 型有限 → Dedekind 有限（可证）
Finite→DedekindFinite : ∀ {A} → Finite A → DedekindFinite A

-- Dedekind 有限 → 型有限（构造性可能不成立）
-- 需标注为经典等价
DedekindFinite→Finite-Classical : ...  -- 经典逻辑下成立
```

**依赖**：P0-a（`injSurj` 推广）
**工作量**：100–150 行
**优先级**：P1（依赖 P0-a）

### 4.2 Eckmann 离散 Hodge 定理（1944–1945）

**出处**：Beno Eckmann, *Harmonische Funktionen und Randwertaufgaben in einem Komplex*, Comment. Math. Helv. 17 (1944–45), 240–255. Eckmann 在 1944 年指出 Hodge 工作在有限线性代数框架下进行。

**核心主张**：组合拉普拉斯算子最早出现在 Eckmann 关于有限维 Hodge 理论的工作中。他证明并表述了**离散版 Hodge 定理**：在有限单纯复形上，Hodge 分解的证明全部是有限维线性代数的练习。核心分解为：

\[
C^k = \operatorname{im}(\partial_{k+1}) \bigoplus \operatorname{im}(\delta^{k-1}) \bigoplus \ker(L_k)
\]

**⚠ 修正**：Eckmann 的 Hodge 分解**只在正定内积下成立**。\(GF(3)\) 上的内积不正定（\(x\cdot x\) 可以为 0），所以 \(\oplus\) 应该是**子空间和**，不是直和。正确表述：

```agda
-- 经典版本（需要正定内积）
eckmann-hodge-classical : C k ≡ im(∂ (suc k)) ⊕ im(δ k) ⊕ ker(L k)

-- GF(3) 版本（只有子空间和）
eckmann-hodge-gf3 : C k ≡ im(∂ (suc k)) + im(δ k) + ker(L k)

-- 不分裂定理：三部分不正交
non-splitting : im(∂ 1) ∩ ker(δ 0) ≠ {0}
```

**与框架的关系**："正合列不分裂"现象——\(\text{im}(\partial_1)\cap\ker(\delta_0)\neq\{\mathbf{0}_v\}\)——在 Eckmann 框架中对应三部分**不正交**的退化情形。在传统 Hodge 理论中，正定内积保证正交分解；在 \(GF(3)\) 上，内积的正定性丧失，正合列不再直和分裂。

**依赖**：链复形基础
**工作量**：200–250 行
**优先级**：P2

### 4.3 Dodziuk 组合 Hodge 逼近（1976）

**出处**：Jozef Dodziuk, *Finite-difference approach to the Hodge theory of harmonic forms*, Amer. J. Math. 98 (1976), 79–104.

## 第七层：表示论与不忠实表示

### 7.1 Burau 表示的不忠实性（1991–1999）

**出处**：J. Moody, 1991；D. Long & M. Paton, 1993；Stephen Bigelow, *The Burau representation is not faithful for n=5*, Geometry & Topology 3 (1999), 397–404. Bigelow 通过构造 5-穿孔圆盘上的一条曲线证明了这一结果。目前唯一开情形是 \(n=4\)。

**核心主张**：Burau 表示在 \(n\geq 5\) 时不忠实。

**与框架的关系**："不忠实商禁止"公理在表示论中对应的是**忠实表示与不忠实表示的区分**。Burau 表示的不忠实性表明：不忠实表示会丢失拓扑信息，与"同伦泄露"概念在直觉上一致。

**形式化切入点**：

```agda
-- 忠实表示
Faithful : (ρ : Group → Matrix n n R) → Set
Faithful ρ = Injective (representationMap ρ)

-- Burau 表示的不忠实性
burau-not-faithful : ∀ n → n ≥ 5 → ¬ Faithful (burau n)
```

**依赖**：辫群基础、矩阵表示
**工作量**：250–350 行
**优先级**：P3

### 7.2 Kac-Moody 代数的不忠实表示

**出处**：V. Kac, *Infinite Dimensional Lie Algebras*, 1990 及相关文献。K(E9) 和 K(E10) 的表示被证明是不忠实的——它们是无限维代数的有限维表示，因此核非平凡。这些不忠实表示的存在直接导致**非平凡理想**的出现，从而破坏代数结构的刚性。

**核心主张**：\(K(E_9)\) 和 \(K(E_{10})\) 的 320 维和 32 维表示被证明是不忠实的。无限维李代数不是 Kac-Moody 型且允许有限维不忠实表示。

**与框架的关系**："不忠实商禁止"公理的核心动机——不忠实表示导致信息丢失——在 Kac-Moody 代数中有严格的对应。

**形式化切入点**：

```agda
-- Kac-Moody 代数的不忠实表示
kacMoody-unfaithful : ¬ Faithful (E10-rep 32)
```

**依赖**：李代数基础
**工作量**：300–400 行
**优先级**：P3

## 第八层：McKay 对应与五重结构

### 8.1 McKay 对应（1980）

**出处**：John McKay, *Graphs, singularities, and finite groups*, Proc. Symp. Pure Math. 37 (1980), 183–186. McKay 发现有限子群 \(G \leq SU_2(\mathbb{C})\) 的不可约表示与仿射 ADE Dynkin 图之间存在自然的 1-1 对应。

**核心主张**：建立了有限子群 \(G \leq SU_2(\mathbb{C})\) 的不可约表示与仿射 ADE Dynkin 图之间的双射。McKay quiver 的顶点对应 \(G\) 的不可约表示，箭头的重数由张量积分解给出。这一对应在有限子群与单边仿射 Dynkin 图之间建立了自然的 1-1 对应。McKay 定理表明 \(a_{ij}\) 精确对应于仿射 ADE 李代数的 Dynkin 图。

**与框架的关系**：McKay 对应为"五重结构"与"正多面体/有限子群"之间的关联提供了严格的代数表示论框架。"五行基数 \((2,5,4,6,8)\)"与正多面体几何不变量的关联，可以通过 McKay 对应的 \(E_8\) 型 Dynkin 图来理解。

**形式化切入点**：

```agda
-- McKay 对应
McKayCorrespondence : FiniteSubgroup SU2 → AffineDynkinDiagram

-- McKay quiver
mckayQuiver : (G : FiniteSubgroup SU2) → Quiver
```

**依赖**：有限群表示论、Dynkin 图
**工作量**：250–350 行
**优先级**：P3

## 第九层：Cubical Agda 与形式化平台

### 9.1 Cubical Agda（2019）

**出处**：Andrea Vezzosi, Anders Mörtberg, Andreas Abel, *Cubical Agda: A Dependently Typed Programming Language with Univalence and Higher Inductive Types*, ICFP 2019, Proc. ACM Program. Lang. 3 (ICFP), 87:1–87:29. Cubical Agda 是 Agda 的扩展，原生支持 **higher inductive types（HITs）** 和 **computational univalence**。

**核心主张**：Cubical Agda 通过 cubical primitives 将 Agda 扩展为全功能证明助手，原生支持 univalence 和 HITs 的一般模式。HITs 机制允许显式构造商空间与同伦型。这使得构造性代数拓扑的形式化成为可能。

**与框架的关系**：Cubical Agda 的 HITs 机制是"不忠实商禁止"公理的技术基础——在 Cubical Agda 中，只有**忠实商**才能通过 HITs 合法构造。"0-postulate"主张在 Cubical Agda 的构造性框架下是可验证的工程目标。

**形式化切入点**：

```agda
-- 高阶归纳类型

  base : S¹
  loop : base ≡ base

-- 商类型
_/_ : (A : Type) → (R : A → A → Type) → Type
```

**依赖**：无阻塞
**工作量**：无需新形式化（已有 Cubical Agda 基础设施）
