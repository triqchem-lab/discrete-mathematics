## 一、问数分类术语（大衍总数术·置诸问数，类名有四）

| 术语 | 原文定义 | 含义 |
|---|---|---|
| **元数** | "谓尾位见单零者" | 末尾为个位数的普通整数（如 3、5、7） |
| **收数** | "谓尾位见分厘者" | 末尾带有分数单位的数（如 365.25 日） |
| **通数** | "谓诸数各有分子分母者" | 分数形式，有分子分母（如历法"一会积年"问题） |
| **复数** | "谓尾位见十或百及千以上者" | 末尾为整十、整百、整千及以上的大数 |

## 二、大衍总数术核心术语（求元→求定→求衍→求奇→求乘→求用）

### 2.1 模数化约阶段

| 术语 | 原文表述 | 含义 |
|---|---|---|
| **定母 / 定数** | "以定相乘为衍母" | 经"连环求等，约奇弗约偶"化约后得到的**两两互素**的模数 |
| **连环求等** | "两两连环求等" | 对诸元数两两配对求最大公约数（等数），逐步化约 |
| **约奇弗约偶** | "约奇弗约偶" | 化约原则：约去含有**奇数个等数**的元数，不约含有**偶数个等数**的元数 |
| **复乘偶** | "复乘偶" | 若约奇数，则将偶数乘回，保持总乘积不变 |
| **总等** | "先求总等" | 所有问数的最大公约数；先求总等存一位约众位，再连环求等 |
| **类数** | "皆约而犹有类数存" | 化约后仍可继续约的数，暂搁置，待其他约遍后再处理 |
| **续等** | "又相减以求续等" | 两数仍不互素时，用相减（辗转相减）求续等（后续公约数） |

### 2.2 衍母、衍数、奇数

| 术语 | 原文表述 | 含义 |
|---|---|---|
| **衍母** | "以定相乘为衍母" | **所有定母相乘**得到的总乘积 M = ∏mᵢ |
| **衍数** | "以各定约衍母，得各衍数" | 衍母除以**各定母**得到的数 Gᵢ = M/mᵢ |
| **奇数** | "诸衍数各满定母去之，不满曰奇" | 衍数被**本定母**除后的**余数** |
| **乘率** | "以奇与定用大衍求一入之，以求乘率" | 通过"求一术"求得的**乘数因子**，使乘率×奇数÷定母余1 |
| **用数** | "以乘率乘衍数，得用数" | **乘率×衍数**；性质：被本定母除余1，被其他定母整除 |

### 2.3 泛用、正用、借数

| 术语 | 原文表述 | 含义 |
|---|---|---|
| **泛用** | "置各乘率对乘衍数得泛用" | 乘率×衍数的**原始值**，尚未调整 |
| **正用** | "併泛课衍母多一者为正用" | 泛用叠加后满足"多一"条件的**正式用数** |
| **借数** | "以元数两位求等，以等约衍母为借数" | 定母为1时从其他处**借用**的调整量 |
| **无用数** | "定母得一而衍数同衍母者，为无用数" | 定母=1时，衍数=衍母，用数失去区分作用 |

### 2.4 总数、不满数

| 术语 | 原文表述 | 含义 |
|---|---|---|
| **总数** | "并之为总数" | 各余数×用数之和 Σrᵢ·Uᵢ |
| **不满数 / 所求数** | "满衍母去之，不满为所求数" | 总数除以衍母后的**余数**，即最小正解 |
| **所求率数** | "併总满衍母去之，不满为所求率数" | 同"不满数" |

## 三、大衍求一术操作术语（置奇右上，定居右下，立天元一于左上）

### 3.1 算筹布局术语

| 术语 | 原文表述 | 含义 |
|---|---|---|
| **奇** | "置奇右上" | **奇数**（余数），置于右上角 |
| **定** | "定居右下" | **定母**，置于右下角 |
| **天元一** | "立天元一于左上" | 在左上角立"一"作为初始值 |
| **子** | "各立天元一为子" | 在左行各立"天元一"作为"子" |

### 3.2 运算操作术语

| 术语 | 原文表述 | 含义 |
|---|---|---|
| **商数** | "所得商数" | 除法运算的**商** |
| **相生** | "与左上一相生入左下" | 将商数与左上之数**相乘**，结果放入左下 |
| **递互除** | "以少除多，递互除之" | 右行上下两数，以**小除大**，轮流相除（辗转相除） |
| **递互累乘** | "所得商数，随即递互累乘" | 所得商数，**依次相互累乘** |
| **归左行** | "归左行上下" | 将递互累乘的结果，**归入左行** |
| **奇一而止** | "须使右上末后奇一而止" | 辗转相除直到**右上角余数为1**时停止 |
| **奇一** | "或奇数已见单一者" | 奇数本身已为1时，乘率直接为1 |

### 3.3 结果术语

| 术语 | 原文表述 | 含义 |
|---|---|---|
| **乘率** | "乃验左上所得，以为乘率" | 停止时**左上角所得之数**即为乘率 |

## 四、《孙子算经》术曰术语（物不知数）

| 术语 | 原文表述 | 含义 |
|---|---|---|
| **术曰** | "术曰" | **算法/方法**的标记，非"定理曰" |
| **置** | "置一百四十" | 算筹操作：**摆放**数值 |
| **并之** | "并之，得二百三十三" | **相加** |
| **减之** | "以二百一十减之" | **相减** |
| **剩 / 賸** | "三三数之，剩二" | **余数** |
| **即得** | "减之，即得" | **得到结果** |

## 六、术语体系总图

```
问数分类
├── 元数（个位整数）
├── 收数（小数）
├── 通数（分数）
└── 复数（大数）

大衍总数术六步
├── 求元（问数分类）
├── 求定（连环求等 → 定母）
├── 求衍（衍母 → 衍数）
├── 求奇（衍数 mod 定母 → 奇数）
├── 求乘（大衍求一术 → 乘率）
└── 求用（乘率 × 衍数 → 用数）

大衍求一术布局
├── 奇（右上）
├── 定（右下）
├── 天元一（左上）
└── 递互除乘 → 乘率（左上所得）

合成
├── 总数（Σ 余数 × 用数）
└── 不满数 / 所求数（总数 mod 衍母）
```
