# 道体·道用·术器——框架的形而上与形而下

> **日期**: 2026-10-04
> **性质**: 本体论最高层——道/器区分的完整体系
> **依据**: 《易经·系辞》"形而上者谓之道，形而下者谓之器" + 框架五层架构 + 用户指正

---

## 一、核心区分

| 层 | 本体论身份 | 判据 | 实例 |
|---|---|---|---|
| **道体** | 判断一切术是否合法的标准 | 不可被投影、是判断标准、不生成只限定 | L0 五公理 |
| **道用** | 道体的使用方法（元层红线） | 判断结构/形式化是否合法 | 本源/投影区分、不忠实商禁止、术/定理区分 |
| **道器之间** | 由道生成、实现道、但本身可被投影 | 有生成元（从道生成） | Trit, FAb(n), GF(9), SunyiBase |
| **器（术）** | 可执行的操作序列 | record→step→termination→projection | 大衍求一术、开方术、天元术、损益术 |

---

## 二、道体——L0 五公理

| 公理 | 内容 | 为何是道 |
|---|---|---|
| **GF(3) 公理** | Trit 三值 + ⊕ 叠加表 + ⊗ 干涉表 | 一切上层的原子，不可再分解 |
| **数字根公理** | dr(L/L₀) ∈ {3,6,9} | 拓扑不动点签名，决定"什么算闭合" |
| **损益公理** | 损一 ×2/3 / 益一 ×4/3 | 律管长度操作的第一性原理 |
| **归零公理** | 1²+i²=0²（虚实对消灭） | 零冥族的根据 |
| **离散存在公理** | GF(3) 格点为最小几何单元 | 空间为何离散，连续统为何是投影 |

---

## 三、道用——三条元层红线

| 红线 | 内容 | 判断什么 |
|---|---|---|
| **本源/投影区分** | DC 是本源，C₁₂/R₁₂/Doz 是投影 | 什么算"同一个东西" |
| **不忠实商禁止** | 不忠实商绝非合法同余关系 | 什么算"合法的商" |
| **术/定理区分** | 术是"怎么做"，定理是"是什么" | 什么算"正确的形式化" |

**道用不在 L0 里，但是 L0 公理的使用方法。** L0 说"GF(3) 是本源"，道用说"所以不要把 Z/12Z 当本源"。

## 四、三条判据（判断"道"的标准）

| 判据 | 内容 | 应用 |
|---|---|---|
| **判据 1：道不可被投影** | 可投影且不丢失本体论信息 → 术；不可投影 → 道 | modInverse 可投影 → 大衍术是术；GF(3) 公理不可投影 → 道 |
| **判据 2：道是判断的标准** | 可用来判断其他东西是否合法 → 道；被执行 → 术 | 不忠实商禁止判断商 → 道；递互除乘被执行 → 术 |
| **判据 3：道不生成只限定** | 从别的道生成 → 结构；不从任何东西生成 → 道 | SunyiChain 从 SunyiBase 生成 → 结构；损益公理不生成 → 道 |

## 六、为什么道器区分重要

| 原因 | 内容 | 后果 |
|---|---|---|
| 防止术被误认为道 | 大衍术是术，只解决同余方程组 | 把它当道→强行应用到不该用的地方 |
| 防止道被降维为术 | 本源/投影区分是道，不能被证明 | 试图证明→"如何定义本源"的无限倒退 |
| 防止道器混淆 | 十二律是 SunyiBase 的生成结果 | 第一性原理是损益公理，不是十二律 |
