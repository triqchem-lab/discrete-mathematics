## 四、为什么截断③仍不是 C₃（`≅` 应为 `↠`）

裁决 2 第 3 步写：

> 在 `T¹` 的 Cayley 图上，`Loop` 的闭走是 `0→1→2→0→…`，三步归零，所以 `π₁ᵈ ≅ C₃`

**但 `T¹` 的 Cayley 图（顶点 `Fin 3`，边 `x ↦ x+1`）在本库中就是 `Pi1dCycleThree.G3`。** 而该模块已证：

```agda
gpow-injective : ∀ {m n : ℕ} → m ≢ n → ¬ (AHomotopy G3 (gpow m) (gpow n))
gpow-0≢3       : ¬ (AHomotopy G3 (gpow 0) (gpow 3))
```

（回执 `753489f1`，0 postulate / 0 hole）

**⇒ 圈数 m ↦ 同伦类 `[g^m]` 是单射 ⇒ `π₁ᵈ(G3)` 有无穷多个元素 ⇒ 不同构于任何有限群。**

**根因**：`T¹` 的 Cayley 图**无弦** `0→2` ⇒ **无有向三角形** ⇒ 按 `no-collapse-iff-triangle-free`，`AHomotopy` 退化为**命题相等**。三步回到的是**顶点**，不是把走缩成空走 —— 走的圈数仍然记得住。

**⇒ 正确的陈述是 `π₁ᵈ(T¹) ↠ C₃`（净位移 = 圈数 mod 3），不是 `≅`。**
而这个 `mod 3` 恰恰**丢掉圈数** —— 那就是**非忠实商 = 信息截断②**（`00:19`：`C₄→C₂` 非忠实商是本体系的元公理级禁令；这里是 `ℕ→C₃` 的同类错误）。

**⇒ 「无截断的 C₃」必须换载体**，与裁决 1 的理由完全同构。

### 7.1 为什么走层不塌缩（结构性理由）

`T6CayleyVec 1` 的 Cayley 图**无有向三角形**（`tf1`）：从 `[a]` 出发唯一的边到 `[a+1]`，
所以 `[a] → [a+1] → [a+2]` 这条两步路**没有弦** `[a] → [a+2]` 可作 `slide` 的第三条边。
而 `AHomotopy` 的**全部**生成元（`slide` / `expand`）都要一组三角形 ⇒ 无三角形时
`AStep` 空 ⇒ `AHomotopy` 退化为命题相等。

**⇒ 要让走层塌缩，必须补 2-胞腔（填充）**，这正是 C3-a 的内容；或用呈现群把关系写进
生成方式（C3-c）；或显式声明 `↠`（C3-b）。**三者仍待裁决，本文档不选边。**
