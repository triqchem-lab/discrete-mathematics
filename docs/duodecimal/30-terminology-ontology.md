## 三、展示群八要素（type-theory presentation group requirements）

来源：11-type-theory-presentation.md + 12-rigorous-type-theory.md

| 要素 | 定义 | 检查方式 |
|---|---|---|
| ① 载体 | record/Σ-类型/data 构造子 | 看代码定义 |
| ② 生成元 | data 构造子或 record 字段 | 看初始化 |
| ③ 关系 | record 字段（非 HIT 构造子） | 看字段 |
| ④ 相位 | 每元素不可约携带的 C₄ 位置 | 看是否有 AlphaPower/等价物 |
| ⑤ 时钟 | 迭代过程 mixedOp^n = id | 看是否有周期闭合 |
| ⑥ 归零 | 周期闭合机制 | 看归零条件 |
| ⑦ 刚性 | Frobenius 诱导的自同构 | 看是否有 Gal 共轭 |
| ⑧ 核对 | refl 确认定义自洽（不产生结构） | 看验证 |

**按需原则**：不是所有模块都需全部八要素——Trit/FAb 作为基座层不需要相位/时钟/刚性。

### "不适用" vs "结构上不存在"

| 标记 | 含义 | 例 |
|---|---|---|
| **—（不适用）** | 该层不需要此要素 | Trit 不需要相位（它是基座层） |
| **∅（结构上不存在）** | 结构本身不具备此要素 | FAb 自由群无 Galois（无刚性） |

## 四、本源/投影判断流程

### 4.1 判断一个模块是本源还是投影

```
问 1：它是否由独立代数域生成？
  是 → 可能是本源
  否 → 可能是投影
问 2：它的身份是否由生成方式决定？
  是 → 本源
  否（由"同构于什么"决定）→ 投影
问 3：它是否保留了生成元来源/关系体系/Frobenius 刚性？
  全保留 → 本源
  有丢失 → 投影（不忠实商）
```

## 五、术与定理的区分

来源：27-crt-original-texts.md + 用户指正

| 维度 | 术 | 定理 |
|---|---|---|
| **本体** | 操作体系（布局+序列+终止+术语） | 结构命题（前提/结论/证明） |
| **信息** | 完整（含操作者身体动作、算筹位置） | 压缩（只保留逻辑关系） |
| **传统** | 中国算学（《九章》《数书》） | 希腊公理化传统 |
| **验证** | 算筹执行 + 口诀记忆 | 程序执行 + 测试 |
| **Agda 形式化** | record + 函数（保留结构） | data + Π（压缩为逻辑） |
| **例** | 大衍求一术（四格布局） | x²≡1 恰 2 根 |

**术→Agda 函数（保留结构）** ≠ **算法→Agda 函数（丢失结构→modInverse 降维）**
