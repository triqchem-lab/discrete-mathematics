## 0. 一句话结论

**两套四极目前都是「范畴混装」**：把**本源侧的生成分量**（幅度 `C₃`／相位 `⟨α⟩`／Frobenius σ）与**投影侧的判据**（CRT 同余／A₄ 轨道／6624 parity）**并列为同一层的「四个极」**。

## 3. 重述：四极应当分层，而不是并列

```
本源层（生成方式 —— 展示群第一原理）
  DC = ⟨δ, φ | δ³ = id, φ⁴ = id, δφ = φδ⟩          （DayanCore.agda；展示群，不是 C₁₂）
  ├─ 分量：幅度 = Trit / C₃       （GF(3) 加法）
  ├─ 分量：相位 = ⟨α⟩ / C₄        （GF(9)⟨α⟩ 乘法）
  └─ 结构：Frobenius σ : x ↦ x³   （域自同构；诱导相位取逆——已证）

投影层（判据函子 —— 必须逐条量保真度）
  toDuodec / crt12 / 轨道商 / parity / …
  ├─ 加法侧投影：**已证无损**（ABCL1.additive-dim-passes）
  ├─ 乘法侧投影：**已证有损**（ABCL1.no-injective-hom ← 壁垒）
  └─ 其余投影（A₄ 轨道、∥·∥₂ 截断、6624 parity）：**保真度未验证**
```

**判据统一（已按审阅收窄——尺子的适用面有限）**：每个「极」都应写成**一个投影 + 一条保真度命题**，但：

> **「存在保单位单射（无损）/ 不存在（有损）」这把尺子只适用于「群（或环）同态型」的投影。**

| 投影 | 是否同态型 | 尺子适用 | 库内证据 |

| **`toDuodec : DuodecPoint → Duodec`** | ✅ **群同态——而且是同构** | ✅ | **`DuodecClock.agda:302 mixed-to-+12 : ∀ p q → toDuodec (mixedOp p q) ≡ toDuodec p +12 toDuodec q`（全部 `refl` 子句＝定理）**＋两个往返 `:285`／`:294` |

⚠ **两处更正（一处来自审阅、一处在核对时被库内定理推翻）**：

1. **`toDuodec` 不是「非同态」——它是群同构**。因此「`toDuodec` 有损」必须**限定为展示层的损失**：
   **作为群无损（同构，可证）**；有损的是**展示（生成方式）**——特征 3 的来源、⟨α⟩ 的独立因子、走钟的逐步演化（`23-*.md` §四）。
   真正失败的是**乘法侧** `mixedOp = *12`（不是 `mixedOp ↔ +12`）。
   ⇒ 也顺带说清「DC ≅ C₁₂」：**在群层面为真**（上表两条往返 + `mixed-to-+12`），**在展示群层面为伪**（红线所禁）。诚实写法：**「作为群同构，作为展示群不可抽象」**。
2. **`T6.agda` 里两种构造并存**（审阅提出的关联，核对成立）：
   `Orbit x = Σ T6Lattice (λ y → ∥ A4OrbitEquiv x y ∥₂)`（`:938`，**set truncation**）
   与 `T6╱A4 = T6Lattice / A4OrbitEquiv`（`:960`，**set quotient**，已 import `Cubical.HITs.SetQuotients`）；
   二者的**粘合点**是 `φ-respects`（`:976-977`，**postulate**，注释自标「定理的核心公理级别断言」），用于 `orbitStabilizer←`（`:1036`）。
   ⇒ **截断/商的选择与这条 postulate 直接相关**——若改用 set quotient，待验证的需求会随之改变。

**逻辑强度必须逐极标明**（审阅 §4）：`additive-dim-passes` = **存在性的无损双射（同构）**；`no-injective-hom` = **否定性的「不存在单射同态」**——**两者强度不同**。每极的保真度命题都要写清属于哪一档：
**「无损双射/同构」＞「单射同态」＞「无单射同态」**。
