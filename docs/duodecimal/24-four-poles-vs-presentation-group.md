## 0. 一句话结论

**两套四极目前都是「范畴混装」**：把**本源侧的生成分量**（幅度 `C₃`／相位 `⟨α⟩`／Frobenius σ）与**投影侧的判据**（CRT 同余／A₄ 轨道／6624 parity）**并列为同一层的「四个极」**。
⇒ 按展示群第一原理与本源/投影界线，四极应当**重述为分层结构**：本源层给生成方式与分量，投影层给**判据函子**，而每个判据函子的**保真度**用同一把尺子量——**「是否存在保单位单射（无损往返）」**，这把尺子已经被 `ABCL1.agda` 造出来了。

## 2. 新四极（幅度/相位/共轭/拓扑）逐极定性

| 极 | 代数身份 | 隶属 | 问题 |
|---|---|---|---|
| 幅度极 | `Trit` / `GF(3)` 加法 `C₃` | **本源侧分量** | 它是 DC 的**分量**，不是「极（判定层/投影）」 |
| 相位极 | `⟨α⟩ ≅ C₄` | **本源侧分量** | 同上 |
| 共轭极 | `σ : x ↦ x³`（Frobenius） | **本源侧结构** | 与旧四极的 GF9 极**同一物**；它对相位分量诱导取逆（已证） |
| 拓扑极 | 提案写成 `CRT: Z/12 ≅ Z/3×Z/4` | **投影侧**（且 CRT 属加法侧） | 与旧四极的「拓扑极 = 6624 parity」**同名不同物**；且踩红线（CRT 是波系统/谱投影，不是模运算定理） |

⇒ 新四极**同样混装**（两项本源分量 + 一项本源结构 + 一项投影），且**丢了旧的几何极**。

## 3. 重述：四极应当分层，而不是并列

```
本源层（生成方式 —— 展示群第一原理）
  DC = ⟨δ, φ | δ³ = id, φ⁴ = id, δφ = φδ⟩          （DayanCore.agda；展示群，不是 C₁₂）
  ├─ 分量：幅度 = Trit / C₃       （GF(3) 加法）
  ├─ 分量：相位 = ⟨α⟩ / C₄        （GF(9)⟨α⟩ 乘法）
  └─ 结构：Frobenius σ : x ↦ x³   （域自同构；诱导相位取逆——已证）

投影层（判据函子 —— 必须逐条量保真度）
  toDuodec / crt12 / 轨道商 / parity / …
  ├─ 加法侧投影：**已证无损**（ABCL1.additive-dim-passes）
  ├─ 乘法侧投影：**已证有损**（ABCL1.no-injective-hom ← 壁垒）
  └─ 其余投影（A₄ 轨道、∥·∥₂ 截断、6624 parity）：**保真度未验证**
```

**判据统一**：每个「极」都应写成**一个投影函子 + 一条保真度命题**，而保真度的标准形式就是壁垒用的那把尺子——
> **存在保单位单射（无损）/ 不存在（有损）**。

`ABCL1.agda` 已经把这把尺子造出来一次（`IsUnitHom` + `Inj` + `no-injective-hom`）：**它是可复用的判据模板**，不是一次性结论。
