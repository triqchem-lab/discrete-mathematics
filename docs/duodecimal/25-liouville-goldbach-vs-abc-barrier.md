## 2. 「维度不一样」的三重区分

1. **(1-Dim)/(2-Dim)**（Mochizuki [EssLog] §3.1, p.67-68，见
   [`23-two-arithmetic-dimensions.md:30-34`](23-two-arithmetic-dimensions.md)）：
   真实状态是 **(2-Dim)「两个维度」**；**(1-Dim) 是错误假设**——
   「crush 成一个维度（假设固定关系）⇒ **立即得到表观矛盾**」。
   ⚠ 措辞按 [`23 号 :62`](23-two-arithmetic-dimensions.md) 纠正：**不是**「加法 1 维、乘法 2 维」，
   而是「**两个维度；把它们当一维就矛盾**」。
   ⇒ 新闻的「1 = −1」**正是这个「立即得到的矛盾」**：G 被逼成严格乘法（造出 `IsUnitHom`）
   那一刻就是「压成一维」，矛盾按 (1-Dim)/(2-Dim) 的预言准时爆发。
2. **承载层不同**：新闻加法侧 = **ℕ 加法组合**（Goldbach 分解 N=a+b），乘法侧 = **λ 符号**（值群 C₂）；
   本库加法侧 = **GF(3) 损益 ⊕ + CRT Z/12**，乘法侧 = **⟨α⟩ = C₄ 相位**
   （需二次扩域 α² = −1 ∉ GF(3)，「乘法二维」的库内依据 `ABC/README.md:116`）。
3. **值群阶数不同**：2 值符号 C₂ vs 4 值相位 C₄ ⇒ **C₂ 是 C₄ 的非忠实商**
   （相位不可约性元公理禁）。⚠ 口径收紧（2026-09-24）：λ 的 C₂ 是**该问题的定义域**，
   但按本框架它站在**非忠实/有损一侧**（C₄→C₂ 的商不构成合法同余）——
   **不是**「该问题有错」，而是**两者不同基座**；**不得**拿 C₂ 的结论反推 C₄ 相位结构
   （那是范数坍缩族的假象，见 [`10-norm-collapse.md:11,15`](10-norm-collapse.md)）。

## 7. 原创性边界（2026-09-24 评估，诚实定位）

**壁垒定理的数学内核是已知的**：「C₄ 到 V₄（或 C₂）不存在保结构单射」是**标准有限群论**
（阶数障碍：C₄ 有 4 阶元，而 V₄ 指数 2、C₂ 阶 2）——**不声称新的群论事实**。

**独创在框架定位，不在数学内容**：
1. **本源层 / 投影层的显式区分**（展示群八要素：载体 + 生成元 + 关系 + 相位 + 时钟 + 归零 + 刚性）；
2. **把已知事实提升为「跨层定理」**：「本源 → 投影的函子不存在保结构单射」——
   描述的是**两层之间的关系**，不是任一层内的现象；
3. **诊断功能**：该定理成为「任何投影操作是否丢信息」的**可复用判据**
   （`ABCL1.no-injective-hom` 目标 V₄；`SignProjection.sign-not-faithful` 目标 C₂）。

⇒ **引用时的正确措辞**：「本库把标准群论的阶数障碍**定位**为本源/投影分层下的跨层判据」；
**不得**写成「发现了新的群论定理」。
