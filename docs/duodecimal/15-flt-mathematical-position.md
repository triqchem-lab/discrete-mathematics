## 摘要

本文档不声称证明了费马大定理（FLT）。FLT 在整数 ℤ 上的无解性依赖 ℤ 的
Archimedes 序结构，其机器证明（Wiles 路线，Lean 4 中约 3 万定理页面）是连续统侧
数学自洽性的工程成果。

我们在此声明的，是一个**范围更窄、但完全严格且经机器验证**的数学事实：

> **定理（偶次费马方程的 3-整除约束）。** 设 a, b, c ∈ ℤ⁺，n ≥ 2 为偶数。
> 若 aⁿ + bⁿ = cⁿ，则 3 | abc。

换言之：**偶次费马方程的任何正整数解，三个数中至少有一个被 3 整除。**
该定理已用 Agda 完全形式化，证明不依赖选择公理、排中律或任何未证实公理。

这个"窄"是刻意的。本文档的第二个目的，是**精确划定**为何完整 FLT
（奇偶 n ≥ 3 全体、无整除性假设）不在 GF(3)/GF(9) 离散代数基座的语言内——
并回应由此产生的审阅质疑。

## 1. 已形式化的定理（完整清单）

以下全部在 Agda 中逐条编译通过（0 postulate / 0 hole），位于
`src/Sovereign/Problem/Fermat/`：

| 编号 | 定理（数学陈述） | Agda 标识符 | 证明方法 |
|------|------------------|-------------|----------|
| T1 | GF(3)× 中每个非零元的平方为 1 | `FermatL1.nonzero-square` | 2-case refl |
| T2 | 非零元 x 满足 x^{2k}=1、x^{2k+1}=x | `FermatL1.pow3-even/odd` | 归纳 |
| T3 | 零幂族：0^n = 0 (n ≥ 1) | `FermatL0.pow3-zero-suc` | refl |
| T4 | GF(9)× ≅ C₈：每个单位 x⁸=1；φ=1+2α 阶恰 8 | `FermatL3.gf9-pow8`, `phi-pow8` | 9-case refl |
| T5 | mod 3：n 奇时 aⁿ+bⁿ=cⁿ 有非零解 (1,1,2),(2,2,1) | `FermatL2.flt-mod3-sol-112/221` | 代数链 |
| T6 | mod 3：n 偶时无非零三元组解 | `FermatL2.flt-even-nonsol` | 代数链+矛盾 |
| T7 | mod 3：n 偶时任何解含 0 分量 | `FermatL2.flt-even-zero-channel` | case 分派 |
| **T8** | **ℤ：n 偶时 aⁿ+bⁿ=cⁿ ⟹ 3\|abc** | **`FermatL4_NatLift.flt-even-nat-zero-channel`** | **模 3 同态提升** |
| T9 | 模 3 同态 red₃ : ℕ→Trit 保持 +、×、幂 | `FermatL4_NatLift.red₃-homo-+/-*/-pow` | 归纳 |
| T10 | R₁₂ 单位群 V₄：u²=1，偶次幂 d1/奇次幂自身 | `FermatL4_Mod12Cycle.pow12-unit-even/odd` | 归纳+穷举 |
| T11 | R₁₂ 湮灭：0ⁿ(n≥1)=0，6ⁿ(n≥2)=0 | `FermatL4_Mod12Cycle.pow12-zero-suc/six-nilpotent` | refl+穷举 |
| **T12** | **R₁₂：a,b,c 皆单位 + n 偶 ⟹ aⁿ+₁₂bⁿ≠cⁿ (mod 12)** | **`FermatL4_Mod12Cycle.flt-mod12-even-nonsol`** | V₄ 偶次幂 + 1+1≠1 |

**T8 是核心交付**。它把 T6/T7 的同余事实通过环同态 red₃ (n ↦ n mod 3)
**提升到整数层**，得到的是一则经典数论命题——不是框架内约定，是 ℤ 上的真命题。

**证明要点（T8）**：设 n = 2k。反设 aⁿ+bⁿ=cⁿ 且 3∤a、3∤b、3∤c。对等式两边取
red₃：因 red₃ 是环同态（T9），red₃(aⁿ) = pow3(red₃ a)(n) = 1（非零元的偶次幂 = 1，
T2），同理 red₃(bⁿ) = 1，故 red₃(LHS) = 1 ⊕ 1 = 2。而 red₃(cⁿ) = 1。
于是 2 = 1，矛盾。∎
关键步（非零元偶次幂 = 1）在 GF(3) 内由穷举保证；同态提升由 T9 保证。

> **一致性抽查（非证明，仅佐证）**：对 a,b,c < 30、偶指数 n=2,4,6 穷举，
> 所有满足 aⁿ+bⁿ=cⁿ 的三元组均满足 3|abc，无一违反 T8。

**关于陈述的精确对应**：T8 的 Agda 陈述（`flt-even-nat-zero-channel`）把
"3|a"编码为 `red₃ a ≡ T₀`（即 a ≡ 0 mod 3），结论写作
`red₃ a ≡ T₀ ⊎ red₃ b ≡ T₀ ⊎ red₃ c ≡ T₀`。这与人类陈述 "3|a ⊎ 3|b ⊎ 3|c"
在定义层等价：red₃ 就是"模 3 取余"嵌入 Trit。凡引用 T8 的数学文本，
可用任一形式；二者同义。

## 2. 什么没有被证明（诚实的边界）

以下陈述**没有被**本文档或任何仓库代码证明，也**不应被**转述为已证明：

1. **完整 FLT**：`∀ a,b,c ∈ ℤ⁺, n ≥ 3, aⁿ+bⁿ ≠ cⁿ`。**未证明。**
2. 偶指数 + 无整除假设的完全无解。**未证明**——T8 只排除"三数皆非 3 倍数"，
   不排除 3|abc 的解（如 3²+4²=5²，3|3，正是 T8 允许的形状）。
3. 任何"十二进制比十进制更能证 FLT"或"进制选择改变可证性"的主张。**未主张**。

特别地：**进制不改变数论性质**。3²+4²=5² 在任何进制下都成立；
我们**从不**声称勾股三元组在某个进制下消失。T8 是进制无关的整数事实。

## 3. 对典型审阅质疑的逐条回应

我们以审阅者身份，把此前对话中出现过的质疑列出并正面回应：

**Q1：「进制不改变数论性质，所以整个框架是误解？」**
A：同意进制不变性——因此我们**不**主张"进制证明 FLT"。我们主张的是 T8，
一个进制无关、经 GF(3) 结构证明的整数定理。进制只是表述，GF(3) 是证明工具，
结论在 ℤ 上。

**Q2：「位数分离定理（DC12 论文）有反例，论证循环」**
A：完全同意。DC12 论文已被废弃。本白皮书**不含**任何位数分离论证，
也不含"用位数推无解"的循环推理。T8 走的是同态提升，与位数无关。

**Q3：「模 3 约束远不足以证明无解」**
A：同意，且这是边界的一部分。T8 只是必要条件。我们说清"证到了哪一步、
为何止步"，而不是假装模约束 = FLT。

**Q4：「0 postulate 不自动等于正确」**
A：同意。所以我们提供：(i) 可复现仓库路径（见 §5），(ii) 定理的人类可读陈述
（§1 表），(iii) 一键验证闸门。0 postulate 只说明**公理集干净**，正确性由
Agda 内核 + 可复核的陈述共同保证。

**Q5：「与 Wiles 证明比行数不公平」**
A：同意。我们**不**做"822 行 vs 60478 模块"的竞赛主张。T8 是 Wiles 证明的
一个初等引理级特例（偶指数 + 3-整除），不是 FLT。行数对比无意义。

## 4. 元理论定位（为什么完整 FLT 在此基座外）

完整 FLT 需要证明**对所有** n ≥ 3 无解。我们证明 T2/T4 显示：在 GF(3)× 与
GF(9)× 上，幂运算把指数 n 的信息压缩为两个周期（奇偶、mod 8）。这两个周期
不足以区分 n=2（有解）与 n≥3（无解）——那个区分需要 ℤ 的序结构
（单调性、夹逼、无穷递降），而序结构在有限域中不存在。

因此我们的立场是：**T8 及 T1-T7 是"幂的律"在离散基座上的全部可证内容**；
在此之上叠加序结构所需的机器（模形式、Galois 表示等）属于连续统侧，
不在本框架内复述。这不是回避困难，而是精确划定"律"与"序"的分工。
