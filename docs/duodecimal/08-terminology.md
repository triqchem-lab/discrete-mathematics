## 七、合法/非法表述对照

### 7.1 本源 vs 投影

| 非法（投影误当本源） | 合法 |
|----------------------|------|
| Z/12Z 是涡旋代数本体 | DC（Z/3⊕⟨α⟩）是十二进制代数核；Z/12 加法是其群投影 |
| 十二进制 = 模 12 环 | 十二进制时钟 = 3 加 × 4 乘；模 12 环是另赋乘法的投影 |
| GF(3) 只是 Z/12 的阴影、非基础 | GF(3) 与 ⟨α⟩ **共同生成** DC；π₃ 是 DC/C₁₂ **落到** GF(3) 的投影 |
| 12 不可作 3×4 理解 | 周期 12 **就是** 3×4 的联合周期；「根」指基数/闭环，不指不可分解 |

### 7.2 群结构

| 非法 | 合法 |
|------|------|
| 四象 V₄ = α 的 4 阶 | V₄ 是 R₁₂ 单位群；α 给的是 **C₄** |
| 代数极 = z12 | 代数极 = DC 核 + 到 C₁₂/R₁₂ 的投影与判定 |

### 7.3 零因子

| 非法 | 合法 |
|------|------|
| DuodecClock 有零因子 | DuodecClock 没有零因子；R₁₂ 有零因子（2×6=0, 3×4=0） |
| 零因子是本源概念 | 零因子是 R₁₂ 环乘法的投影产物，不是 DC 本源的 |

### 7.4 记数法

| 非法 | 合法 |
|------|------|
| 12 进制 = 以 12 为底的位值制 | 十二进制 = Trit ⊕ ⟨α⟩ 的联合时钟；以 12 为底的位值制是 Doz，记数法层 |

### 7.5 进制 ≠ 位域（**不同范畴**，2026-09-13 登记）

| | **进制**（numeral base / radix） | **位域**（digit field） |
|---|---|---|
| 是什么 | 记数法：位值权重 `b^k`、位值域 `0..b−1`、逢 b 进一 | 字内的一段字段：**状态数**（容量）与划分 |
| 变量 | 基 `b`（一个数） | 容量 `C`（一个数）与其分解 |
| 代码 | `Sovereign.Format.Positional` / `Doz` | `Sovereign.Format.DigitField` |
| 桥 | —— | `Sovereign.Format.DigitRealization`（**双射**，不是等号） |

| 非法 | 合法 |
|------|------|
| 12 进制 = 3 × 2 × 2 | 12 **态位域**可由 1 个三态域 + 2 个二态域拼成（`DigitField.capacity-12`）；以 12 为底的**记数法**是 `Doz` |
| 十二进制一位 = 1 个 trit + 2 个 bit | 12 态**位域**与十二进制**数位**之间有一一对应（`DigitRealization.realize` / `separate` 互逆） |
| 三进制「不适合」以 12 为底的记数法 | 位域容量与布局是位域的事：按容量口径 27 个三态域与 43 个二态域都装 11 位十二进制数位；只有**固定 3 trit/位**的交织布局才有冗余 |
| 位域容量 = 进制的基 | 位域容量是状态数；进制的基是记数法的基。二者之间的换算属**桥** |
