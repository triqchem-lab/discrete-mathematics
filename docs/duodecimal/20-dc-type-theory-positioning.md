## 二、DC 的精确数学身份（穷举验证）

### 2.1 群论事实

- (X, mixedOp) **就是**直积群 Z/3 × Z/4 ≅ C₁₂——mixedOp 的运算表即逐分量直积运算。仓库"不是直积群 C₃×C₄"的说法在群论术语上不成立；真正的区别是：DC 携带直积分解**之外**的标记数据（σ = ×7、GF(9) 嵌入、主因子物理语义）。
- g = δ∘φ 是生成元；CRT 编码下 δ ↦ 4、φ ↦ 9、σ ↦ ×7。
- 阶分布 = C₁₂ 标准分布（阶 12 四个、阶 6 两个、阶 4 两个、阶 3 两个、阶 2 一个、单位一个）。

### 2.2 动力系统：最忠实的语义读法

DC 的"走钟一圈" = C₁₂ 上的离散动力系统 = **μ₁₂ ⊂ S¹ 上的 30° 有理旋转**：

- (X, T_g) 恰有 **1 条 12-周期轨道**，无不动点，前 11 步不回（正则表示的自由作用）
- δ（+1 mod 3）= 120° 旋转（4 条等边三角形轨道）；φ（×α）= 90° 旋转（3 条正方形轨道）
- **12 = lcm(3,4) = 振幅钟（周期3）与相位钟（周期4）的最小公周期**
- 遍历论意义下唯一遍历、极小、周期；与无理旋转的区别仅是有限 = 轨道闭合

**联合周期定理（精确形式）**：设 δ, φ 可交换，δ³ = φ⁴ = id。则 (δ∘φ)ⁿ = δⁿ∘φⁿ，对全部点同时归零 ⟺ n ≡ 0 (mod 3) 且 n ≡ 0 (mod 4)，最小正解 n = lcm(3,4) = 12。

### 2.3 拓扑/纤维丛：正确但退化

- 离散拓扑贡献为零（有限群一切映射连续）
- DC → Z/3 是平凡 C₄-主丛：Schur–Zassenhaus + H²(Z/3;Z/4)=0 使扩张全分裂、上同调全消失。"纤维丛"说法数学上真但空洞

  - 生成元 {g} → **12-圈** = 钟面（"走钟"语义）

### 2.4 σ（Frobenius）的真实几何

σ = ×7 ∈ Aut(C₁₂)，固定 C₆ = {偶指标}（6 个不动点），是**算术/Frobenius 型自同构**（cyclotomic Galois 元 z ↦ z⁷），**不是**十二边形的度量反射。区别于 ρ = ×11（逆元/几何镜像，固定 ±1 两顶点）。σ 仅在每根 φ-纤维内是沿 a⁰–a² 直径的镜像。

## 三、守卫类型论层：为什么"▷¹²=id"不可能，但 DC 仍是守卫对象

### 3.1 否命题（文献确证的硬边界）

守卫模态 ▷ 的语义是树 topos `Set^{ω^op}` 上的 shift：(▷X)(n+1) = X(n)，**时间轴是 ω（无界良基）**。若强加 ▷¹²A ≡ A，则 ▷ 成自同构，产生 unguarding `▷A→A`；而守卫不动点 `fix : (▷A→A)→A` 使所有类型可居（取 A=⊥ 得矛盾）。

> CCTT (Kristensen–Møgelberg–Vezzosi, LICS 2022) §3.1："any type A with a map ▷^κA→A can be inhabited using fixed points."

**结论**：`▷¹² = id` 作为模态律 = 不一致。守卫时间必须是 ω，不能模 12。**"有限周期时间"与 Löb/守卫不动点互斥。**

### 3.2 正命题：DC 的周期律属于态空间，不属于时间

DC 的 g¹²=id 是**态空间代数律**（非时间轴性质），在守卫类型论中可三层正确表达：

| 层 | 机制 | DC 对应 |
|----|------|---------|
| (a) 态空间层 | 有限归纳 + 有限 case refl / HIT 商 | g¹²=id 逐 case 证明（无需守卫） |
| (b) 动力学层 | 守卫流 Str ≅ A × ▷Str | 轨道 orbit x（沿 g 迭代）的生产性定义 |
| (c) 行为相等层 | Guarded Cubical：互模拟 ≅ 路径相等 | 周期流每 12 步路径相等回自身 |

**关键定理**：TCTT（Møgelberg–Veltri, POPL 2019）主定理——最终守卫 F-余代数上的互模拟 = 路径相等。这使"12 步归零"成为**关于守卫轨道流的可证路径命题**，而非时间公理。

### 3.3 原创性判断

文献系统性检索确认：**"C₄/有限周期群作为守卫结构"是空白**——但空白原因是有限结构在 MLTT 里就是归纳对象、不需要守卫。可写的原创主张是重构后的形式：

> **有限周期动力学 = 带周期律约束的最终守卫余代数**
> （守卫给不动点与生产性；周期律是额外的代数条件，经互模拟=路径相等提升为行为命题）

## 五、术语修正建议（防审阅被抓住）

1. **DuodecClock.agda 头注"不是直积群 C₃×C₄"**：群论术语上不成立（mixedOp 即直积运算）。建议改为"DC 携带直积分解之外的标记数据（σ、GF(9) 嵌入、主因子物理语义）"。
2. **σ（sigmaDC=×7，Frobenius）与 ρ（×11，逆元/几何镜像）是两个不同对合**：σ 固定 C₆（6 点，算术共轭）；ρ 固定 ±1（2 点，几何镜像）。文档中"反射"应分别限定。
3. **Cayley 图措辞**：DCCayleyGraph 实现的是环面网格/循环图 Ci₁₂(3,4)（生成元 {δ,φ}），非 12-圈（生成元 {g}）。两者都是正确读法，应注明"双语义"。
