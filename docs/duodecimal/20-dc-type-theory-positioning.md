## 三、守卫类型论层：为什么"▷¹²=id"不可能，但 DC 的轨道是守卫对象

### 3.1 否命题（文献确证的硬边界）

守卫模态 ▷ 的语义是树 topos `Set^{ω^op}` 上的 shift：(▷X)(n+1) = X(n)，**时间轴是 ω（无界良基）**。若强加 ▷¹²A ≡ A，则 ▷ 成自同构，产生 unguarding `▷A→A`；而守卫不动点 `fix : (▷A→A)→A` 使所有类型可居（取 A=⊥ 得矛盾）。

> CCTT (Kristensen–Møgelberg–Vezzosi, LICS 2022) §3.1："any type A with a map ▷^κA→A can be inhabited using fixed points."

**结论**：`▷¹² = id` 作为模态律 = 不一致。守卫时间必须是 ω，不能模 12。**"有限周期时间"与 Löb/守卫不动点互斥。**

### 3.2 正命题：DC 的周期律属于态空间，不属于时间

DC 的 g¹²=id（g=δ∘φ 走钟一圈）是**态空间代数律**（非时间轴性质），在守卫类型论中可三层正确表达：

| 层 | 机制 | DC 对应 |
|----|------|---------|
| (a) 态空间层 | 有限归纳 + 有限 case refl / HIT 商 | g¹²=id 逐 case 证明（无需守卫） |
| (b) 动力学层 | 守卫流 Str ≅ A × ▷Str | 轨道 orbit x（沿 g 迭代）的生产性定义 |
| (c) 行为相等层 | Guarded Cubical：互模拟 ≅ 路径相等 | 周期流每 12 步路径相等回自身 |

**关键定理**：TCTT（Møgelberg–Veltri, POPL 2019）主定理——最终守卫 F-余代数上的互模拟 = 路径相等。这使"12 步归零"成为**关于守卫轨道流的可证路径命题**，而非时间公理。

### 3.3 五问五答（δ/周期/交换/归零/σ 与守卫的精确对应）

**Q1 δ 能解释为 ▷ 吗？—— 不能，二者不同层。**
δ : Carrier → Carrier 是态空间自同构（有逆、周期 3）。候选对应全失败：`δ : ▷A→A` 是 unguarding（不一致）；`δ : A→▷A` 是 next（非走一步）；δ = ▷ 类型错（▷ 是类型构造子）。**正确**：δ 是守卫流上的转移函数——`orbit x : Str X, Str ≅ X × ▷Str`，每个 tick 应用一次 δ。字面等同 δ=▷ 立即不一致（CCTT §3.1）。

**Q2 δ³=id 对应什么？—— 态空间律，不是 ▷³=id。**
不能是 `▷³=id` 模态律（= ▷ 有逆 → 不一致）。是 Carrier 上的命题（有限 case refl 或 HIT 商）。守卫贡献在**行为版本**：轨道流上"每 3 步回同相"作为路径命题，由态空间 δ³x=x 提升 + TCTT 互模拟≅路径相等得到。

**Q3 交换性 δφ=φδ 怎么表示？—— 不需要时钟机制。**
多元时钟（Vákár 2017 / CCTT）的 clock variables 管**多条独立时间流**（每条无界 ω），不是"多个状态转移生成元"。DC 的 δ、φ 是同一时间轴上的两个**可交换转移**（态空间分量正交，refl），非两个时钟。建模成两个 clock 是概念错配——DC 只有一条钟。

**Q4 12 步归零是定理还是公理？—— 定理。**
从 δ³=id、φ⁴=id、δφ=φδ 经 lcm(3,4)=12 推出（穷举验证），MLTT 即定理，非公理、非 ▷¹²=id。守卫增量：轨道流获得"每 12 步路径相等"的行为版本（TCTT），定理地位提升但仍是定理。

**Q5 Frobenius 对合 σ 什么角色？—— 内部自同构，与守卫正交。**
σ²=id 是 DC 内部对称（GF(9) galoisConjugate 诱导），不是守卫、不需守卫表达。守卫时间与 σ 正交——σ 作用态空间，▷ 作用时间轴。

### 3.4 原创性判断

文献系统性检索确认：**"C₄/有限周期群作为守卫结构"是空白**——但空白原因是有限结构在 MLTT 里就是归纳对象、不需要守卫。可写的原创主张是重构后的形式：
