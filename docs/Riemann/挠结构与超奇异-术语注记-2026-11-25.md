## 一、挠结构：有限阶点群（与 M7 完全同向）

- 挠点：某整数倍回到无穷远点的点；E[n] = {P : nP = O} 是群，「挠结构」即其构型。
- **普通/超奇异的根本分野由 E[p] 决定**：
  - 普通：E[p] ≅ ℤ/p（非平凡 p 阶点存在）[未形式化·经典对照；F₉ 有理层已形式化见 §三];
  - 超奇异：E[p] = {O}（p-挠塌缩）。
- M7（`E3Tor.agda`, exit=0）已形式化 F₉ 有理层：**超奇异 4 类 e3-triv**（3-挠破灭）+
  **普通 4 类 e3w**（恰 C₃ = {∞, +2 见证}）。

## 二、「超奇异」≠「奇异曲面」（术语辨析 ✓，附本仓库落点）

- 标准代数几何的「奇异」：梯度为零、切平面退化——「奇异曲面/曲线」带此类奇点。
- 「超奇异」是**算术**术语（p-挠行为的历史命名），**不是几何奇点**。
- 本仓库落点：分类域内的 18 条曲线**全部 disc ≢ 0（光滑）**（`CurveF3.disc-*` 27 条 +
  `IsNonSing` 18 见证）；9 条奇异曲线（disc ≡ 0）在 `CurveIsoF3`/`E3Tor` 分类域外
  （cls-of 分派时假设真用 ⊥-elim）。「超奇异」4 类（cls0/5/6/7）是光滑曲线的
  **算术**子类，与几何奇点无关 ✓。

## 三、一处表述修正（oracle `e3` 表 + charEq 数据）

讨论原句：「p=3 时，[3]P = 𝒪 对**所有**点 P 都成立（这正是 E[3] 平凡的直接推论）」。

**枚举否证**（8 类 3-挠表，全部 18 曲线）：

| 类 | 群 | [3]P = O 的点 |
|---|---|---|
| 超奇异 cls0/5/6/7 | 2⁴ / 2⁴ / C₇ / C₇ | **仅 {O}**（破灭——E[3] 平凡的真实含义） |
| 普通 cls1..4 | 12/15 点（含 C₃） | {O, +2 个}（恰 C₃，非全体） |

「所有点 3-挠」在任何一类都不发生；**E[3] 平凡的直接推论是破灭方向**：
[3]P = O ⟹ P = O——已形式化为 `E3Tor.e3-triv*`（4 类, () 拦截）。

成立的「∀ 点」命题是另一条，且已形式化：**t=0 类的 [4]P = O 对所有 P ∈ E(F₉)**
（`GroupCls0/5.charEq`：mul4 p ≡ ptInf, 16 条 ×2；来源 = π² − tπ + 3 = 0 取 t=0
配 σ² = id ⟹ 4P = t·σP = O）。t=±3 类的对应形式：4P = ±3·σP（`GroupCls6/7.charEq`）。
