## 一、对应链（待分层标注的对象）

```
  范数方程 t=0 分支        经典 CM 侧                    离散已证
  t² + 3s² = 4·3ⁿ   ↔   π ∈ ℚ(i)（纯虚 Frobenius）  ↔   NoNormT0Even 无解谱系
```

- t = 0 时 π² = −q（Frobenius 特征多项式 x² − tx + q 取 t=0）；
  对 q = 3ⁿ 即 π = √(−3ⁿ)。`[未形式化·经典对照]`（经典 Waterhouse/Silverman A.2，
  库内无对应定理；库内已有的是**值层**刻画 `water-iff` / `sup-trace`）
- t = 0 且 n 偶 ⇒ 无整数 s：本源，见 §二。

## 二、本源层（内核已证，编译裁决）

| 内核定理 | 位置 | 内容 |
|---|---|---|
| `no-sq-4pow3-odd` | `RH/NoNormT0Even.agda:341` | `∀ m s → s·s ≢ 4·3^(2m+1)`（ℕ 层） |
| `no-norm-t0-even` | `RH/NoNormT0Even.agda:411` | `∀ m → ¬ Σ ℤ s, 3s² ≡ 4·3^(2m+2)`（ℤ 层，Lean 侧 `no_norm_t0_even` 对应） |

| `witness-sat` | `RH/Witness.agda:140` | ∀n 正部见证（t=0 分支：奇 n 的 s = 2·3^k 可解——**可解侧**同库内已证） |

即：**「t=0 分支 n 偶无解 / n 奇可解（s=±2·3^k）」是内核定理字面内容**；
相邻奇指数情形（如 3s² = 12, s=±2）在同一套定义下 `refl` 可居留，
故「偶无解」是数论事实而非定义缺陷（NoNormT0Even 头注已声明，构造性路径文档 §2 亦录）。

## 四、「投影失配」正名（承接 WeilRigidity 2026-11-24 勘误）

`RH/WeilRigidity.agda` 头注勘误已记录（构造性路径文档 §6.75）：
- 特征 3 下 x²+x+1 = (x−1)²，故 ℤ[ω]⊗𝔽₃ ≅ 𝔽₃[ε]/ε² **不是域**；
- 约化后得到 GF(9) 的是 ℤ[i]（x²+1 模 3 无根）。

因此本注记对应链里「π ∈ ℚ(i)」的**合法离散投影载体是 GF(9)**
（`FrobeniusBlind`/`WeilRigidity` 的实例数值层），
而 ℚ(ω) 一侧在特征 3 命中判据②（非忠实商）——
「ProjectionMismatch」一名即指此：**t=0 的连续侧 ℚ(ω)-叙事与离散侧 GF(9)-载体不共用同一判别式形**。
范数形 t²+3s² 本身属 ℚ(√−3) ⊂ ℚ(ω)（`[直觉·未验证]`——形与域的归属没有库内定理，
但 t=0/偶指数无解这一**空档**在两则叙事里都成立：本源即 §二的空档定理）。
