| 筛网 | 问句 | 通过的范式（本库实例） | 失败形态 |

## 三、五路线逐一诊断（缺口步骤 → 需要的见证 → 为何无 → 本库正面见证）

### 路线 1：F₁ 绝对点几何（Borger/Soulé/Connes/Consani/Manin）

- **缺口步骤**：F₁ 曲面上导出高维 Lefschetz 迹公式 + 显式希尔伯特空间（登记：未闭合）。
- **需要的见证**：迹公式的逐点对应证书——每个零点-不动点的配对表。
- **为何无**：F₁ **删掉了加法**。E2 说重合需要双结构两侧同格可枚举；F₁ 只留乘法侧，本体只剩半面，投影无锚。登记瓶颈（动机狭窄：有限型只盖 Artin-Tate；盖 ζ 需无穷维 → 交点积失效）的见证翻译 = **E5 正性来源缺席**：无加法格就没有交配对，无交配对则 Schwarz 一步无从谈起。
- **本库正面见证**：`GroupCls0..7` 的 addE 16×16 加法格与 `F9MultC8` C₈ 相位**同格可枚举**——「重合」是两侧的结构事实；F₁ 恰好手术掉了其中一侧。

### 路线 2：算术动力系统（Deninger）

- **缺口步骤**：正则化行列式 det∞(sI−D) 的算子域与自伴性（登记：算子未定义）。
- **需要的见证**：D 的逐点定义域证书 + 离散谱证书（谱逐点列名）。
- **为何无**：D 是**连续平移流**的生成元 → 谱连续 → **W1 直接死**（连续谱没有逐点位置，证书无处落笔）。登记瓶颈（连续谱污染、非临界噪声）的见证翻译 = E2 偏离的谱面形态：相位注入是连续的，零点的离散相干性被淹没。
- **本库正面见证**：σ 是离散映射，`sig` 表 16 行逐字；`trace-witness`（迹集 7 值逐值见证）——「离散相干」不是口号，是逐点证书的存在。

### 路线 3：非交换几何（Connes/Marcolli）

- **缺口步骤**：迹公式在希尔伯特空间上的成立性（登记：以吸收光谱形式出现零点）。
- **需要的见证**：迹公式正性的**非循环**证书（W4）。
- **为何无**：登记瓶颈原文——试验函数正性条件**逻辑上等价于 RH** → **W4 循环见证**：拿结论当见证。深一层是 W3：正性来源缺席（R₊* 模群作用是连续物理流，非代数自同构——E2 的又一实例：相位外部注入）。共振态污染 = 非临界零点混入 = **E1 模锁定失败的谱面表述**（模未被锁，谱里混入线上/线外杂音）。
- **本库正面见证**：函数域侧 Weil 判据是**定理**（E5：正性来自交配对 σᵗσ = q，`FrobFix` 承载 Fix/pairs 分轨）——同一「迹公式 ⟹ 模锁定」的推理在对应层有真实正性供给；Connes 侧缺的正是这个供给方。

### 路线 4：完美oid / p-进几何（Scholze/Fargues/Fontaine/Lurie）

- **缺口步骤**：全局 ζ(s) 谱算子（登记：未建立全局算子）。
- **需要的见证**：全局黏合证书——局部对象拼接出全局谱的逐点表。
- **为何无**：登记瓶颈——**阿基米德壁垒**：倾斜（tilting）只在 p-进局部有效，无穷远素数处全局钻石解体。见证翻译：W1 在局部成立（p-进有真 Frobenius φ，五路线中离本体最近），但**全局可枚举性在实地方断裂**——实地方恰是枚举死亡的地方。次世代打分（公理 1 得 7.5 最高、公理 3 得 6.0）与此一致：闭包好、编码断。
- **本库正面见证**：F₃ 无地方分解（单一特征、无 ℝ 因子）——`CountF9All` 的 16 点全表即「全局 = 局部」的可枚举样本；完美oid 路线缺的不是 Frobenius（它有真 φ），是把局部谱拼成 ζ 谱的**总表**。

### 路线 5：量子拓扑与 Galois 刚性（Berry-Keating/Mochizuki）

- **缺口步骤**：xp 算子离散化；IUTT 的零点算子（登记：两者皆无）。
- **需要的见证**：xp：截断后的相空间对称性证书（截断前后谱的对应表）；IUTT：Θ-link 之后恒等式的存续证书。
- **为何无**：xp 须引入**非自然边界截断** → 截断破坏相空间对称 → 见证失真（W4 变体：见证对象被证明动作本身改造）。IUTT 的 Θ-link **拆开 ⊕/⊗ 双结构**——这是 E2 的反面操作：它拆除的恰是我们承证「重合」的那对结构；拆开后加法侧与乘法侧的对应恒等式失去落点（Scholze 的 codimension-1 frobenioid 质疑即此：拆结构后见证恒等式消失）。且 IUTT 目标偏移（abc 不等式 ≠ ζ 零点编码）→ W1 层面无见证对象。
- **本库正面见证**：加乘双结构的可检性本身——`NormD1`（x²+y²，加法侧范数）与 `EndDistortion`（ρ²=−1，乘法侧 CM）在同一曲线点群上同时成立且互不破坏；Θ-link 型操作在我们的寄存器里没有合法执行位置。

## 四、总病根（一句话）与 Alpöge 对照

**五路线都在特征 0 的货架上寻找「本体级」对象（刚性自同构、交配对、全局自伴算子），而特征 0 只有「对应级/投影级」对象；W-筛网把这一点变成可检的——五路线各断在不同网：**

| 路线 | 断网 | 断点一句话 |
|---|---|---|
| F₁ | W2（半边本体） | 删掉加法 → 重合只剩半面 |
| Deninger | W1 | 连续流生成元 → 谱无处落笔 |
| Connes | W4 + W3 | 正性 ⟺ RH（循环）+ 正性来源缺席 |
| 完美oid | W1（全局） | 局部有真 φ，实地方枚举死亡 |
| IUTT/xp | W1 + W4 | 无见证对象 / 拆双结构后见证失真 |

**Alpöge 对照**（投影层成立的样本）：不找本体，在对应层**制造**重数（θ-lift m ≈ √X）——W1/W4 层面通过（对应对象可枚举、非循环，形式证明经多重独立内核验证），但 W3 的正性来源在特征 0 仍是**外部注入**（ℓ-adic 钉扎 + 文献块），即投影成立、本体未还乡——《Constructive-Path》零节的登记不变：这是关于刚性来源的结构性论断，不是「另一个证明」。
