## 二、核心数学定理链

### 2.1 离散雅可比定理

设 S 为有限集，|S| = N，F: S → S 为任意映射。
M_F 为 F 的函数表矩阵（N×N，列向量为 F 的像指示向量）。
则：**det(M_F) ≠ 0 ⟺ F 是双射**

证明链：
```
det(M_F) ≠ 0
    ⟺ 列互异 ∧ 无全零行        （函数表矩阵结构）
    ⟺ F 是单射 ∧ F 是满射      （行列性质）
    ⟺ F 是双射                 （鸽巢原理）
```
