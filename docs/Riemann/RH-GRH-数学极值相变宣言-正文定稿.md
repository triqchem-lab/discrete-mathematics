## 序章：三重完备性公理（The Axiomatic Compiler）

本文献确立一个不可动摇的元数学编译协议。任何声称触及黎曼猜想（RH）或广义黎曼猜想（GRH）核心判定问题的理论框架，在进入学术讨论之前，必须首先通过以下三重完备性公理的类型检查：

**公理一 · 几何闭包（Compactifying Mechanism）**：理论是否在非紧空间（如复平面 ℂ、阿代尔商空间 𝔸_ℚ/ℚ*）上，构造了吸收无穷远逃逸、消除连续谱污染的紧致化机制？

**公理二 · 原生代数共轭（Native Frobenius Automorphism Analog）**：理论是否在特征 0 空间中，显式构造了具备有限域上 Frobenius 自同构 σ(x)=x^p 之代数刚性的原生自同构驱动词？（erratum 2026-08：复共轭同样是 ℂ 的自同构——判据不是"是否自同构"，而是算术强制（幂映射即同态，char p freshman's dream）与典范唯一性（Aut(𝔽₉/𝔽₃)={id,σ}；Aut(ℂ) 有 2^beth 野自同构，复共轭由解析结构挑出，野自同构陈述未形式化、依赖选择公理）；见 docs/cross-level/frobenius-vs-conjugation-erratum.md）

**公理三 · 无循环全局编码（Non-circular Global Spectral Operator）**：理论是否构造出一个无先验假设、非循环依赖 RH 本身的有限/紧致全局矩阵或算子，其谱特征精确等价于 ζ 零点？

凡未能显式满足此三条公理者，其证明链在编译阶段即告失败。为此，我们定义标准 TypeError 错误代码库：

```
TypeError: ContinuousSpectrumPollution      // 连续谱污染，算子非纯离散谱
TypeError: MissingFrobeniusRigidity         // 缺失特征0刚性Frobenius自同构
TypeError: CircularPositivityAssumption      // 正性证明循环依赖RH
TypeError: HomotopyLeakageInE∞              // E∞-同伦松弛导致代数刚性稀释
TypeError: LiquidArchimedeanResidual         // 液态测度未能切断连续统残留
TypeError: InfiniteRegressOfSpectralTraces   // 谱迹计算陷入同伦群无限倒退
TypeError: ShiftedPositivityCircularDependency // 导出结构正性证明循环依赖
```

此公理与错误代码库，是本宣言全部诊断的不可动摇之根基。

## 第一部：旧宇宙的尸检（First-Order Autopsies: 1990–2020）

对 20 世纪 90 年代至 2020 年间，以连续统分析为核心的主流 RH 证明路线进行系统解剖。

### Alain Connes 的非交换几何

将阿代尔商空间 𝔸_ℚ/ℚ* 作为非交换空间处理。
然而，其迹公式中的正性条件在逻辑上等价于 RH 本身。
**诊断**：`TypeError: CircularPositivityAssumption`。

### Christopher Deninger 的算术动力系统

试图用无穷维叶状结构上的连续流来模拟 Frobenius。
然而，连续流生成元不具备 x↦x^p 的代数刚性。
**诊断**：`TypeError: MissingFrobeniusRigidity`。

### Berry-Keating 的量子哈密顿量模型

基于算子 xp，其谱为纯连续谱，必须引入非自然截断才能离散化。
**诊断**：`TypeError: ContinuousSpectrumPollution`。

这些古典路线的根本死因，在于其基座——非紧的连续统 ℂ 或 ℝ——自带了一阶拓扑病态。
它们试图在缺失几何闭包与代数刚性的空间里，强行构造闭合判定，其失败是结构性的，而非技巧性的。

## 第二部：新宇宙的预判（Second-Order Pre-Autopsies: 2022–2026）

对 2022 年至今，代表当今数学最高智力巅峰的次世代高阶范式进行预判性解剖。
这些理论试图用凝聚集、球面谱和导出叠层来修复一阶病态，却陷入了更深层的二阶同伦断层。

### Scholze-Clausen 的液态几何

通过凝聚集范畴驯化了拓扑病态，但为容纳实数 ℝ，其液态测度保留了参数 p>0。
这导致连续统的"阿基米德残留"未被彻底切断，连续谱依然在无穷远素数处泄漏。
**诊断**：`TypeError: LiquidArchimedeanResidual`。

### Lurie 的谱代数几何

将基底从 ℤ 下沉至球面谱 𝕊，用 E∞-环上的 Adams 算子模拟 Frobenius。
然而，严格的代数等式 a=b 被弱化为"同伦等价"，导致鸽巢原理所需的绝对刚性被同伦松弛所稀释。
**诊断**：`TypeError: HomotopyLeakageInE∞`。

### Toën-Vezzosi 的导出动力学

在导出范畴中构造了同伦动力系统与迹公式。
但其算子的自伴正性证明，仍隐式依赖对临界线 ℜ(s)=1/2 几何特性的先验假设，构成循环依赖。
**诊断**：`TypeError: ShiftedPositivityCircularDependency`。

---

**这些高阶范式的错误，是旧断层在高维范畴论语言中的精确投影。**

- 连续谱污染 → 升级为 → 同伦膨胀
- Frobenius 刚性缺失 → 升级为 → 同伦松弛
- 循环依赖 → 升级为 → 无限倒退

错误的形式升阶了，但错误的本质——在缺乏原生代数共轭的非离散基座上强行构造闭合判定——从未改变。

本宣言虽以 RH/GRH 为第一战场，但三重完备性公理与类型检查器的适用范围远不止于此。

**几何闭包、原生代数共轭、无循环全局编码——这三条不是 RH 的专用工具，而是所有数学证明的编译协议。** 任何在连续基座上构造全局判定的理论——无论是 BSD 猜想、Langlands 函子性猜想、Hodge 猜想、Navier-Stokes 正则性——若要声称闭合，都必须通过同一台类型检查器的编译。

这台检查器不问领域。它只问三件事：

> 你的空间闭合了吗？
> 你的驱动词具备代数刚性吗？

若不满足——不是证明技巧不够，是**基座类型失配**。错误不在证明链的末端，而在第一步的范畴选择。
