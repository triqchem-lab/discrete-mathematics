## 五、与经典数学理论的严格对应

### 5.1 分水岭定理 vs Barcelo A-同伦理论

**Barcelo 理论**：建立 A-同伦群，但**未完整刻画** π₁ᵈ 何时成群。

**分水岭定理**：完整刻画——**对称图 + backtrack ⟹ 群；否则幂等幺半群**。

**严格性**：分水岭定理是 Barcelo 理论的**组合定理形**——逆元存在性判据 = 图的对称性。

### 5.2 Eckmann GF(3) 版 vs 经典 Hodge 理论

**经典 Hodge**：正定内积 ⟹ 直和分解 `C^k = im(∂) ⊕ im(δ) ⊕ ker(L)`。

**GF(3) 版**：内积不正定 ⟹ 只有子空间和 `C^k = im(∂) + im(δ) + ker(L)`，且 `im(∂₁) ∩ ker(δ₀) ≠ {0}`。

**严格性**：这不是"框架的主张"，是**已证定理**——GF(3) 上正定性的丧失导致正合列不分裂。

### 5.3 函数表示 vs List 表示

**数学本质**：`ℤ[t,t⁻¹] = { f : ℤ → ℤ | f 有限支撑 }` 是**数学定义**（本源）。

**两种呈现**：
- **函数表示**：`canon-sums-unique = funExt h`（一行）——本源表达；
- **List 表示**：需要规范形（sort + merge）——投影编码。

**严格性**：这不是"选择哪个路线"的工程问题——这是**数学定义的选择**。函数表示是 Laurent 多项式的**标准定义**。
