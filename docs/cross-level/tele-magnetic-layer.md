## 三层语义分层

语料中"电信塔"与"磁性"的感官分级对应 GF(9) 的三类代数操作。此分层防止 "α 是磁引擎" 等语义混注。

| 语料层 | GF(9) 结构 | 代数性质 | 说明 |
|---|---|---|---|
| **电信塔** | 乘法子群链 ⟨-1⟩⊂⟨α⟩⊂⟨φ⟩ | 阶 2,4,8; 乘法旋转 | α=90°, φ=45°, -1=180°; 乘法群内部 |
| **磁性通道** | Frobenius 共轭 σ(x)=x³ | 域自同构, 对合 σ²=id | 不在乘法子群链内; 是域的内禀自同构 |
| **归零/跨维度** | 特征 3 加法归零 1+1+1=0 | 加法群消没 | 零元唯一性; "只有0跨维度" |

## 对应关系详细说明

### 电信塔 = 乘法旋转

- **α** (阶 4, 90°): 克里斯托螺旋基本旋转。`DuodecClock` 的第二个因子。
- **φ** (阶 8, 45°): α 的平方根层 (φ²=α)。`ConsciousnessLayer` 的意识旋转。
- **-1 = α²** (阶 2, 180°): 反转。σ 对合的乘法对应。
- **子群链**: ⟨-1⟩⊂⟨α⟩⊂⟨φ⟩, 阶 2,4,8。`DivisibilityChain` 证明 2∣4∣8。

### 磁性通道 = Frobenius 自同构

- **σ(x) = x³**: 特征 3 的 Frobenius 自同构。在 GF(9) 上是共轭映射 σ(a+bα) = a-bα。
- **σ² = id**: 对合。`galoisConjugate²` 已证。
- **σ 不在乘法子群链中**: σ 是域层面的操作 (域自同构)，不是 GF(9)* 的元素。
- **语料对应**: "磁性" 通道 = 域自同构通道。"2T=0" 可指 σ²=id (对合归零)。

### 归零层 = 特征 3 加法

- **1+1+1=0**: GF(3) 特征 3。`tri-period-zero` 已证。
- **零元吸收**: 0·x=0。`gf9-zero-mulˡ/ʳ` 已证。
- **零幂吸收**: 0^(n+1)=0。`zero-power-gf9` 已证。
- **语料对应**: "只有0跨维度"、"0是一切的密码"。归零是加法层通道。
