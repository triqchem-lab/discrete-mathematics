# 幻方术语辨析（数学数字幻方 vs 卢先生矢量方向幻方）

> 状态：术语固化文档（2026）。目的：防止后续模块把「数学数字幻方」与卢先生「矢量方向/变量计数幻方」混用。
> 关联：`MagicSquareM4.agda`、`ArthurMagicSquare.agda`、`MagicSquareHFM.agda`、`OrthogonalLatinSquare.agda`、`GF9MagicSquare.agda`、`MagicSquare144.agda` 头部均标注了边界。

---

## 一、核心区分：本框架里「幻方」有两个（严格说三个）不同含义

### 1. 数学数字幻方（classical magic square）
n×n 方阵，**每行、每列、两条对角线之和相等**（幻常数 = n(n²+1)/2）。
- 3×3 洛书：幻和 15
- 4×4 瑟尔 M₄：幻和 34
- 9 阶 GF(9) Euler 叠加：幻和 369

这是**矩阵与求和约束**的数学对象。本框架已形式化的模块（见下表）全部属此类。

### 2. 卢先生「矢量方向/变量计数」幻方
**阶数 n = 同时在变的矢量方向（变量）个数**，与「行列求和」无关。

知识库原文依据：
- 四阶幻方 = 长、宽、高 + 时间 = 4 个矢量方向：
  > 「四阶患方就是三+1。这是长宽高。加上一个时间矢量的方向。它事实上是时间单位调整器，而且它只往一个方向跑」「给一个四阶幻方，然后给他的一个场给个矢量，要获得电，要获得磁」
- N 阶 = N 个矢量方向：
  > 「12d，就是你在同一个空间里边有 12 个矢量方向可以调整的。3d 你只有前后是一个方向，左右是一个方向，上下……」
  > 「进到每一个点，里边有七个、八个、九个变量的矢量方向是什么？」
- 144 阶 = 12 维对称关系 = 144 个方向，排列数 144! ≈ 1.51×10⁹⁶：
  > 「人体结构内部是 12 个维度的。12 个维度的对称的关系，在数学上是 144 阶换方。自己用 144 乘 143 一直乘到一……是 1.51×10 的 96 次方」
  > 「每一个点上，他有 12 个方向……12 个力。如果两个点的关系呢，它最少会有 144 个力学关系」
  > 「等你跨越到宇宙 144 个变量的时候，游戏才会结束」
- 方向/矢量是核心（现代科学丢掉的东西）：
  > 「词的方向和矢量定位……方向加矢量。这是我们现在最大的一个问题，科学把这个东西丢了。科学只有正负加减。方向和矢量是角度」

这是**维度与排列**的对象，与数字幻方的「矩阵求和」完全不同。**尚未形式化**（概念层）。

### 3. 144 胞腔静态容器（本框架特有用法）
`MagicSquare144.agda` 中的「144 阶幻方」= **144 胞腔静态容器** = 120（正十二面体胞腔）+ 24（梅尔卡巴胞腔）。
它既不是数字幻方（行列求和），也不是矢量方向计数，而是**胞腔计数**。文档原注释即注明「此静态组成 ≠ 缠绕数分解」。

## 三、算力极限的正确定位（修正「16 阶 + 浮点漂移」）

- **卡死计算机的不是浮点精度，而是组合爆炸**：矢量方向数增至 144 时，排列组合量 144! ≈ 1.51×10⁹⁶ 使资源耗尽。
- 知识库原文：
  > 「按现在最好的量子计算机……把资源耗完了，他只能算到 64 卦就结了」
  > 「十的 96 次方以上」=「全知全觉的信息网段」
- 本框架对策：**不穷举 144!，用 CRT 分解把 144 阶降维到局部分量**，从而避免组合爆炸——这正是「离散优先」路线的威力。

### 3.1 浮点精度的精确边界（IEEE 754 double）

64 位双精度浮点：53 位有效数字，整数**精确无漂移**范围 = 绝对值 ≤ 2⁵³ ≈ 9.007×10¹⁵（约 15 位十进制）。

| 场景 | 是否无漂移 | 原因 |
|:---|:---|:---|
| 数字幻方（任意可行 n 阶） | ✅ 完全精确 | 幻和 S = n(n²+1)/2 ≤ 2⁵³ ⟹ n ≤ 2.6×10⁵；16 阶幻和仅 2056 |
| 矢量方向排列数 n! | 仅 n ≤ 18 精确 | 18! = 6.40×10¹⁵ < 2⁵³ < 19! = 1.22×10¹⁷ |
| 144! ≈ 1.51×10⁹⁶ | ❌ 远超 2⁵³ | 必须任意精度整数（Python `int` / Rust `num-bigint`） |

**关键数值**：2⁵³ = 9,007,199,254,740,992；18! = 6,402,373,705,728,000（< 2⁵³）；19! = 121,645,100,408,832,000（> 2⁵³）。

## 四、信息边界（诚实声明）

1. 知识库中**没有**「16 阶幻方」「浮点精度漂移」的原文。
2. 之前「二进制只能算到 16 阶、三进制才能算到 144 阶」的表述**不在知识库**，且**「16 阶」在两个解释下都不成立**：
   - 数字幻方：任何可行阶数都无浮点漂移（幻和 ≤ 2⁵³ 可到 26 万阶）；
   - 矢量方向阶乘：double 精确边界是 **18 阶**（18! < 2⁵³ < 19!），不是 16 阶。
   若原始语境是「矢量方向数变多后组合爆炸」，则与「144! ≈ 1.51×10⁹⁶、量子计算机算到 64 卦耗尽资源」在逻辑上对应。
3. 幻方阶数**与数值进制无关**：本框架的 Rust `ternary_magic.rs` 用普通 i64（64 位整数，精确范围 2⁶³≈9.2×10¹⁸）已直接算出 144 阶数字幻方（20736 胞，幻常数 1493064）。三进制的真正价值在 GF(9)/GF(3) 域结构（MOLS、Frobenius C₂），不在「能否算到 144」。
