## 二、Python 枚举逻辑（等价于 GAP）

1. 构造 24 个单位四元数（精确分数，无浮点）：
   - ±1, ±i, ±j, ±k（8 个）
   - (±1 ±i ±j ±k)/2（16 个，半整数）
2. 四元数乘法 `mul` + 共轭 `conj` 精确运算。
3. 共轭类：对每个未归类元素 x，计算 {g·x·g⁻¹ | g ∈ 群}，set 分组。
4. 特征标表：标准 SL(2,3) 表（7 表示 × 7 类），值在 Z[ω]（ω=e^{2πi/3}）。
5. 验证：列正交（Σᵢ χᵢ(c)·χᵢ(d)* = 24/|c| 当 c=d）、行正交（Σ_c |c|·χᵢ(c)·χⱼ(c)* = 24 当 i=j）、维度平方和 = 24。

**结果**：7 类（大小 1,1,4,4,4,4,6），列正交 ✅ 行正交 ✅ 维度和 24 ✅。

## 五、关键简化事实

**特征标值全部落在 Z[ω] 内，无需 √2 扩域。**

此前预期「二维表示的迹需 √2」（因半整数四元数），但实际：
- 二维表示在 3 阶元取 −1（特征值 ω+ω² = −1）
- 在 4 阶元取 0（特征值 i+(−i) = 0）

均为整数，无 √2 项。因此 `BinaryTetrahedralRepresentation.agda` 直接复用
`A4Representation` 的 Zω 环，无需 Z[ω,s]。这是比预期更简的数学事实。

## 六、中心特征分解（手征 Z₂ 的代数载体）

类 1（−1 中心）上：

- 中心特征 +1：χ₁, χ₁′, χ₁″, χ₃ → 值 **1, 1, 1, 3**（= 维数，A₄ 的提升）
- 中心特征 −1：χ₂, χ₂′, χ₂″ → 值 **−2, −2, −2**（新的二维表示）

这正是 2·A₄ 作为「A₄ 的中心扩张（×Z₂）」的代数体现。

## 七、与 A₄ 表示论的对照

| | A₄（12 阶） | 2·A₄（24 阶） |
|---|---|---|
| 共轭类 | 4（1,4,4,3） | 7（1,1,4,4,4,4,6） |
| 不可约表示 | {1,1′,1″,3} | {1,1′,1″,2,2′,2″,3} |
| 3 阶（三代费米子） | ✅ | ✅ 保留 |
| 4 阶（Frobenius） | ❌ 无 | ✅ 四元数单位 |
| 手征 Z₂ | ❌ 无 | ✅ 中心 ±1 |

A₄ 的 4 个不可约表示（χ₁,χ₁′,χ₁″,χ₃）是 2·A₄ 中**中心特征 +1** 的那 4 个
（提升保持）；2·A₄ 新增 3 个二维表示（χ₂,χ₂′,χ₂″）是中心特征 −1 的。
