## 附录 B：H₂O@C₆₀ 量子受限模型的物理数学基础 (v2.6, 2026-07-16)

### B.1 物理层：刚体分子在纳米笼中的量子运动

H₂O@C₆₀ 研究的不是电子结构（sp3 杂化等），而是**整个水分子作为刚体**在 C₆₀ 笼内的量子运动。这是核运动（转动+平动），能量尺度在 meV 量级（~0.5 meV），比化学键能（~5 eV）小一万倍。

**6D 平动-转动 (TR) 哈密顿量**：

```
H = T_trans(r) + H_rot(Ω) + V_conf(r, Ω)

T_trans:  3D 各向同性谐振子（平动动能 + 笼内约束势）
          能级: E_n = (n + 3/2)ħω, 简并度 (n+1)(n+2)/2
          n = 0, 1, 2, ...

H_rot:    不对称陀螺转动
          能级: j_{ka,kc}, 其中 j 是总角动量, ka,kc 是投影量子数

V_conf:   笼内约束势，耦合平动和转动
          → 总角动量 λ = l(轨道) + j(转动)
```

**核自旋异构**：

水分子有两个全同 ¹H 核（均为费米子，自旋 I=1/2）。Pauli 原理要求总波函数反对称：

| 异构体 | 核自旋 I | 转动态 | 简并度 | GF(3)对应 |
|:---|:---|:---|:---|:---|
| **ortho-H₂O** | I=1 (对称, 三重态) | K_a+K_c 奇 | 3 | T₀, T₁, T₂ |
| **para-H₂O** | I=0 (反对称, 单态) | K_a+K_c 偶 | 1 | 基态/归零态 |

**ortho 的三重态 = GF(3) 三态 {T₀, T₁, T₂} = C3 群的两个实现。**

### B.2 对称性破缺：I_h → A₄

- 孤立 C₆₀：I_h 对称（120 阶）
- 固态 C₆₀ 晶体：邻位分子四极静电场 → 破缺 → 有效对称性 A₄（12 阶）
- 后果：ortho-H₂O 基态三重简并分裂为 1+2，分裂能 0.52 meV
- 0.52 meV = Δ/2 热阈值投影，Δ=√3 能隙
