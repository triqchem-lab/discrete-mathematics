## 二、命中公式（全枚举 240 候选）

枚举空间：x ∈ {i, σ(i)}，y ∈ {j, σ(j)}，(a,b) ≠ (0,0)，c ∈ GF(4) → 2×2×15×4 = 240。

| 变量组合 | 拉丁候选数 |
|:--------:|:---------:|
| (i, j) | 36 |
| (i, σ(j)) | 36 |
| (σ(i), j) | 36 |
| (σ(i), σ(j)) | 36 |

**精确命中（各唯一，且均为纯仿射）**：

```
L1 = 2·i ⊕ 3·j ⊕ 2     (x=i, y=j, a=2, b=3, c=2)
L2 = 3·i ⊕ 2·j ⊕ 2     (x=i, y=j, a=3, b=2, c=2)
```

正交性根源：系数矩阵 `[[2,3],[3,2]]` 行列式 = 2·2 ⊕ 3·3 = 3 ⊕ 2 = 1 ≠ 0 ⟹ (i,j) ↦ (L1,L2) 是双射 ⟹ 16 对互异。

参数由三点 (0,0),(0,1),(1,0) 确定（σ(0)=0, σ(1)=1，故各变体解出的 (a,b,c) 与纯仿射相同），逐格比对第一个不匹配：

## 五、对角引理数据（a≠b ⟹ transversal）

GF(4) 中副对角 j = 3−i = 3⊕i 是仿射映射，故 L(i,i) = (a+b)i⊕c，L(i,3⊕i) = (a+b)i⊕3b⊕c：

| 公式 | a+b | 主对角 | 副对角 |
|:----:|:---:|:------:|:------:|
| L1 = 2i+3j+2 | 1 | [2,3,0,1] 置换 ✓ | [0,1,2,3] 置换 ✓ |
| L2 = 3i+2j+2 | 1 | [2,3,0,1] 置换 ✓ | [3,2,1,0] 置换 ✓ |
| i+j（反例） | 0 | [0,0,0,0] ✗ | [3,3,3,3] ✗ |

transversal ⟹ 对角元素和恒 = 0+1+2+3 = 6 ⟹ 叠加对角和 = 4·6+6 = 30（0-15）/ +4 = 34（1-16）。

**命题**：完全幻方 = 正交拉丁方对（行列式 ≠ 0）+ 双方系数不对称 a≠b。

## 六、系数空间 Frobenius 共轭（修正后的 σ 角色）

σ(x)=x² = [0,1,3,2]，故 **σ(2)=3，σ(3)=2**：

```
L1 线性系数 (2,3) ──σ──▶ (3,2) = L2 线性系数
∀i,j: L2(i,j) = σ(2)·i ⊕ σ(3)·j ⊕ 2   ✅ 16 格全对
```

| 层面 | σ 作用 | 结果 |
|:----:|:------:|:----:|
| 坐标空间 i↦σ(i) | 变量替换 | ❌ 全部失败（§三） |
| 系数空间 a↦σ(a) | L1→L2 | ✅ 正交对 + 完全幻方 |

**诚实边界**：σ(c) = σ(2) = 3 ≠ 2 = c——共轭仅作用在线性系数对 (a,b)，**常数项未共轭**；「L2 是 L1 的完整仿射 σ 像」不成立。另 a⊕b = 1 是 σ-不动点（σ(1)=1），故对角 transversal 条件共轭不变。

与既有框架的对应：2·A₄ 特征标共轭 χ₁′(ω)↔χ₁″(ω²)、E⊥B 的 σ 共轭，同为「共轭对」结构在不同空间的投影；此处 σ 作用在**系数空间**。

## 七、经典 Dürer M₄ 负结果 + 归属更正

1. Dürer 本身是完全幻方（十线全 34，1-16 编码）✅。
2. 0-15 编码首行 [15,2,1,12] → 任何 M = 4A+B 分解中 A = ⌊v/4⌋ 被唯一强制，首行高位 **[3,0,0,3] 行内重复** ⟹ A 非拉丁 ⟹ **Dürer 不是正交拉丁方叠加**（自然基4编码；该分解唯一，与公式形式无关）。
3. **新发现**：库 M4（手写 L1/L2 叠加 +1）**不在经典 Dürer 的 D4 轨道**（8 个旋转/镜像全不匹配；直观判据：Dürer 中 15、14 相邻，库 M4 中 15 在 (2,3)、14 在 (0,2) 不相邻）。库 M4 是另一个关联型（complementary pairs 和 = 17）完全幻方。
4. **更正**：`OrthogonalLatinSquareGF4.agda` 头注释「手写 L1/L2（来自 Dürer M₄ 分解）」归属有误——应为「来自库 M4（MagicSquareM4.agda）分解」。该模块其余数学内容（genL1 ≢ 手写 L1、域仿射给半幻方）不受影响，均与本报告一致。
