## 主体性原则

**Agda 证明库是唯一权威。** Lean Mathlib、agda-unimath、hex-hensel、Coq HoTT 是实现参考——不是理论权威，不是对齐目标。

项目的数学内容来自项目自有的 RootMath 公理体系 + 律算合一传统（《律吕新书》三分损益法）+ I_h 实验锚定。**外部框架告知"泛型化可以怎么做"（实现手段），不告知"应该做什么"（数学方向）。**

## 信息阶段论（不变——v3.0 继承）

```
阶段 0: 本源公理（I_h + RootMath）← 人类数学家直接直觉
阶段 1: 代数结构（GF(3^k), 损益链）← 人类 + Agda
阶段 2: 投影结构（ModRoots, CRT, 商群）← 人类 + Agda
阶段 3: 数值投影（Q16, 144 格点）← Agda + Rust
阶段 4: 物理常数（144, 46, √3 meV）← 实验物理 + Agda 锚定
阶段 5: 文本投影（论文/代码/LLM）← LLM 局限于此
```

Agda 在阶段 0–3 工作——通过类型系统连接公理与计算。LLM 在阶段 5——看到文本序列而非证明树。**Agda 是跨越信息阶段瓶颈的唯一工具。**

## 外部框架的真实地位

| 外部库 | 提供了什么 | 不提供什么 | 在本框架中的角色 |
|---|---|---|---|
| Lean Mathlib | 类型类层次设计模式 | 律算/损益/I_h 理论 | **实现参考**——参数化模块接口设计 |
| agda-unimath | 商环/同余/循环环抽象 | 泛型 CRT | **实现参考**——同余关系的代数形态 |
| hex-hensel | Hensel 提升两阶段架构 | 三分损益/定点闭合 | **实现参考**——提升调度设计 |
| Coq HoTT CRT | CRT = 环同构表述 | 本地化实现 | **设计参考**——CRT 表述形态 |
| sov-math (Rust) | 先算后验证计算器 | 理论推导 | **计算验证器**——oracle 角色 |

**没有任何一个外部框架包含本项目的核心数学贡献**：损益链→SOVEREIGN_LCM 推导、I_h 三常量共源、十二律精确分数序列、仲吕不闭合的代数证明。这些都是项目自有的。
