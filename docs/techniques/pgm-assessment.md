# PGM（展示群元理论）设计评估：可实测的边界

**日期**: 2026-09-14　**状态**: 全部结论均有实测证据；**未作实现**（本轮只做可验证的边界测定）
**输入**: 用户交付的 PGM 设计文档（四层相等阶梯 L0–L3 + `presentation` 块 + 内核改造方案，自标「不是已实现的系统」）

本文件不做设计复述，只回答三个能用 Agda 裁决的问题：
**(Q1) `--rewriting` 能不能局部控制？　(Q2) 展示关系能不能声明成 L2 规约规则？　(Q3) 阶梯对称吗（`promote`/`demote`）？**

---

## Q1 ── 规则**不能**局部排除（设计的诊断成立；我先前的假设被推翻）

**实测**（`/tmp/pgmprobe/Infect.agda`，**不开** `--rewriting`，却 import 带重写规则的 `Sovereign.Structology.T6`）：

```
Infect（不开 --rewriting）rc=42
/tmp/pgmprobe/Infect.agda:3.1-50: error: [InfectiveImport]
using the --rewriting flag from a module which does not.
```

⇒ 只要 import 了带规则的模块，**导入方被迫开启 `--rewriting`**，且 Agda **没有任何机制隐藏/排除某条规则** ⇒ 定义与规则**捆绑传播**。
**结论**：设计文档「`--rewriting` 全局生效、无法局部控制」**成立**。
**自我更正**：我此前假设「重写规则按模块作用域生效 ⇒ L2 的局部性今天就有」——**该假设在本工具链上被机器推翻**（能选的只是"导入哪些模块"，而不能"只要定义、不要规则"）。

> 这同时**精确定位了 PGM 的真正卖点**：不是"加一个新相等层级"，而是
> **把规则集与定义集解耦**（可只导入定义、按作用域启用规则）。这是 Agda 今天确实缺的能力。

## Q2 ── 以**已定义运算**写的关系，大多声明不成 L2 规则

| 探针 | 规则形式 | 结果 |
|---|---|---|
| `Pgm1` | 用**库内已证定理** `mixedOp-12-cycle : ∀ p → mixedOp^12 p ≡ p` 作规则 | **rc=42**；`-W[no]RewriteLHSReduces`：`mixedOp-12-cycle is not a legal rewrite rule, since the left-hand side …`（`mixedOp^12` 是**已定义**符号 ⇒ δ 展开 ⇒ LHS 会归约） |
| `Pgm2` | 把 12 层 `mixedOp (T₁ , a1) (… p)` **嵌套写开**作规则 | **rc=42**；同样 `-W[no]RewriteLHSReduces`（LHS 头部 `mixedOp` 是已定义符号）；`l2-auto = refl` 随之 `[UnequalTerms]` |
| `Pgm3` | `mixedOp (T₀ , a0) p ↝ p` | **rc=0，但这是假证据**：`mixedOp (T₀,a0) p` 本来就**定义归约**（a0 是单位元）⇒ `refl` 无需规则即过；规则本身仍带 `RewriteLHSReduces` 警告 |
| `GapProbe10`（前轮，`docs/techniques/presentation-reduction-gap/`） | 生成元是 **postulate**（abstract，head 不可归约） | **rc=0，规则生效**（`λ x → refl` 证出普遍定律） |

**结论**：Agda 的规则要求 **LHS 不可归约**。在真实形式化里运算都是**已定义函数**（`mixedOp` / `step` / …），LHS 必然可归约 ⇒ **展示关系几乎声明不成 L2 规则**；只有「生成元是 postulate/builtin 原语（stuck 头部）」时才可行。
这正是库内 `Structology/T6.agda` 的规则写在 **builtin `div-helper`/`mod-helper`** 上、而不是写在库自己的取模运算上的原因（`T6.agda:20` 注释原话：「因 REWRITE 需 LHS 不可归约」）。

⇒ **对设计的直接影响**：PGM 的 `orientation` 子句若直接定向 `δ (δ (δ c)) → c` 而 `δ` 是已定义函数，**当前内核会拒收**；设计必须同时给出「生成元如何以 stuck 形式暴露」（如 postulate/parameter 化，或内核级新增"展示规约"而绕过 REWRITE 的 LHS 限制）——后者才是真正的内核工作量。

## Q3 ── 阶梯**不对称**：`promote` 存在，`demote` 不可能

- **`promote : x ≡_p y → x ≡ y`** ✓ **今天即可得**：每条重写规则的**命题形式**就是一个证明项（本项目每条规则都自带同型 postulate/lemma，例：`div3k`/`mod3k`）。L2 用法（`refl`）可**展开**为 L3 用法（显式规则应用 + `trans`）——已有实测同型的成对样本：`ReductionGapWitness` 里 `law-auto = λ x → refl`（有规则）对 `step-3-law`（3 个 case，无规则）。
- **`demote : x ≡ y → x ≡_p y`** ✗ **不可能**：从**证明**得不到**可转换性**。证明能给的只有**搬运**（`subst`）——那仍是 L3 的行为，不是 L1/L2 的定义相等。这正是「缺口」在反方向上的同一堵墙。

⇒ 设计文档「`demote` 把 L3 降级到 L2」这一条**不成立**；澄清写法：`x ≡ y` ⇒ 可 `subst` 改写（L3 内动作），但**无法**把 `x ≡_p y` 变成类型检查器可用的判定。

## Q4 ── 「L2 是新层级」这一表述需澄清

若 L2 相等**参与转换检查**（设计 §2.4 明确要求「转换检查时允许 L2 相等作为 L1 相等的见证」），那么**在该上下文里 `δ(δ(δ c))` 与 `c` 就是可转换的**——这就是"定义相等"在那个上下文的定义。
⇒ L2 不是一个可与 L1「并存互不干扰」的**相等层级**（定理 3 的表述），而是**上下文敏感的转换策略**：
- 「互不干扰」在有意义的意义上，只能表述为「**不带规则的上下文**里二者不可转换」（这正是前轮探针矩阵 `GapProbe2b` rc=42 与 `GapProbe9/10` rc=0 测出的东西 ✓）。

**给出的修正表述**：
> PGM 的 L2 = **按作用域启用的转换策略**；其价值在于（a）作用域可局部选择（今天缺失，见 Q1），（b）**规则集与定义集解耦**（今天缺失），（c）L3 见证仍可 `promote` 回显式证明（今天即可得）。「插入第三个相等层级」按字面读不成立。

## 结论（一句话）

**PGM 的诊断成立**（无局部控制、无规则/定义解耦、缺口真实），**但 §2 的实现路线在现有内核上会被两处硬约束卡住**：① 规则不可排除（Q1）；② 规则 LHS 不可归约 ⇒ 以已定义运算写的关系多半声明不成规则（Q2）。因此 PGM 若要有意义，其「内核改造」的最小必要集不是"四层相等阶梯"，而是：
**(a) 规则集与定义集解耦 + 作用域化（可只导入定义、按块启用规则）；(b) 允许 LHS 可归约的展示规约（或要求生成元以 stuck 形式暴露）；(c) 合流性/终止性检查（Agda 今日不查）。**
`demote`（Q3）与「L2 与 L1 并存不干扰」（Q4）两条表述需删改。
