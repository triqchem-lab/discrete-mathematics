# docs/techniques — 可复用的 Agda 证明技术

本目录收录**可复用的证明技术**（不是某个定理的证明，而是「一类目标怎么证」的方法论）。
每篇必须包含四样：

1. **适用判据** —— 什么形状能用、什么形状不能用（反例行）；
2. **实战证据** —— 至少一个已通过 Agda 内核的实例，附 `proof_compile` 回执与文件:行号；
3. **陷阱** —— 实战踩到的坑，附报错类型（可直接复现）；
4. **配套纪律** —— 用该技术做替换/重构时的交付证据要求。

## 约定

- 文中引用的**每个 Agda 符号名都必须能在源码 grep 到**（`grep -c "^<name> :"`），避免文档漂移（见 `memory/doc-code-drift-scan.md`）。
- 回执 ID 必须可查（绑源码哈希）；若模块此后被改动，回执即失效，文档须同步更新或标注。
- 技术升级（例如找到更通用的重排引理）时**追加**新篇或在篇内新增小节，不删除历史结论。
