## 一、阻塞总览

六个未解问题共享**两条基础设施链**：

```
链1 (N×N 线性代数)                 链2 (有限域曲线与群上同调)
─────────────────                  ─────────────────────────
jad_GF9Matrix det4-gf9 ✅           
  ↓                                 
jac_NxNDeterminant (N×N 行列式)     
  ↓                                 
jac_Eigenvalue (特征值)             
  ↓                                 
jac_CharPoly (特征多项式)           
  ↓                                 
┌─────────┬─────────┬──────────┐    
▼         ▼         ▼          ▼    
Hodge   PvsNP   YangMills   Langlands
    
                                     jac_CurveArith (有限域曲线算术)
                                       ↓  
                                     jac_Selmer (离散 Selmer 群)
                                       ↓
                                     BSD
```

## 二、所需模块清单

| # | 模块 | 内容 | 行数 | 解锁 |
|---|---|---|---|---|
| I1 | `jac_NxNDeterminant` | GF(9) 上 N×N Laplace 展开 (基于 det4-gf9 推广) | ~800 | 全部 |
| I2 | `jac_Eigenvalue` | GF(9) 上 2×2/3×3 特征值穷举 (9/27 case) | ~400 | LatticeField |

| I5 | `jac_CurveArith` | GF(9) 上椭圆曲线点计数 #E | ~800 | BSD |
| I6 | `jac_Selmer` | 离散 Selmer 群 H¹(G,E[n]) 有限计算 | ~600 | BSD |
| I7 | `jac_EllipticComplex` | 从单复形到椭圆复形的 jac_Topology 升级 | ~400 | Hodge |

| **合计** | **7 模块** | | **~4100 行** | |

## 三、解锁映射

| 千禧年问题 | 需要的基础设施 |
|---|---|
| **Hodge** | I1(N×N det) + I7(椭圆复形) |

## 四、执行序

```
Phase 1 (最先):  I1 (N×N Determinant)     ← 解锁全部
                  I2 (Eigenvalue)           ← 解锁 YM

Phase 2:          I3 (CharPoly)             ← 解锁 PvsNP
                  I4 (MatrixInverse)        ← 解锁 Langlands

Phase 3:          I5 (CurveArith)           ← 解锁 BSD
                  I6 (Selmer)               ← 解锁 BSD
                  I7 (EllipticComplex)      ← 解锁 Hodge
```
