## 一、问题

`F = Σ_j x_j²` 作用在 `R_n = GF(3)[x_1..x_n]/(x_j³)` 上（`dim R_n = 3^n`）。记
- `a_n = dim ker F_n`
- `c_n = dim ker F_n²`
- `b_n = dim(ker F_n ∩ V_nA)`（`V_nA` = 至少一个坐标指数为 0 的子空间）
- `q_n = dim(ker F_n ∩ im F_n)`

oracle 已确认（回执 `87ce8e37`、`bd06f20b`）：
```
a_n = 3^{n−1} + 2^{n−1},   b_n = 3^{n−1} − 2^{n−1},   c_n = 2·3^{n−1} + 2^{n−1},   q_n = 3^{n−1}
a_{n+1} = 2a_n + q_n,      b_{n+1} = 2b_n + q_n,      a_n − b_n = 2^n,   q_n = c_n − a_n
```

**缺口**：这些闭式的**结构证明**（数学上已知为真，形式化未完成）。

## 三、★ 成功的路线：按 `#2` **分片**

### 3.1 结构

`F` 在单项式基上：
```
F(x^a) = Σ_{j : a_j = 0} x^{a + 2e_j}          （a_j ≥ 1 的项被 x_j³ = 0 杀掉）
```
令 `S_k = {a : #2(a) = k}`（`#2(a) = #{j : a_j = 2}`，`|S_k| = C(n,k)·2^{n−k}`），则

```
★★ F : span(S_k) → span(S_{k+1})               （严格升一片）
⇒ ker F = ⊕_k ker(F|_{S_k})                    （分片直和）
```

### 3.2 两条精确分解（oracle `1588083b`，n=1..6，域 1092 全覆盖 ✓）

```
(A)  a_n = Σ_k dim ker(F|_{S_k})
(B)  q_n = Σ_k dim(ker(F|_{S_k}) ∩ im(F|_{S_{k−1}}))
```

| n | 各片 `ker/交` | `Σker`=`a_n` | `Σ交`=`q_n` |
|---|---|---|---|
| 1 | 1/0 1/1 | 2 | 1 = 3⁰ ✓ |
| 2 | 1/0 3/2 1/1 | 5 | 3 = 3¹ ✓ |
| 3 | 1/0 6/3 5/5 1/1 | 13 | 9 = 3² ✓ |
| 4 | 1/0 10/4 16/15 7/7 1/1 | 35 | 27 = 3³ ✓ |
| 5 | 1/0 15/5 41/36 30/30 9/9 1/1 | 97 | 81 = 3⁴ ✓ |
| 6 | 1/0 21/6 92/77 101/100 48/48 11/11 1/1 | 275 | 243 = 3⁵ ✓ |

### 3.3 三条可读出的子结构

1. **高片饱和**：`k ≥ n−2` 时 `交_k = ker_k`（交点 = 整片核）
2. **`ker_0 = 1`**，且 `rank(F|_{S_0}) = 2^n − 1`（实测 1,3,7,15,31）
3. **`ker_1 = C(n+1,2)`**（三角数 1,3,6,10,15,21）；**`交_{n,1} = n`**

## 十、④ 完成（2026-10-21，回执 `61e97ed7`）

### 10.1 ★ 找到了**不需要线性性**的 ④ 表述

**洞察** ✓：`mulX2 j p x` 只取 `p (zeroAt j x)` ✓，而 `wt2 (zeroAt j x) = wt2 x − 1` ✓
⇒ **`sum2 p x` 只用到 `p` 在片 `wt2 x − 1` 上的值** ✓ ✓

```agda
AgreeOn k p q = ∀ x → wt2 x ≡ k → p x ≡ q x
★ mulX2-agree : AgreeOn k p q → wt2 x ≡ suc k → mulX2 j p x ≡ mulX2 j q x
★★★ sum2-agree : AgreeOn k p q → wt2 x ≡ suc k → sum2 p x ≡ sum2 q x
```

### 10.2 这就是 `ker F = ⊕_k ker(F|_{S_k})` 的**点态内容**

```
片 k+1 处的方程（sum2 p x = 0）只约束 p 在片 k 上的值
⇒ 各片的核条件互相独立
⇒ ker F = ⊕_k ker(F|_{S_k})
```

**不需要线性性** ✓、**不需要 `restrict`** ✓、**不需要维数** ✓ —— 40 行 ✓

### 10.3 剩余

```
④ 点态内容 ✅ 完成
⑤ 维数相加（a_n = Σ_k dim ker_k）  ✗ 需要 dim ✗ —— 与块分解 ④ 同源
⑥ |S_k| = C(n,k)·2^{n−k}            ✓ 纯算术（真）
```

## 十三、构造性秩-零化度：设计修正（2026-10-21，计划执行中发现）

### 13.1 已确认的正面结论

**`ImOf V` 用数据表示 ⇒ `Σ` 相等不需要 funext** ✓
```agda
ImOf V T y = Σ (CoeffN n) (λ z → V z × Fiber T y z)
```
分量：`CoeffN n`（函数）+ `V z : Set`（命题）+ `Fiber T y z`（命题）
⇒ `Σ` 整体相等**不需要**分量级 funext ✓

### 13.2 ★ 执行中发现的设计问题：`section` 不能自动导出 ✗

**原想法**：`ImOf` 自带原像 ⇒ section = `proj₁` 自动 ✓
**实际**：**退化的** ✗
```
section (T p) ⟨p, Vp, refl⟩ = p
⇒ p = (p − section(T p)) + section(T p) = 0 + p    ← 恒等 ✗
```
⇒ 「核部分」永远是 0 ✗ —— 分解毫无信息 ✓

**根因** ✓：`im` 作为**数据**会记住原像 ✗ ⇒ 由它构造的 section **依赖 `p`** ✗
⇒ 不是「每类选一个代表」✗

### 13.3 ★ 修正：`section` 是**独立的第四个参数**，且带契约

```agda
-- 契约：σ y 只依赖 y 的值，不依赖 y 的哪个原像
-- （类型上无法强制 ⇒ 必须显式声明 ✓）
Section V T = (y : CoeffN m) → ImOf V T y → Σ (CoeffN n) (λ z → V z × Fiber T y z)
```

**mathlib** 用 `Classical.choice` + `Quot` 保证「只依赖类」✓
**构造性 Agda** 必须把它**显式假设** ✗ ✓

### 13.4 ★ 定理的精确陈述（交付时必须逐字写明）

```
rank-nullity（条件于四个参数）：
  给定
    ① bV : Basis V
    ② bK : Basis (V ∩ ker T)
    ③ bI : Basis (im T)
    ④ σ  : Section V T（满足「只依赖 y」的契约）
  则  Basis.dim bV ≡ Basis.dim bK + Basis.dim bI
```

**这不是**：
- ✗ 无条件的 `dim` 存在性（mathlib 有，我们没有）
- ✗ `q_n = 3^{n−1}`（8 条路线全败）
- ✗ `a_n` 的闭式

**这是** ✓：
- 条件于基 + section 的**结构等式**
- 把 `q_n = c_n − a_n` 从「具体 n 的数值」升为「任意 n 的结构等式（条件于基）」

### 13.5 对 T4 问题的直接帮助：**有限** ⚠️

`Basis (ker F_n)` 的显式构造**正是 `a_n` 闭式的困难所在** ✗ ——
所以本计划**闭合的是关系**（`q_n = c_n − a_n` ✓），**不是闭式**（`q_n = 3^{n−1}` ✗）

⇒ 交付时必须把这两件事**分开写** ✓
